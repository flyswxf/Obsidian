## 一、岗位概述

### 1.1 岗位定位

AI模型-多模态大模型岗位是一个**面向多模态大模型全栈研发的前沿技术岗位**，要求候选人具备从多模态模型架构设计、训练对齐、数据处理到推理部署的完整能力链。该岗位覆盖视觉-语言模型（VLM）、多模态生成模型（文生图/视频/3D）、以及统一理解-生成模型等前沿方向，是当前大模型领域最活跃、最具挑战性的研究方向之一。

该岗位的核心特点：
- **跨模态**：需要同时深入理解视觉（图像/视频）、语言、音频等多种模态
- **全链路**：从数据构建→模型架构→训练对齐→评测→推理部署的完整闭环
- **前沿性**：涉及 Qwen-VL、InternVL、GLM-4V、Sora、FLUX 等最新模型与技术
- **工程+研究并重**：既要求理论深度（架构设计、训练范式创新），又要求工程能力（训练框架、推理优化）

### 1.2 掌握程度体系

| 等级 | 能力定位 |
|------|----------|
| **入门级** | 不清楚相关概念，无法独立完成任务 |
| **基础级** | 了解基础概念和主流模型，能使用工具完成基本任务 |
| **进阶级** | 熟悉主流架构和评测体系，能针对具体任务进行训练和评测 |
| **精通级** | 深入理解关键技术选择，能系统优化复杂场景，具备工程实践见解 |
| **专家级** | 具备创新性研究或工程实践能力，能提出新方法/新架构，效果对齐或超越业界SOTA |

### 1.3 学习目标

- **短期目标（3-6个月）**：达到各知识领域进阶级水平，熟悉主流VLM架构和训练流程，能使用开源框架完成VLM训练和评测
- **中期目标（6-12个月）**：达到精通级水平，深入理解动态分辨率、原生多模态、MoE等关键技术，能系统优化复杂多模态场景
- **长期目标（12-18个月）**：向专家级迈进，具备多模态模型架构创新、训练范式改进或推理优化方面的研究/工程实践能力

### 1.4 岗位知识领域总览

| 知识领域 | 类型 | 核心内容 |
|----------|------|----------|
| 多模态模型架构 | 专业知识 | Transformer/ViT、VLM三段式架构、动态分辨率、原生多模态、MoE、长上下文 |
| 多模态任务与评测 | 专业知识 | Caption/VQA/OCR/Grounding、MMMU/MMBench/Video-MME、评测体系建设 |
| 多模态生成任务 | 专业知识 | 扩散模型(DDPM/DDIM)、SD/SDXL/FLUX/DiT、Flow Matching、文生视频/3D |
| 多模态模型训练与对齐 | 关键技能 | 视觉-语言对齐、SFT、DPO/MPO、GRPO/RLVR、幻觉抑制 |
| 多模态数据处理 | 关键技能 | 数据集构建、清洗标注、合成数据、主动学习 |
| 多模态模型推理与部署优化 | 关键技能 | vLLM/SGLang/TensorRT-LLM、视觉token压缩、量化、PD分离、MoE部署 |

## 三、分领域详细知识点梳理

### 3.1 多模态模型架构

#### 3.1.1 基础架构组件

**Transformer 架构回顾**
- Self-Attention 机制：Q/K/V 计算、缩放点积注意力、多头注意力
- Cross-Attention：跨模态注意力交互的核心机制
- 位置编码：绝对位置编码、相对位置编码、RoPE（旋转位置编码）、ALiBi
- LayerNorm vs RMSNorm：归一化方式对比与选择
- SwiGLU 激活函数：现代 LLM 的标准选择
- Flash Attention 1/2/3：IO 感知的注意力加速

**Vision Transformer (ViT)**
- Patch 化：图像切分为固定大小 Patch（通常 16×16），线性投影为 Token
- 位置嵌入：1D 绝对位置嵌入、2D 位置嵌入、相对位置嵌入
- Class Token (CLS Token)：全局图像表示的聚合
- ViT 变体：Swin Transformer（层次化/窗口注意力）、DeiT（数据高效训练）、BEiT（掩码图像建模）
- ViT 规模化：ViT-Large/Huge/Giant，视觉编码器的 Scaling Laws

**图像预处理与 Tokenization**
- 图像归一化与标准化（均值/方差归一化）
- Patch 化策略：固定 Patch 大小 vs 自适应 Patch
- 视觉 Token 嵌入：线性投影、卷积投影
- 图像 Token 与文本 Token 的统一表示空间

**CLIP 模型与对比学习**
- 图像-文本对比学习目标：InfoNCE Loss
- CLIP 视觉编码器（ViT 版本）与文本编码器（Transformer）
- 零样本分类与图文检索能力
- CLIP 嵌入空间特性分析
- CLIP 变体：OpenCLIP、EVA-CLIP、SigLIP

#### 3.1.2 VLM 三段式架构

**视觉编码器（Visual Encoder）**
- 预训练 ViT：使用 CLIP-ViT 或 EVA-CLIP 作为视觉编码器
- SigLIP：使用 Sigmoid Loss 替代 Softmax Loss 的改进方案
- 视觉编码器选择策略：分辨率、参数量、预训练数据影响
- 多视觉编码器融合：CLIP（语义）+ SAM（分割）+ DINOv2（结构）

**模态投影/连接层（Projector / Connector）**
- 线性投影层：LLaVA 的最简方案，直接线性映射
- MLP 投影层：LLaVA-1.5/Qwen-VL 的两层 MLP，更强的映射能力
- Q-Former：BLIP-2/InstructBLIP 的查询 Transformer，可学习查询提取视觉特征
- Perceiver Resampler：Flamingo 的固定数量 Token 生成机制
- Cross-Attention 适配器：在 LLM 层间插入交叉注意力
- 投影层设计对效果的影响：Token 数量、表达能力、训练效率

**LLM 解码器（Language Model Decoder）**
- 基座 LLM 选择：LLaMA、Qwen、GLM、Mistral 等开源 LLM
- 视觉 Token 插入位置：前缀插入（LLaVA）、交错插入（Flamingo）、任意位置
- 多模态输入格式设计：`<image> <visual_tokens> </image> <text>`
- LLM 规模对多模态能力的影响：7B/13B/72B/110B 的效果差异

#### 3.1.3 主流 VLM 模型详解

**LLaVA 系列**
- LLaVA：CLIP-ViT + 线性投影 + LLaMA，开创视觉指令微调范式
- LLaVA-1.5：MLP 投影层 + 数据增强，效果大幅提升
- LLaVA-NeXT：动态分辨率支持，多分辨率训练
- LLaVA-OneVision：统一图像/多图/视频处理架构
- 数据构建：GPT-4 辅助生成视觉指令数据

**Qwen-VL 系列**
- Qwen-VL：Qwen LLM + ViT + Cross-Attention 适配器
- Qwen2-VL：引入 M-RoPE（多模态旋转位置编码），原生动态分辨率
- Qwen3-VL：进一步架构优化与训练策略改进
- 关键创新：绝对位置编码实现动态分辨率、多粒度视觉编码

**InternVL 系列**
- InternVL：InternViT（6B 参数视觉编码器）+ QLLaMA
- InternVL 1.5：动态分辨率 + Pixel Shuffle 投影
- InternVL 2/2.5/3：多 LLM 规模选择、改进的数据管线
- 关键创新：InternViT 大规模视觉编码器、像素混洗 Token 压缩

**GLM-4V 系列**
- GLM-4V：基于 GLM 基座的原生多模态模型
- GLM-4.6V：增强的长上下文多模态理解
- 关键创新：原生多模态预训练、统一理解与生成

**Kimi（Moonshot）**
- 超长上下文多模态处理能力
- 文档理解与多页文档分析
- 关键创新：长上下文窗口扩展、高效 KV Cache 管理

#### 3.1.4 关键架构技术

**动态分辨率（Dynamic Resolution）**
- 核心问题：固定分辨率限制了高分辨率图像细节理解
- 任意分辨率输入处理：保持图像宽高比的动态分块
- Patch 数量自适应：根据图像大小调整 Token 数量
- 分块（Tile）策略：将大图切分为多个子图分别编码
- 高分辨率图像处理优化：计算量控制、Token 数量管理

**原生多模态（Native Multimodal）**
- 核心思想：从头训练统一多模态模型，而非后期拼接
- 统一 Token 空间：视觉/文本/音频 Token 在同一嵌入空间
- 模态融合 vs 模态拼接：深度交互 vs 简单连接
- Any-to-Any 架构：支持任意模态输入到任意模态输出

**MoE（Mixture of Experts）架构**
- MoE 基本原理：稀疏激活，每个 Token 只激活部分专家
- 路由机制：Top-K 路由、Expert Choice 路由
- 负载均衡：辅助损失确保专家利用率均衡
- 多模态 MoE 设计：模态特定专家 vs 共享专家
- DeepSeek-V3 MoE：细粒度专家 + 共享专家创新
- 稀疏激活与计算效率：参数量 vs 计算量解耦

**长上下文设计**
- 长上下文位置编码扩展：YaRN、NTK-aware 插值
- KV Cache 压缩与管理：PagedAttention、KV Cache 量化
- 长视频理解的上下文处理：时序 Token 高效编码
- Ring Attention / Sequence Parallelism：超长序列分布式处理
- 上下文窗口从 4K→32K→128K→1M 的扩展技术

#### 3.1.5 视频/音频多模态架构

**视频编码器**
- 视频 ViT：TimeSformer（时空分离注意力）、VideoMAE（掩码视频建模）
- 3D 卷积与时空注意力：时空联合建模
- 帧采样策略：均匀采样、密集采样、自适应关键帧选择
- 视频 Token 时序建模：时序位置编码、时序池化

**音频编码器**
- 音频频谱特征提取：Mel 频谱图、FBANK 特征
- Whisper 编码器：大规模预训练语音识别模型
- 音频 Token 化：连续音频信号到离散 Token 的转换
- 音频-语言对齐：音频嵌入空间与文本嵌入空间对齐

**统一多模态架构**
- Any-to-Any 模型设计：任意模态输入→任意模态输出
- 模态特定编码器 + 统一解码器架构
- 统一 Token 空间：Chameleon 式的统一 Token 化方案

#### 3.1.6 架构设计前沿

- **统一理解-生成模型**：Emu3（Next-token prediction 统一理解与生成）、Janus/JanusFlow（解耦理解与生成的统一框架）
- **多模态 Agent 架构**：GUI Agent（CogAgent/AppAgent）、VLA 机器人控制（RT-2/OpenVLA）
- **端到端多模态预训练**：从数据到模型的全流程统一训练
- **千亿参数多模态模型设计**：超大规模多模态模型的工程挑战与解决方案

### 3.3 多模态生成任务

#### 3.3.1 扩散模型基础

**扩散模型原理**
- 前向加噪过程：逐步向数据添加高斯噪声（马尔可夫链）
- 反向去噪过程：学习从噪声中恢复数据
- Score Matching / Score-based Models：分数匹配视角
- 概率流 ODE / SDE：连续时间扩散模型的数学框架

**DDPM**
- 训练目标推导：变分下界（ELBO）最大化
- 噪声调度：线性调度、余弦调度
- 参数化网络：U-Net 架构（下采样-瓶颈-上采样 + 跳跃连接）
- 采样算法：逐步去噪采样（通常需要 1000 步）

**DDIM**
- 非马尔可夫采样：跳步采样加速
- 确定性采样：相同噪声生成相同图像
- 加速采样：从 1000 步降至 20-50 步
- 插值与编辑：确定性采样支持图像插值和编辑

**潜空间扩散（Latent Diffusion）**
- VAE 编码器/解码器：将像素空间压缩到潜空间
- 潜空间扩散优势：计算效率大幅提升
- Stable Diffusion 架构：VAE + U-Net + 文本编码器
- 文本条件注入：Cross-Attention 层将文本信息注入生成过程

**分类器引导与无分类器引导**
- Classifier Guidance：使用分类器梯度引导生成
- Classifier-Free Guidance（CFG）：无需分类器的引导方法
- CFG Scale 调节：控制生成质量与多样性的权衡
- 负面提示词：通过负面条件引导避免不需要的内容

#### 3.3.2 主流文生图架构

**Stable Diffusion 系列**
- SD 1.5：基于 Latent Diffusion，CLIP 文本编码器
- SD 2.1：OpenCLIP 文本编码器，改进的训练数据
- SDXL：双文本编码器（CLIP + OpenCLIP），更大 U-Net
- SD3：引入 DiT 架构，Rectified Flow 采样
- 架构演进：U-Net → DiT，分辨率与质量持续提升

**DiT（Diffusion Transformer）**
- 核心创新：Transformer 替代 U-Net 作为去噪网络
- 缩放策略：模型规模可预测性扩展
- AdaLN-Zero 条件注入：自适应层归一化
- DiT 在 SD3/FLUX 中的应用：证明 Transformer 架构的优越性

**FLUX**
- Rectified Flow 架构：更高效的采样路径
- 双流/单流 Transformer：两阶段处理
- T5 + CLIP 双文本编码：强大的文本理解能力
- 超高分辨率生成：支持 4K 分辨率生成

**DALL-E 系列 / Imagen / Parti**
- DALL-E 1/2/3：从 dVAE 到扩散模型的演进
- Imagen：超大 T5 语言模型条件 + 级联扩散
- Parti：自回归文生图方法

#### 3.3.3 可控生成方法

**ControlNet**
- 条件控制原理：通过额外条件（边缘/深度/姿态/分割）控制生成
- 可训练副本设计：复制编码器权重，零初始化
- 多条件组合：多个 ControlNet 叠加
- ControlNet 变体：T2I-Adapter（轻量级）、ReferenceNet

**LoRA（Low-Rank Adaptation）**
- LoRA 原理：低秩矩阵分解，W = W₀ + BA
- 文生图风格定制：训练特定风格/角色的 LoRA
- 多 LoRA 合并：加权合并多个 LoRA
- LoRA 训练实践：数据准备、超参数调优

**IP-Adapter**
- 图像提示词注入：将图像作为额外条件
- 风格/内容迁移：保持参考图像的风格或内容
- FaceID/Portrait 生成：身份保持的人像生成
- 与 ControlNet 协同：精确控制 + 风格迁移

**InstantID / PhotoMaker**
- 身份保持生成：保持人脸身份的图像生成
- 面部特征嵌入：FaceNet/ArcFace 特征注入
- 个性化生成：少量参考图像定制生成

**其他可控生成技术**
- DreamBooth：少量图像微调实现主体定制
- Textual Inversion：学习新概念的嵌入表示
- Prompt-to-Prompt / Attention Control：通过修改注意力图控制生成
- InstructPix2Pix：指令式图像编辑
- Blended Diffusion / Mask-guided：区域控制生成

#### 3.3.4 新兴生成范式

**Flow Matching / Rectified Flow**
- 连续标准化流：学习概率路径的向量场
- 最优传输路径：从噪声到数据的直线路径
- Flow Matching vs Diffusion：更简单的训练目标、更高效的采样
- 在 FLUX/SD3 中的应用：替代传统扩散采样

**自回归图像生成**
- Visual Tokenizer：VQ-VAE/VQGAN 将图像编码为离散 Token
- 自回归 vs 扩散对比：生成质量、速度、可控性
- LlamaGen：LLaMA 架构用于图像生成
- Emu3：统一自回归框架下的图像生成

**掩码生成模型**
- MaskGIT：双向 Transformer + 迭代解码
- 随机掩码策略：从全掩码逐步揭示
- 并行解码：相比自回归的加速优势

**统一理解-生成模型**
- Emu3：Next-token prediction 统一理解与生成
- Janus / JanusFlow：解耦视觉编码（理解）和生成
- Show-o：自回归+扩散混合模型
- Chameleon：混合模态早期融合

#### 3.3.5 文生视频

**视频扩散模型基础**
- 3D U-Net / 时序层：在 2D U-Net 基础上增加时序维度
- 视频潜空间扩散：在潜空间中进行视频生成

- 时序注意力机制：跨帧信息交互

- 长视频生成策略：分块生成、时序条件

**可灵（Kling）/ Veo**
- 高质量视频生成：物理世界模拟级别的真实感
- 长视频时序一致性：分钟级视频的一致性保持
- 运动控制与物理模拟

**开源视频生成**
- ModelScope / AnimateDiff：图像动画化
- Stable Video Diffusion：Stability AI 的视频生成模型
- CogVideoX / Open-Sora：开源 Sora 复现
- HunyuanVideo：腾讯开源视频生成模型

**视频生成关键技术**
- 时序一致性保持：跨帧内容、风格、运动一致性
- 长视频生成：分块级联、时序条件传递
- 可控视频生成：运动控制、镜头控制、内容控制
- 视频编辑与修改：文本引导的视频编辑

#### 3.3.6 3D 生成

**3D 表示方法**
- NeRF / Instant-NGP：神经辐射场表示
- 3D Gaussian Splatting：显式 3D 高斯表示

#### 3.4.4 多模态偏好对齐

**RLHF（强化学习人类反馈）**
- 奖励模型训练：从人类偏好数据训练奖励模型
- PPO 优化：策略梯度强化学习
- 多模态 RLHF 流程：偏好数据→奖励模型→PPO 训练
- KL 散度约束：防止策略偏离参考模型

**DPO（Direct Preference Optimization）**
- DPO 原理：直接从偏好数据优化，无需奖励模型
- DPO 数学推导：Bradley-Terry 模型 + 变分推断
- 多模态 DPO 实现：视觉偏好对数据构建
- DPO 变体：IPO（保守DPO）、KTO（Kahneman-Tversky优化）、SimPO（简单DPO）

**MPO（Multimodal Preference Optimization）**
- 多模态偏好建模：考虑视觉和文本双模态偏好
- 混合偏好数据：人类偏好 + AI 反馈
- 多粒度偏好优化：图像级、区域级、文本级偏好

**GRPO（Group Relative Policy Optimization）**
- GRPO 原理：组内相对优势估计，无需奖励模型
- 组采样与优势计算：同一输入的多个输出比较
- 多模态 GRPO 应用：视觉问答的偏好优化

**RLVR（Reinforcement Learning with Verifiable Rewards）**
- 可验证奖励设计：基于规则的奖励信号（如 OCR 正确性）
- 视觉验证信号：视觉定位准确性作为奖励
- 多模态 RLVR 场景：文档理解、数学推理等可验证任务

**偏好数据构建**
- 人类标注偏好数据：成对比较标注
- AI 反馈（RLAIF）：使用强模型生成偏好标签
- 模型自生成偏好对：同一模型不同解码策略生成对比
- 偏好数据质量控制：标注一致性、难度分布

#### 3.4.5 幻觉抑制与推理增强

**多模态幻觉问题**
- 对象幻觉（Object Hallucination）：描述不存在的对象
- 属性幻觉：错误描述对象属性（颜色/数量/位置）
- 关系幻觉：错误描述对象间关系
- 幻觉成因分析：训练数据偏差、视觉编码不足、LLM 先验过强
