# Obsidian
Obsidian笔记同步

## UML 笔记获取指南

- 本仓库提供一个专用分支 `UML`，仅包含 `UML` 笔记内容
- 直接克隆该分支（仅拉取 UML 分支）：

```
git clone -b UML --single-branch <仓库地址>
```

提示：将 `<仓库地址>` 替换为实际的 Git 仓库 URL，例如 `https://github.com/<用户名>/<仓库名>.git`。


## 使用指南

- 克隆后可在 Obsidian 中选择“打开文件夹作为库（Open folder as vault）”，指向克隆目录下的 `UML`。
