## 一句话总结

文本到图像扩散模型里的 cross-attention 图把每个像素与提示词中的每个词绑定起来，实际决定了图像的空间布局；只要在去噪的每一步把这些注意力图从"原提示词的生成"注入到"新提示词的生成"，就能只改文字、不碰像素地完成局部替换、全局风格化与语义强度调节。

## 问题背景：为什么"改一个词"会毁掉整张图

大规模语言-图像模型（Imagen、DALL·E 2、Parti）能按文字生成语义与组合能力都很强的多样图像，但它们不提供简单的编辑手段：对提示词做哪怕最轻微的改动，输出往往变成一张完全不同的图。而编辑的内在要求恰恰相反——保留原图的大部分内容，只改想改的那一处。两者直接冲突。

已有手段为什么不够：

- **掩膜修复路线**（GLIDE、Blended Diffusion、DALL·E 2 等）：要求用户手工画出要重绘的区域，只改掩膜内、背景与原图对齐。问题在于画掩膜繁琐、破坏"快速直观的文字编辑"体验；且掩膜内的原始结构与内容被完全丢弃，因此"只改某个物体的纹理"这类编辑超出其能力范围。
- **GAN + CLIP 路线**：在人脸等高度筛选的数据集上效果很好，但在大规模多样数据上吃力。
- **纯文本（无掩膜）路线**：多数工作只能做全局编辑（如 VQGAN-CLIP）；Text2Live 能无掩膜局部编辑，但主要只能改纹理、改不了复杂结构（如把自行车换成汽车），而且每张输入图都要单独训练一个网络。

原文的目标因此很明确：只编辑文本提示词，不需要用户提供掩膜，也不需要模型训练、微调、额外数据或优化。

## 预备知识：扩散模型在做什么（原文附录 A.1）

为什么先补这一节：后文所有"注入"都发生在去噪的每一步内部，不先理解去噪，就无法理解注入到底发生在哪、又能改变什么。

通俗地说，扩散模型先给一张真实图像逐步加噪、直到变成纯噪声（前向过程），再训练一个网络学会把噪声一步步去回图像（反向过程）；生成图像就是从纯噪声出发跑一遍反向过程。（解读注：可以想象成给照片逐层蒙上磨砂玻璃，再学会逐层擦掉磨砂。）

- 前向过程是马尔可夫链，每步加高斯噪声：$q(x_t \mid x_{t-1}) := \mathcal{N}(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t \mathbf{I})$，由噪声调度 $\beta_0,\dots,\beta_T \in (0,1)$ 参数化；$T$ 足够大时 $x_T$ 近似各向同性高斯分布。
- 前向过程可以不采中间变量、直接写成数据与噪声的线性组合：
$$x_t = \sqrt{\alpha_t}\,x_0 + \sqrt{1-\alpha_t}\,w,\quad w \sim \mathcal{N}(0,\mathbf{I}),\quad \alpha_t := \prod_{i=1}^{t}(1-\beta_i)$$
- 反向过程用参数化高斯转移近似 $p_\theta(x_{t-1}\mid x_t) := \mathcal{N}(x_{t-1}\mid \mu_\theta(x_t,t), \Sigma_\theta(x_t,t))$，并把均值改为预测"被加进去的噪声" $\epsilon_\theta(x_t,t)$，由贝叶斯定理得：
$$\mu_\theta(x_t,t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\alpha_t}}\,\epsilon_\theta(x_t,t)\right)$$
- 采样一步：$x_{t-1} = \mu_\theta(x_t,t) + \sigma_t z,\ z \sim \mathcal{N}(0,\mathbf{I})$；DDIM 取所有步 $\sigma_t = 0$，使采样变为确定性过程。
- 训练目标（最大化变分下界）：
$$\min_\theta L(\theta) := \mathbb{E}_{x_0\sim q(x_0),\, w\sim\mathcal{N}(0,\mathbf{I}),\, t}\,\big\| w - \epsilon_\theta(x_t,t) \big\|_2^2$$

直观解释：模型的核心能力就是"给定带噪图与当前步号，猜出图里被加的噪声"；生成即反复猜噪声、减噪声。

## 核心观察：注意力图就是图像的"布局图"

### 一个失败的朴素尝试

设图像 $I$ 由文本引导扩散模型用提示词 $P$ 与随机种子 $s$ 生成，目标是只给编辑后的提示词 $P^*$、得到编辑图 $I^*$。最朴素的想法是固定内部随机性、用 $P^*$ 重新生成。原文 fig. 2 表明这完全失败：以 "lemon cake" 生成的图为起点，仅保持随机种子相同而不注入注意力，把提示词换成 "pumpkin cake" 等会得到结构与原图几乎无关的全新图像。

为什么这一步重要：它排除了"随机性是唯一决定因素"的可能，逼出真正可控的量——像素与文本的交互。

### cross-attention 在文本条件扩散模型中的角色

通俗地说，cross-attention（交叉注意力）就是让图像的每个像素去"询问"提示词里的每个词："你和我有关吗？有关就把你的内容给我。"原文以 Imagen 为骨干模型。Imagen 由三个文本条件扩散模型串联：文生图 $64\times64$ 模型，以及两个超分辨率模型 $64\times64\to256\times256$、$256\times256\to1024\times1024$。由于构图与几何主要在 $64\times64$ 分辨率上决定，原文只改造文生图扩散模型，超分辨率部分原样使用。三个模型的差异为：

- $64\times64$ 模型从随机噪声出发、使用 U-Net；在 U-Net 的下采样与上采样中，分辨率 $[16, 8]$ 处用 cross-attention 层、分辨率 $[32, 16, 8]$ 处用 hybrid-attention 层来条件于文本嵌入。
- $64\to256$ 模型以朴素上采样的 $64\times64$ 图为条件，使用高效 U-Net，瓶颈（分辨率 32）含 hybrid attention 层。
- $256\to1024$ 模型以朴素上采样的 $256\times256$ 图为条件，使用高效 U-Net，瓶颈（分辨率 64）只含 cross-attention 层。

每个扩散步 $t$ 用 U 形网络从带噪图 $z_t$ 与文本嵌入 $\psi(P)$ 预测噪声 $\epsilon$，最终 $I = z_0$。两种模态的交互就发生在噪声预测内部：视觉与文本特征经 cross-attention 层融合，为每个文本 token 产出一张空间注意力图。

形式化（原文式 1 及上下文）：带噪图的深层空间特征 $\phi(z_t)$ 经可学习线性投影得到查询矩阵 $Q = \ell_Q(\phi(z_t))$；文本嵌入被投影为键矩阵 $K = \ell_K(\psi(P))$ 与值矩阵 $V = \ell_V(\psi(P))$。注意力图为

$$M = \mathrm{Softmax}\!\left(\frac{Q K^{T}}{\sqrt{d}}\right)$$

符号逐项：

- $Q$：每个图像像素（空间位置）一个查询向量，代表"这个像素想找什么"；
- $K$：每个文本 token 一个键向量，代表"这个词能提供什么"；
- $V$：每个文本 token 一个值向量，代表"这个词携带的内容"；
- $d$：键与查询的隐空间投影维度，$\sqrt{d}$ 起缩放作用；
- $M_{ij}$：第 $j$ 个 token 的值对第 $i$ 个像素的权重，即"像素 $i$ 在多大程度上听词 $j$ 的"；
- $\mathrm{Softmax}$：沿 token 维度归一化，使每个像素对所有词的权重和为 1。

cross-attention 的输出为 $\hat{\phi}(z_t) = M V$，再用于更新空间特征 $\phi(z_t)$。

直观解释：$MV$ 就是以注意力图 $M$ 为权重、对值 $V$ 做加权平均，而 $M$ 由 $Q$ 与 $K$ 的相似度决定，因此"像素与词的匹配程度"直接决定每个像素从哪些词取内容。实践中并行使用多头注意力，再把各头结果拼接、过一个可学习线性层得到最终输出。

原文还指出，Imagen 与 GLIDE 类似，在每步噪声预测中通过两类注意力层条件于文本：i) cross-attention 层；ii) hybrid attention——把文本嵌入序列直接拼接到每个自注意力层的键值对上，从而同时充当自注意力与 cross-attention。后文把两者统称 cross-attention，因为该方法只干预 hybrid attention 中的 cross-attention 部分，即只修改对应文本 token 的最后若干通道。

### 观察：像素被"描述它的词"吸引，且结构早期就定型

原文 fig. 4 以提示词 "a furry bear watching a bird" 展示 cross-attention 图：对所有时间步平均后，每个词对应一张空间图，熊的像素集中在 "bear"、鸟的像素集中在 "bird"，即像素更倾向于关注描述它自己的词；逐时间步的图还显示，图像结构在扩散过程的早期步骤就已确定。注意：平均只是为了可视化，方法中各 head 的注意力图保持分开。

（解读注：可以把 $M$ 看成一张"词 → 区域"的软分割图，这正是后续所有编辑操作的把手；这一观察与 [[DAAM-扩散模型cross-attention词像素归因|DAAM 的词-像素归因]] 同源，区别在于本篇把它当作控制量而非事后解释。）

### 从观察到方法：注入注意力图

既然注意力图反映整体构图，就可以把用原提示词 $P$ 生成时得到的注意力图 $M$，注入到用修改后提示词 $P^*$ 的第二次生成中，从而合成既按 $P^*$ 被编辑、又保留 $I$ 结构的图像 $I^*$。这是后文一切编辑操作的总纲。

## 通用编辑框架：把"注入"写成算法

记号（原文 3.2 节）：

- $\mathrm{DM}(z_t, P, t, s)$：扩散过程单步 $t$ 的计算，输出带噪图 $z_{t-1}$ 与注意力图 $M_t$（不用时省略）；
- $\mathrm{DM}(z_t, P, t, s)\{M \xleftarrow{c} \hat{M}\}$：该扩散步中用给定的 $\hat{M}$ 覆盖注意力图 $M$，但值 $V$ 仍来自当前提示词；
- $M_t^{*}$：用编辑后提示词 $P^*$ 产生的注意力图；
- $\mathrm{Edit}(M_t, M_t^{*}, t)$：通用编辑函数，输入原图与编辑图在各自生成过程中第 $t$ 步的注意力图。

算法 1（原文的 Prompt-to-Prompt 编辑算法）：

1. 输入：源提示词 $P$、目标提示词 $P^*$、随机种子 $s$；输出：源图 $x_{src}$ 与编辑图 $x_{dst}$。
2. $z_T \sim \mathcal{N}(0,\mathbf{I})$（随机种子 $s$）；$z_T^{*} \leftarrow z_T$。
3. 对 $t = T, T-1, \dots, 1$ 循环：
   - $z_{t-1}, M_t \leftarrow \mathrm{DM}(z_t, P, t, s)$；
   - $M_t^{*} \leftarrow \mathrm{DM}(z_t^{*}, P^*, t, s)$；
   - $\hat{M}_t \leftarrow \mathrm{Edit}(M_t, M_t^{*}, t)$；
   - $z_{t-1}^{*} \leftarrow \mathrm{DM}(z_t^{*}, P^*, t, s_t)\{M \xleftarrow{c} \hat{M}_t\}$。
4. 返回 $(z_0, z_0^{*})$。

要点：

- 两个提示词的扩散过程同时进行，每步按编辑任务施加一次基于注意力的操作。
- 必须固定内部随机性：扩散模型的特性决定了即使同一提示词，两个随机种子也会产生截然不同的输出。
- 开销很小：第 7 行的前向调用可以省掉（把编辑函数放进扩散前向函数内部实现）；同一步还可对 $z_{t-1}$ 与 $z_t^{*}$ 同 batch 并行计算，因此相对原始推理只多一步开销。
- 也可以把"由 $P$ 与 $s$ 生成的图像 $I$"作为额外输入，算法保持不变；真实图像的编辑见下一节的应用部分。

直观解释：相当于让"新提示词的生成"在每一步都参考"旧提示词生成"的布局草稿——只换内容、不换排版。

## 三类编辑操作：Edit 函数的三种填法

### 词替换（Word Swap）

场景：把原提示词的某个 token 换成另一个，如 $P=$ "a big red bicycle" 改为 $P^*=$ "a big red car"。挑战是既保留原构图、又体现新内容。做法是把源图注意力图注入新提示词的生成；但全程注入可能过度约束几何（尤其涉及大结构改动时），因此原文给出更软的约束：

$$\mathrm{Edit}(M_t, M_t^{*}, t) := \begin{cases} M_t^{*} & \text{if } t < \tau \\ M_t & \text{otherwise} \end{cases}$$

符号：$\tau$ 是时间戳参数，决定注入施加到第几步为止；$t \ge \tau$（扩散早期）注入源图 $M_t$，$t < \tau$（扩散后期）改用目标自己的 $M_t^{*}$。

直观解释：构图在早期步骤定型，所以只在早期注入源图布局来"定版式"，后期放开、让模型自由适应新词所需的几何。

原文补充：还可以为提示词中不同 token 指定不同的注入步数；若两个词对应的 token 数不同，可用对齐函数对注意力图做复制或平均。

### 添加新短语（Adding a New Phrase）

场景：向提示词添加新 token，如 $P=$ "a castle next to a river" 改为 $P^*=$ "children drawing of a castle next to a river"。为保留共有细节，只对两个提示词共有的 token 做注意力注入。为此引入对齐函数 $\mathcal{A}$：输入目标提示词 $P^*$ 的 token 下标，输出其在 $P$ 中对应的 token 下标，无匹配则输出 None。编辑函数为

$$\big(\mathrm{Edit}(M_t, M_t^{*}, t)\big)_{i,j} := \begin{cases} (M_t^{*})_{i,j} & \text{if } \mathcal{A}(j) = \mathrm{None} \\ (M_t)_{i,\mathcal{A}(j)} & \text{otherwise} \end{cases}$$

符号：下标 $i$ 对应像素、$j$ 对应文本 token；新词的列（$\mathcal{A}(j)=\mathrm{None}$）保留目标自己的注意力，旧词的列按对齐位置从源图取。同样可设时间戳 $\tau$ 控制注入步数。

直观解释：老词沿用旧版式、新词自由发挥，于是加风格词就是风格化、加属性词就是局部细化、加场景词就是全局修改。

### 注意力重加权（Attention Re-weighting）

场景：增强或减弱某个词对结果的影响程度，如 $P=$ "a fluffy red ball"，想让球更蓬松或更不蓬松。做法是用参数 $c \in [-2, 2]$ 缩放指定 token $j^{*}$ 的注意力图，其余注意力图保持不变：

$$\big(\mathrm{Edit}(M_t, M_t^{*}, t)\big)_{i,j} := \begin{cases} c \cdot (M_t)_{i,j} & \text{if } j = j^{*} \\ (M_t)_{i,j} & \text{otherwise} \end{cases}$$

直观解释：把某个词的"音量旋钮"拧大或拧小，得到类似 fader 的连续控制。

## 应用与实验评估（原文第 4 节）

需要先说明：原文第 4 节题为 Applications，全部为定性展示与成组视觉对照，没有给出定量基准数据集、数值指标或用户研究；该方法本身也不需要训练数据。因此"评估"体现为固定其他变量、只改一个因素的对照组，以下数字均引自原文。

- **骨干与分辨率**：被改造的是 Imagen 文生图 $64\times64$ 模型，超分原样使用；cross-attention 位于分辨率 $[16,8]$、hybrid attention 位于 $[32,16,8]$，两个超分模型的瓶颈分辨率分别为 32 与 64。
- **纯文本局部编辑（无掩膜）**：fig. 2 以 "lemon cake" 为源，替换为 pumpkin、pasta、chocolate 等蛋糕，保留空间布局、几何与语义，背景（含左上角的柠檬）也被保留并相应变为南瓜；对照条件为"仅固定随机种子、不注入注意力"（含确定性 DDIM 采样），结果是几乎无关的全新几何。fig. 5 只注入 "butterfly" 一个词的注意力，即可在替换上下文（花、草地、地面、河面、水果、桌子、杯子、电脑、长笛、小提琴、礼物、糖果、玛芬、蛋糕、披萨、面包）时保持蝴蝶的结构与外观。
- **注入步数是保真旋钮**：fig. 6 以 "photo of a cat riding on a bicycle" 为源，把 bicycle 换成 motorcycle、car、airplane、train，注入比例从 0%（左）到 100%（右）的扩散步。不注入时源图内容没有任何保留保证；注入步数越多对原图保真越高；但全程注入会过度约束几何、降低对文本的保真——第 3 行的 car 在 100% 注入下变回了自行车。
- **添加细化**：fig. 7 上排对 "A car on the side of the street." 加局部描述（sport、old、crushed、mat black、limousine、American、convertible），下排加全局描述（flooded street、in Manhattan、blossom street、at autumn、snowy street、in the forest、at sunset、at evening）。
- **全局编辑与风格化**：fig. 7 下排与 fig. 8（"A waterfall between the mountains." 加 drawing of、photo of、painting of、watercolor、charcoal、impressionism、futuristic、neo classical，或 in the jungle、in the desert、on mars）在改变整体风格的同时保留原构图与物体的位置、身份。
- **Fader 控制**：fig. 9 对 "birthday"、"blossom"、"snowy"、"fluffy" 等词做注意力重加权，减小（上排）或增大（下排）其影响，用于控制"山上雪量"这类难以用文字精确描述的程度。
- **真实图像编辑**：需要先做反演（inversion），即找到喂进扩散过程能复现给定图像 $x_0$ 的初始噪声。朴素做法是给输入图加高斯噪声、再跑预定步数去噪，会产生显著畸变；原文改用基于确定性 DDIM（而非 DDPM）的改进反演，把扩散过程反向运行 $x_0 \to x_T$（$x_0$ 设为给定真实图像）。fig. 10 给出成功例子，fig. 11 给出反演失败例子。
- **失真—可编辑权衡**：原文指出反演的不足部分源于 distortion–editability tradeoff——降低 classifier-free guidance 参数（即降低提示词影响）能改善重建，但会限制做大幅修改的能力。
- **自动掩膜补救**：为缓解反演失真，原文用直接从注意力图提取的掩膜恢复原图未编辑区域，该掩膜不需要用户任何指导。fig. 12（"Image of cat wearing a floral shirt."，流程为 resized image + prompt → noised → denoised + attention map → bended → SR）表明即使使用朴素 DDPM 反演（加噪再去噪），猫的身份也能在各种编辑下保持。

## 结论

原文结论：cross-attention 层在文本到图像扩散模型中具有可解释的空间图表示，是把提示词中的词与合成图像空间布局绑定的关键；据此，对提示词的各种操作可以直接控制合成图像的属性，支撑局部与全局编辑。该工作是"给用户简单直观的图像编辑手段"的第一步，让用户在语义文本空间中渐进式导航，而非每次改文字都从零生成一张新图。

## 原文声明的局限

1. **反演**：当前反演过程在部分测试图像上产生可见畸变；且反演要求用户给出合适的提示词，对复杂构图而言困难。原文强调文本引导扩散模型的反演是与其工作正交的课题，留待后续研究。
2. **注意力图分辨率低**：cross-attention 位于网络瓶颈，注意力图分辨率受限，约束了更精确的局部编辑。原文建议在更高分辨率层也加入 cross-attention，但这需要分析训练过程，超出当前范围。
3. **不能移动物体**：当前方法无法在图像内空间地平移已有物体，此类控制留作未来工作。

这篇论文把 [[交叉注意力机制 (Cross-Attention)|交叉注意力]] 从一种"模态融合机制"提升为"可控的布局句柄"，其前提是 [[回归模型与扩散模型|扩散模型]] 的去噪采样可以被逐步干预。在注意力可解释性这条线上，它与 [[DAAM-扩散模型cross-attention词像素归因|DAAM]] 共享同一观察——聚合的 cross-attention 图携带词与图像区域的对应关系；区别在于 DAAM 用它做事后归因，本篇把它事前注入以控制生成。二者连同 [[Chefer-Transformer可解释性-相关性传播|Chefer 的相关性传播]] 一起，构成 [[2026-11-19-注意力可视化新文献复现规划|注意力可视化新文献复现规划]] 中"替换/抑制 cross-attention 图可控制生成图像布局"这一复现判据的理论来源，具体复现状态记录在 [[2026-11-14-注意力可视化复现实验|注意力可视化复现实验]]；术语层面的统一解释见 [[注意力可解释性术语详解]]，本篇在 [[文献阅读报告]] 的注意力可解释性条目下登记。
