## 一、Transformer 的基本零件

### token 与分词

模型不直接吃文字，而是把文字切成 **token**（词元）。切法叫 **分词（tokenization）**，主流算法是 **BPE**（Byte-Pair Encoding，字节对编码）：先按字符拆，再把高频字符组合并成一个 token。

后果是一个"词"可能被拆成多个 token。例如 `didn't` 在 BERT 里是 `didn` + `'` + `t` 三个 token。这就是为什么 [[AttentionFlow与Kobayashi范数-注意力可信吗|B 路实验]]的表格里会出现 top-1 token 是 `'` 这种看起来很荒谬的结果——单引号是独立 token。

RoBERTa 的 token 带 `Ġ` 前缀（`Ġanimal`），那个符号代表一个空格。所以定位候选词不能用字符串相等，得用字符区间重叠。

### 特殊 token

| token | 所属模型 | 含义 |
| --- | --- | --- |
| `[CLS]` | BERT | 序列开头的"汇总位"，其向量常被当作整句表示 |
| `[SEP]` | BERT | 分隔符 / 句子结束标记 |
| `[MASK]` | BERT | 完形填空的挖空位 |
| `<s>` / `</s>` / `<mask>` | RoBERTa | 对应上面三个 |
| EOT | CLIP | end-of-text，文本塔的"汇总位"，作用同 `[CLS]` |
| `<\|vision_start\|>` `<\|image_pad\|>` | Qwen2-VL | 视觉 token 的起止与占位 |

**关键陷阱**：`[CLS]` / `<s>` 这类位置在很多层里会吸走大量注意力，但吸走的注意力往往不代表语义贡献。B 路实验发现 rollout 的 top-1 恒为 `[CLS]`，C 路实验发现 layer 8 的质量大量压在首个视觉 token 上——都是同一个病。

### 注意力的计算

第 $l$ 层第 $h$ 个头里，每个位置 $i$ 生成查询 $q_i$、键 $k_j$、值 $v_j$：

$$\alpha_{ij}=\frac{\exp\left(q_i\cdot k_j/\sqrt{d}\right)}{\sum_{j'}\exp\left(q_i\cdot k_{j'}/\sqrt{d}\right)},\qquad o_i=\sum_j \alpha_{ij}\,v_j$$

- $\alpha_{ij}$ 就是**注意力权重**，读作"位置 $i$ 对位置 $j$ 的关注程度"。每行和为 1。
- $o_i$ 是位置 $i$ 的输出，是所有 $v_j$ 的加权和。
- **多头（multi-head）**：并行走 $h$ 套独立的 $W_Q/W_K/W_V$，各自算完再拼接，最后过一个 $W_O$ 投影。BERT-base 是 12 层 × 12 头。

"注意力可视化"绝大多数时候就是在可视化 $\alpha$。全部争议都围绕一个问题：**$\alpha_{ij}$ 大，是否意味着 $j$ 对 $i$ 的贡献大？**

### 残差连接与 LayerNorm

**残差连接（residual connection）**：子层的输出加回输入，$x \leftarrow x + \mathrm{Sublayer}(x)$。作用是让梯度能直接回流、让深层网络可训练。

**LayerNorm（层归一化，LN）**：把一个向量沿特征维减均值、除标准差，再乘可学习的缩放与偏置。作用是稳定数值分布。

这两个零件是"注意力 ≠ 贡献"的根源之一：因为信息可以走残差通道绕过注意力，也可以被 LN 重新缩放。[[AttentionFlow与Kobayashi范数-注意力可信吗|Kobayashi 2021]] 的全部工作就是把这两项显式计入打分。

### 三种 Transformer 架构

| 架构 | 代表模型 | 注意力是否受因果掩码限制 | 典型任务 |
| --- | --- | --- | --- |
| Encoder-only | BERT、RoBERTa | 否，任意 token 互相可见 | 完形填空、分类、句向量 |
| Decoder-only | GPT、Qwen2-VL、LLaVA | 是，只能看左边（**causal mask**） | 自回归生成 |
| Dual-encoder | CLIP | 各塔内部双向，两塔之间无交叉注意力 | 图文检索、图文对齐 |

这个区分直接决定了注意力矩阵长什么样、以及"该看哪一层"。B 路用 encoder-only，C 路用 decoder-only，A 路用 dual-encoder。

### KV cache 与注意力实现方式

生成式模型每产出一个 token 都要重算注意力，太浪费。**KV cache** 把历史的 $k,v$ 存下来，新 token 只算自己那一行。代价是显存随序列长度线性增长。

PyTorch 提供三种注意力实现：

| 实现 | 是否 materialise 完整 $\alpha$ 矩阵 | 能否拿到注意力 | 显存 |
| --- | --- | --- | --- |
| `eager` | 是，$O(P^2)$ | 能 | 高 |
| `sdpa` | 否（融合 kernel） | 不能，`output_attentions=True` 会强制回退 | 低 |
| `flash_attention_2` | 否 | 不能 | 最低 |

**这是 C 路实验的硬约束**：要提取注意力就必须用 `eager`，就必须吃下 $O(P^2)$ 的中间张量，8B 模型因此在 8 GB 显存上无解。这也是 A 路实验报错 `cannot register a hook on a tensor that doesn't require gradient` 的同源问题——想拿内部量就得放弃省显存的捷径。

## 二、注意力的四种"看法"

同一个模型，"哪些 token 重要"有四种主流算法。理解它们的差别是读懂 B 路实验的前提。

### 1. Raw attention（原始注意力）

直接取某一层的 $\alpha$，通常再对头求平均。最简单，也最不可靠：只看一层，忽略了信息跨层的累积流动。

### 2. Attention Rollout（滚动传播）

Abnar & Zuidema 提出。先做**残差增强**：

$$A'=0.5A+0.5I$$

加 $0.5I$ 表示"有一半信息原地不动，走残差通道"。然后逐层连乘：

$$R^{(l)}=A'^{(l)}R^{(l-1)},\qquad R^{(0)}=I$$

取 $R^{(L)}$ 的某一行，就是"顶层这个位置的信息里，有多少比例来自每个输入 token"。

**病灶**：连乘会让分布不断变平，且 `[CLS]` 因为在每层都吸注意力，连乘后被指数级放大。B 路实验里两句的 rollout top-1 都是 `[CLS]`。

### 3. Attention Flow（注意力流）

同样是 Abnar & Zuidema 提出，但换成**图上的最大流**问题。把每层的 $\tilde A=0.5A+0.5I$ 当作边容量，构造一张 $L+1$ 层节点的有向图（论文 Fig.1 画法是把每层拆成"注意力节点层 + 词向量节点层"共 $2L+2$ 层，官方代码把两者合并成单个 $(l,k)$ 节点，残差边折叠进 $0.5I$）。

从顶层的查询词（源）到某个输入词（汇）求**最大流** $F(v)$，作为归因分数。两种归一化：

- `flow_unnormalised`：直接用 $F(v)$，可 ≥ 源出容量。**用来判断是否饱和。**
- `flow_normalised`：$F(v)/\sum_{v'}F(v')$，行归一化成概率。**用来和其他方法比排名。**

最大流算法有两套：networkx 的 **Edmonds–Karp**（浮点容量）、scipy 的 **Boykov–Kolmogorov**（整数容量，需乘 $10^6$ 取整，且 CSR 图必须结构对称，每条边要补一条零容量反向边）。两套互验相差 1e-7 量级，说明实现没错。

**病灶**：**源侧容量饱和**。$\tilde A$ 行和为 1，所以源节点出容量恰好是 1；只要汇入容量 ≥ 1，最大流就顶满 1.0，所有 token 拿到的分数都一样。B 路在 BERT 上观察到的正是这个：`animal` 与 `street` 的 `flow_unnormalised` 都是 1.000000。

**min-cut（最小割）** 是诊断工具：最大流 = 最小割容量。B 路算出 min-cut = 1.000000 且 binding 在源侧，直接定位了瓶颈位置。

### 4. 梯度修正的相关性传播（Chefer）

见 [[Chefer-Transformer可解释性-相关性传播|专文]]。核心是先用梯度给注意力加权，再逐层传播：

$$\bar{A}=\frac{1}{h}\sum_{k=1}^{h}\left(\nabla A^{(k)}\odot A^{(k)}\right)^{+},\qquad R \leftarrow R+\bar{A}R$$

$(\cdot)^+$ 是逐元素 ReLU（只保留正贡献），$\odot$ 是逐元素相乘。直觉：**注意力高、且梯度也说"这个注意力对当前输出有正贡献"的部分才留下。**

### 5. Grad-CAM（对照组）

卷积网络时代的经典方法，套到 Transformer 上作基线：

$$\alpha_k=\frac{1}{Z}\sum_{i}\sum_{j}\frac{\partial y^c}{\partial A^k_{ij}},\qquad L_{\text{Grad-CAM}}=\mathrm{ReLU}\!\left(\sum_k \alpha_k A^k\right)$$

即"用梯度给特征图 $A^k$ 加权求和"。两个适配点：

- **target layer（目标层）**：必须指定在哪一层取激活。选错层结果可能整体退化为零。
- **reshape_transform**：ViT 的激活形状是 $(1+49,\ B,\ C)$（序列长度 × batch × 通道），Grad-CAM 要求 4D 的 $(B,C,H,W)$，所以要丢掉 CLS token 再 reshape 成 $(B,C,7,7)$。

## 三、归因是否等于贡献：Kobayashi 的两个度量

### 2020 版：变换后向量的范数

Kobayashi 等人（*Attention is Not Only a Weight*, EMNLP 2020）指出：$\alpha_{ij}$ 只是权重，真正加到残差流上的是 $\alpha_{ij}v_j$ 再经 $W_O$ 变换。所以对每个头定义

$$f^{(l,h)}(x_s)=W_O^{(h)}\big(W_V^{(h)}x_s+b_V^{(h)}\big)$$

度量 $\big\|\alpha_{ts}f(x_s)\big\|_2=\alpha_{ts}\,\big\|f(x_s)\big\|_2$。

**实现细节（极易错）**：$W_O$ 必须按头切列 `Wo[:, h*dh:(h+1)*dh]`，否则得到的是混合了所有头的错误向量。正确性校验方式是验证

$$\sum_h \alpha^{(h)} f^{(h)}(x)+b_O$$

能精确重构真实的 attention 输出——B 路实测误差 2.0e-06。

### 2021 版：把残差与 LayerNorm 计入

同一作者（*Incorporating Residual and Normalization Layers*, EMNLP 2021）进一步指出，2020 版仍忽略了残差流本身与 LN 的压缩：

$$g_t(x_s)=\mathrm{LN}\big(h_{l-1}[t]+b_O+\alpha_{ts}f(x_s)\big),\qquad \text{score}_{2021}(s)=\big\|g_t(x_s)\big\|-\big\|g_t(0)\big\|$$

读作"把 $s$ 的贡献加进去后，目标位置表示的范数变化了多少"，**可正可负**。负值意味着加入这个 token 反而让表示范数变小。

### rank gap（排名差）

对每个 token 算两个排名：按 $\alpha$ 的排名 $r_\alpha$、按 $\|\alpha f\|$ 的排名 $r_{norm}$，则

$$\text{rank gap}=r_\alpha-r_{norm}$$

- gap < 0：**高权重 / 低范数**，即"看着很重要，实际贡献小"。BERT 的 `[SEP]` 是 −7。
- gap > 0：**低权重 / 高范数**，即"看着不重要，实际贡献大"。`because` 是 +3。

## 四、注意力里的两种病理现象

### Attention sink（注意力下沉）

模型把大量注意力倒进某个"垃圾桶"位置（通常是首 token、`[CLS]`、或视觉 token 序列的第一个），并不承载语义，只是因为 softmax 必须有地方放"多余"的概率质量。

**识别方法**（C 路用的）：算注意力图 top-2 网格行的质量占比。占比高就是下沉。

| layer | top-2 行质量 |
| --- | --- |
| 8 | 0.388（严重下沉） |
| 18 | 0.286 |
| 27 | 0.208（最轻） |

**危害**：任何"哪个区域最集中"类的指标都会选中下沉层，因为下沉本身就是极度集中的。C 路最初就是这么选到 layer 8，热区框全落在图像顶部一条横带上。

### CLS 主导

Rollout 连乘会指数级放大在每层都吸注意力的 `[CLS]`，导致归因结果里 `[CLS]` 永远是第一名，真正的语义 token 被压到中游。B 路两句的 rollout top-1 都是 `[CLS]`。

## 五、视觉侧特有概念

### ViT 的 patch

Vision Transformer 把图像切成不重叠的小方块，每块叫一个 **patch**，线性投影后当作一个 token。CLIP ViT-B/32 的 patch 是 32×32 像素，输入 224×224 → $7\times7=49$ 个 patch，加上 1 个 CLS token 共 50 个。所以注意力矩阵是 $50\times50$。

热图可视化就是把 CLS 行对 49 个 patch 的分数 reshape 回 $7\times7$，双线性上采样到 $224\times224$。

### Qwen2-VL 的 merge 与网格

Qwen2-VL 用 patch 14，再把 $2\times2$ 个 patch 合并（`merge=2`）成一个视觉 token，因此每个视觉 token 覆盖 $28\times28$ 像素。网格尺寸从 `image_grid_thw[0][1:]//merge` 得到 $(g_h,g_w)$。

视觉 token 在 `input_ids` 里是连续的占位 id `151655`，可以直接定位 span $[v_s,v_e)$。C 路用这个替代了 SAGA 原本"对解码出的字符串重新分词"的脆弱做法。

### 生成时注意力的行对齐

自回归生成时，`outputs.attentions` 是"每个生成步 × 每层"的元组：

- step 0：完整 prompt 的方阵 $(1,12,P,P)$
- step $t\ge1$：增量的一行 $(1,1,1,P+t)$（因为有 KV cache）

要得到"某个输出词看了图像哪里"，必须把这些形状不同的东西拼成一张**行对齐矩阵**：第 $p$ 行 = 预测位置 $p$ 那个 token 的注意力分布（头平均、bos 列置零、行归一化），列覆盖绝对位置 $0..P+t-1$。这就是 `build_attention_matrix` 干的事。

### hotspot / coldspot

- **hotspot（热区）**：注意力图上得分最高的固定面积框。
- **coldspot（冷区）**：在反转图 $1-m$ 上取低注意力框，且要求框中心到 hotspot 中心的距离 $\ge 0.40\times\min(g_h,g_w)$，避免两个框重叠。

框的搜索用 **积分图（integral image）**：预先算好前缀和，之后任意矩形的区域和都能 $O(1)$ 求出，于是可以暴力枚举所有"面积接近目标值"的矩形。约束条件：面积占比 `HOT_RATIO=0.15`（容差 ±10%）、长宽比 $[1.2,4.0]$、**IoU** 0.3 去重。

**IoU（Intersection over Union）** = 交集面积 / 并集面积，衡量两个框的重叠程度，超过阈值就只保留得分高的那个。

### 谱残差显著性（Spectral Residual）

Hou & Zhang (2007) 的经典无监督显著性检测，不需要任何模型。做法：对图像取 FFT 得到频谱，把对数幅度谱减去它自己的平滑版本（残差 = "意外之处"），保留相位后做逆 FFT，平方得到显著图。

**为什么用它**：C 路需要一个"客观的、与注意力无关的"参照来判断哪一层注意力最像"真正在看有意义的东西"。谱残差正好提供了这样一个外部代理。

判据是 **top-15% cell 重叠率**：注意力图取分数最高的 15% 网格，显著图也取最高的 15%，算两者交集占比。

**为什么不用 Spearman**：COCO 两张图上各层的 spearman 全是负的，符号噪声主导，无法用来投票。而 hotspot 检测本来就只消费 top-15% 的 cell，所以用重叠率更贴合下游用法。

## 六、评价指标怎么读

| 指标 | 定义 | 取值 | 怎么判读 |
| --- | --- | --- | --- |
| **Pearson 相关** | 两组数值的线性相关 | $[-1,1]$ | +1 完全同向，0 无关，−1 完全反向 |
| **Spearman 相关** $\rho$ | 两组**排名**的 Pearson | $[-1,1]$ | 只关心顺序，不关心数值大小 |
| **SSIM** | 结构相似性（亮度/对比度/结构三项） | $[-1,1]$，通常 $[0,1]$ | 1 = 两张图完全一样 |
| **质心** | $c_x=\sum x_i w_i/\sum w_i$，$w_i$ 为像素值 | 像素坐标 | 热图"重心"落在哪个物体上 |
| **top-k% 像素/cell** | 取分数最高的 k% 位置 | — | 常用于算质心或重叠率 |
| **ASR** | 攻击成功率 | $[0,1]$ | 见下节 |

**Pearson 与 SSIM 的组合读法**（A 路的关键）：

- Pearson 高 + SSIM 高 → 两张热图基本一样，说明方法**对 query 不敏感**（坏事）。
- Pearson 低/负 + SSIM 低 → 热图确实随 query 变了（必要但不充分，还得看变到哪去了）。
- 所以必须再加**质心坐标**：变化之后是不是落在了正确的物体上。

A 路正是靠这三个指标一起判：Grad-CAM 的 Pearson 更负（−0.21 / −0.63）看起来"更敏感"，但热图弥散、质心偏离目标；Chefer 的 Pearson 较高（0.67 / 0.46）但质心精确落在狗头与猫脸上。单看任何一个指标都会得出错误结论。

**SSIM = 1.0 + Pearson = NaN** 是退化信号：热图全零，两张全零图完全相同。A 路的 Grad-CAM(`ln_2`) 就是这个情况。

**统计显著性**：样本量太小时，比例差异可能纯属偶然。C 路每条件只有 9 个样本，hot 与 cold 之差仅 1 个样本（2 vs 1），因此结论只能算方向性证据。

## 七、攻击与安全术语

### 视觉提示注入 / 排版攻击

把恶意指令**渲染成图像里的文字**，让多模态模型在"看图"时读到并执行。因为绕过了文本层的输入过滤（过滤只检查字符，不检查像素），所以难防。相关综述见 [[劫持攻击]]。

- **Typographic attack（排版攻击）**：直接在图上写字。CLIP 类模型会把文字当成强语义信号。
- **对抗补丁（adversarial patch）**：一小块经过梯度优化的像素，贴到图上就能改变模型输出。

### ASR（Attack Success Rate，攻击成功率）

$$\mathrm{ASR}=\frac{\#\{\text{被劫持样本}\}}{\#\{\text{该条件有效样本}\}}$$

**判定方式决定结论可信度**。C 路用的是"输出小写化后包含目标关键词"的子串匹配，这个判定有一个必须区分的漏洞：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| **感知型（perceive）** | 模型只是把图里的文字**读**了出来，并未服从 | 问"图里有什么"，答"…with a 'Access Granted' sign" |
| **服从型（obey）** | 模型真的**执行**了注入的指令 | 注入"reply with CAT"，模型把狗说成 "A white cat" |

子串匹配会把两者都算成劫持，从而系统性高估攻击效果。C 路 3 例劫持里只有 1 例是服从型。

### Surrogate model 与 PGD

- **Surrogate model（替代模型）**：黑盒攻击时，攻击者拿不到目标模型的梯度，于是找一个结构相似的开源模型（如 CLIP）来算梯度，再把结果迁移过去。
- **PGD（Projected Gradient Descent）**：最常用的白盒对抗样本生成法，沿梯度方向迭代扰动，每步投影回允许的扰动范围内。

C 路**没有**复现 ATPI 的 CLIP surrogate + PGD 部分，因为那与"注入位置是否影响劫持率"这个核心假设正交，且需要独立的优化管线。

### 黑盒 / 白盒

- **白盒**：攻击者知道模型权重，可求梯度。
- **黑盒**：只能查询模型看输出。SAGA 声称是黑盒设置——它只用一个开源 LVLM 提取一次注意力图，然后攻击别的模型。

## 八、实验设计术语

### Winograd 探针与最小对比对

**Winograd 模式**（Winograd Schema）是一对只差一个词、但代词指代对象随之翻转的句子：

- `The animal didn't cross the street because it was too tired` → `it` = animal
- `The animal didn't cross the street because it was too wide` → `it` = street

**最小对比对（minimal pair）**的价值：除了那一个形容词，其他一切都相同。所以如果归因方法可靠，它对 `animal` 和 `street` 的打分高低**必须**随形容词翻转。不翻转就是方法失效，无从辩解。

术语：

- **gold**：正确的指代对象。
- **distractor**：干扰项，即另一个候选。
- **gold/dist 比值**：> 1 表示方向正确，< 1 表示方向反了，= 1 表示完全没有区分度。

### Cloze 探针（完形填空探针）

把某个位置换成 `[MASK]`，看模型给各个候选词的概率。这是**判断模型自己会不会做这道题**的方法，与归因方法无关。

B 路先做这一步的原因很关键：如果模型本身就没解出指代，那归因方法失败就不奇怪。**结果模型解得很好**（BERT 比值 60.13 / 28.46，RoBERTa 469.20 / 4210.89），所以后续归因方法的失败只能怪方法本身。

### 消融实验（ablation）

去掉方法的某个组成部分，看性能掉多少，用来证明这个组成部分是必要的。A 路把 Chefer 的逐层 rollout 换成"只用最后一层"（`start_layer=-1`），SSIM 从 0.8338 掉到 0.5574，说明逐层传播确实有必要。

### Sanity check（合理性校验）

用一条已知答案的路径验证实现是否正确。B 路做了六项，例如：

- $L=1$ 时 attention flow 应当严格等于行归一化的 $(W+I)$（有闭式解）
- networkx 与 scipy 两套最大流实现结果应当一致（实测差 1.4e-07）
- $\sum_j\alpha_{ij}f(x_j)+b_O$ 应当精确重构真实注意力输出（实测差 2.0e-06）
- 手工从原始权重重算 encoder，应当与 HuggingFace 输出一致（实测 hidden L2 差 1.4e-05）

**所有误差都在 float32 噪声量级**，这才排除了"结果是实现 bug"的可能，让"flow 真的退化了"这个结论站得住。

### 头平均（head averaging）

把 12 个头的注意力矩阵直接取平均。这是很强的简化，会掩盖单头的特异行为。B 路为此额外做了**逐头实验**：12 个头的 gold 份额落在 $[0.4793,0.5454]$，均值 0.5083——说明 flow 的退化不是头平均造成的，单头同样饱和，无法靠"挑出好头"解决。

## 九、工程与环境术语

| 术语 | 含义 |
| --- | --- |
| **conda 环境** | 隔离的 Python 依赖集合。本次统一用 `attn-repro`，解释器 `D:\Env\minConda\envs\attn-repro\python.exe` |
| **HF_HOME / HF_HUB_CACHE** | HuggingFace 权重缓存目录的环境变量。重定向到 `D:\checkpoints\hf` 避免占满 C 盘 |
| **bf16 / float32** | 数值精度。bf16 省一半显存但精度低；float32 数值确定性好。B 路用 float32 保证最大流可复现，C 路用 bf16 才装得下 |
| **显存峰值** | 运行过程中占用的最大 GPU 内存。C 路实测 5.15 GB（上限 8 GB） |
| **forward / backward hook** | PyTorch 的回调机制，在模块前向/反向时截获中间张量。Chefer 方法依赖 backward hook 抓 $\nabla A$，因此**前向不能包在 `torch.no_grad()` 里，权重也不能 `requires_grad_(False)`**，否则 hook 注册失败 |
| **sm_120** | RTX 5060 的 CUDA 计算能力代号。装 PyTorch 时必须选支持该架构的版本（本次 cu130） |
| **materialise** | 把注意力矩阵真的算出来存进显存，与融合 kernel 的"算完即弃"相对 |
