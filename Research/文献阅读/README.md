# 文献阅读

这里按研究主题整理文献与阅读报告。PDF 统一由 Zotero 管理，Obsidian 只保留综述、研究观察和可编辑的阅读报告。

## 当前分区

- `主题综述`：自己写的概念梳理，如 `劫持攻击`、`越狱攻击`。
- `文献阅读报告.md`：文献索引、Zotero 条目关联和精读记录入口。
- `排版攻击`：Typographic attack、FigStep、SceneTAP、JailGuard 等。
- `视觉提示注入`：图像/物理提示注入相关论文。
- `Agent安全`：与智能体相关的视觉提示注入或安全研究。
- `VLA与注意力劫持`：VLA 攻击、注意力劫持等方向。
- `参考资料`：目录、榜单、辅助性资料。

## 后续建议

- 新论文优先按主题放，不再按“随手建一个文件夹”归档。
- 如果一篇论文同时属于多个方向，优先放到最核心主题，避免重复保存多个副本。
- 当某个方向累计到 8 到 10 篇以上时，再考虑继续细分子目录。
- PDF 已迁移到 Zotero，后续优先在 Zotero 中阅读和批注，在本文件中沉淀研究结论。
