# Research

这个目录现在按“文献阅读”和“组会与实验”两条主线整理：

- `文献阅读`：按研究主题归档 PDF 与主题综述，适合做长期积累。
- `组会与实验`：按时间和用途整理组会记录、实验规划、部署说明与附件，适合跟踪当前项目推进。

## 目录说明

### 文献阅读

- `主题综述`：自己写的概念梳理和方向总结。
- `排版攻击`：Typographic attack / FigStep / SceneTAP 等相关论文。
- `视觉提示注入`：图像提示注入、物理提示注入等方向论文。
- `Agent安全`：与 agent / multimodal agent 相关的安全论文。
- `VLA与注意力劫持`：与 VLA、attention hijacking 相关的论文。
- `参考资料`：CCF 目录等辅助资料。

### 组会与实验

- `组会汇报`：按年份归档正式组会记录。
- `实验规划`：实验思路、计划、配置草稿。
- `工具部署`：环境配置、工具接入和实现细节说明。
- `附件`：PPT、图片等非 Markdown 材料。

## 维护约定

- 正式汇报统一按 `YYYY-MM-DD-组会汇报.md` 命名。
- 实验计划和调研笔记尽量使用“日期 + 主题”命名，避免再次出现 `1.md`、`未命名.md` 这类文件。
- 图片、PPT、PDF 等附件不直接散落在根目录，统一放到相应主题目录或 `附件` 中。
