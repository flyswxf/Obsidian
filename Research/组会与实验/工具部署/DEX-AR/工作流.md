## 流程总览

| 阶段       | 脚本                          | 节点            | 环境    | 主要产物                                  |
| -------- | --------------------------- | ------------- | ----- | ------------------------------------- |
| 0. 代码同步  | git                         | 登录节点          | —     | 集群工作区与本地同一提交                          |
| 1. 单图 dry-run | `repro_dexar.py`            | GPU 计算节点（Slurm） | `dexar` | 句级 / 逐 token 热图 PNG、`.npy`、`metrics.json` |
| 2. 生成 manifest | `tools/make_voc_manifest.py` | 登录节点          | `dexar` | `voc_manifest.json`                   |
| 3. 批量复现   | `repro_dexar.py --manifest` | GPU 计算节点（Slurm） | `dexar` | 多图热图与聚合 `metrics.json`                 |

数据流：

```text
图像 + 目标句（或模型自生成回答）+ 提示模板
    ↓ compute_dexar：逐 token 前向 + logit lens 梯度 + 动态头过滤
句级热图（filtered / unfiltered）+ 逐 token 热图 + token 权重 δ_t
    ↓ repro_dexar.py
repro_outputs/<时间戳>/ 下 PNG + .npy + metrics.json
```

## 使用方式（输入与输出）

DEX-AR 是**解释器**而非生成器：给定图文，输出「模型在生成指定文本时依赖图像哪些区域」的热图。核心调用只有三步：

```python
from dexar import DexarWrapper, visualize

model = DexarWrapper.from_pretrained("llava-hf/llava-1.5-7b-hf", device="cuda")

result = model.compute_dexar(
    image=image,                 # PIL.Image，resize 到 336x336
    target_sentence="...",       # 要解释的句子
    prompt="USER: <image>\nDescribe the image. ASSISTANT:",
)
visualize(image=image, heatmap=result.sentence_heatmap, title="Sentence heatmap")
```

输入：

| 项 | 说明 |
| --- | --- |
| `image` | PIL.Image，官方样例统一 resize 到 $336\times336$ |
| `target_sentence` | **要解释的句子**，逐 token 用 teacher forcing 喂入 |
| `prompt` | 含 `<image>` 占位的模板，默认 `USER: <image>\nDescribe the image. ASSISTANT:` |
| `layer_index` | 加载时设定，梯度起始层（负值从末层倒数）；默认 `-10`，官方 `playground.py` 用 `0`（全部层） |

`target_sentence` 有三种来源：官方样例写死；模型自身贪心回答（`repro_dexar.py` 未传 `--target` 时自动生成）；人为指定（如攻击场景的目标句）。

`compute_dexar` 返回 `DexarResult`：

| 字段                              | 形状            | 含义                                                                    |
| ------------------------------- | ------------- | --------------------------------------------------------------------- |
| `per_token_heatmaps`            | `[T, 24, 24]` | 逐 token 热图（含头过滤 $w_{l,t,i}=(S_{\text{img}}-S_{\text{text}})^{+}$，式 5） |
| `per_token_heatmaps_unfiltered` | `[T, 24, 24]` | 逐 token 热图（无头过滤）                                                      |
| `token_weights`                 | `[T]`         | 每 token 视觉相关性权重 $\delta_t$（式 6）                                       |
| `sentence_heatmap`              | `[24, 24]`    | 句级热图（过滤版，最常用）                                                         |
| `sentence_heatmap_unfiltered`   | `[24, 24]`    | 句级热图（未过滤，作对照）                                                         |
| `tokens`                        | `list[str]`   | 解码后的 token 字符串，与逐 token 热图对齐                                          |

图像 token 网格固定为 $576=24\times24$。

## 1. 单图 dry-run

默认跑官方样例 `assets/cat_and_dog.jpg`，目标句由模型贪心生成：

```bash
cd /public/home/yhhao/wyf/DEX-AR
sbatch jobs/repro.sbatch
```

指定固定目标句（复刻官方样例）：

```bash
sbatch --export=ALL,TARGET="The image features a dog and a cat sitting together in a grassy field" \
  jobs/repro.sbatch
```

指定图像与选层：

```bash
sbatch --export=ALL,IMAGES="assets/cat_and_dog.jpg",LAYER_INDEX=0 jobs/repro.sbatch
```

监控与日志：

```bash
squeue -u "$USER"
tail -f logs/slurm-<jobid>.out
```

`jobs/repro.sbatch` 可覆盖的环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DEXAR_ENV` | `dexar` | conda 环境名 |
| `LAYER_INDEX` | `0` | 梯度起始层 |
| `OUT` | `/public/home/yhhao/wyf/DEX-AR-runs` | 产物根目录 |
| `IMAGES` | `assets/cat_and_dog.jpg` | 空格分隔的图像路径 |
| `TARGET` | 空 | 固定目标句；不设则由模型生成 |
| `MANIFEST` | 空 | 传 manifest 时优先于 `IMAGES` |

## 2. 生成 VOC manifest

批量复现用 PascalVOC2012 标注生成清单，`--pairs` 每项格式为 `类名:id`，取该类首个目标框并归一化到 $[0,1]$：

```bash
cd /public/home/yhhao/wyf/DEX-AR
python tools/make_voc_manifest.py \
  --voc "/public/home/yhhao/wyf/VOCdevkit/VOC2012" \
  --pairs dog:2008_000019 cat:2008_000060 bicycle:2008_000036 aeroplane:2008_000033 \
  --out voc_manifest.json
```

每项形如：

```json
{"image": ".../JPEGImages/2008_000019.jpg", "target": "This is a photo of a dog.", "bbox": [0.31, 0.05, 0.78, 0.97]}
```

## 3. 批量复现

```bash
cd /public/home/yhhao/wyf/DEX-AR
sbatch --export=ALL,MANIFEST=/public/home/yhhao/wyf/DEX-AR/voc_manifest.json,OUT=/public/home/yhhao/wyf/DEX-AR-runs \
  jobs/repro.sbatch
```

`repro_dexar.py` 会先对首图补一次纯前向画像（`plain_forward_seconds`），再逐图计算，最后写聚合 `metrics.json`。产物结构：

```text
/public/home/yhhao/wyf/DEX-AR-runs/<时间戳>/
├── metrics.json                  # 逐图记录 + 跨图聚合
├── <tag>_sentence_filtered.png / .npy
├── <tag>_sentence_unfiltered.png / .npy
├── <tag>_per_token_filtered.png
└── <tag>_per_token_unfiltered.png
```

`metrics.json` 聚合字段：`mean_top10_mass_filtered/unfiltered`、`mean_entropy_filtered/unfiltered`、`filtered_sharper_frac`，以及有 bbox 时的 `filtered_peak_hit`/`unfiltered_peak_hit`、`mean_mass_in_bbox_filtered/unfiltered`。

> [!warning] 产物不入库
> PNG、`.npy`、`metrics.json` 均为实验产物，`.gitignore` 已排除 `repro_outputs` 与 runs 目录，不要提交。

## 故障定位顺序

1. 是否在 GPU 计算节点；登录节点无 GPU，加载模型会失败。
2. 计算节点是否设置 `HF_HUB_OFFLINE=1` 与 `TRANSFORMERS_OFFLINE=1`（作业脚本已内置）。
3. 换 `--layer-index` 或提示模板后，同一次运行的 `metrics.json` 会混在一起，需换 `OUT` 目录。
4. 同步报错先查 SSH 连通性与 bare 仓库路径，不反复重试。
