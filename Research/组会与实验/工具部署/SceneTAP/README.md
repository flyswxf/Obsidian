SceneTAP 是一套面向视觉语言模型的场景一致性排版攻击方案。它先寻找适合植入文字的场景区域，再把攻击短文本自然地渲染进原图，用于研究视觉指令注入的有效性。

## 工具组成

- **SceneTAP**：串联区域定位、攻击规划、图像渲染与效果评估。
- **SoM**：结合 SEEM、SAM 和 Semantic-SAM 分割图像，回答“文字放在哪里”。
- **TextDiffuser-2**：根据攻击规划在目标区域生成文字，回答“文字怎样融入场景”。
- **DashScope/Qwen**：在登录节点完成攻击规划和结果评估。
- **Kaggle 实验环境**：读取 SceneTAP 生成的攻击图，继续执行 LLaVA 推理、注意力提取和 Patch 对照实验。

环境版本、依赖、模型权重和 Deformable 算子兼容修改统一记录在[[部署]]中。实际运行时按照[[工作流|完整工作流]]区分登录节点与 GPU 计算节点，避免在登录节点执行模型推理。
