> 由于计算节点无法联网, 拆分成三阶段

1. 登录节点联网规划：
```bash
python plan_attacks.py \
  --dataset typo_base_color \
  --image-folder "/public/home/yhhao/wyf/Typographic Dataset v2/Typographic Dataset Base/color-r0" \
  --question-file ./tables/typo_base/color_r0_questions_50.json \
  --slider 3 \
  --filter 12 \
  --seed 42 \
  --planner-model qwen3.7-plus \
  --planner-base-url "https://dashscope.aliyuncs.com/compatible-mode/v1" \
  --planner-api-key "$DASHSCOPE_API_KEY" \
  --output-file ./attack_plans/color_r0_plans_50.json \
```

2. 计算节点离线渲染：
```bash
python render_attacks.py \
  --plan-file ./attack_plans/color_r0_plans_50.json \
  --render-base-dir ./attack_renders/50
```

3. 登录节点联网测试：
```bash
python evaluate_attacks.py \
  --render-file ./attack_renders/50/typo_base_color/slider_3.0/filter_12.0/seed_42/renders.json \
  --model qwen3.7-plus \
  --base-url "https://dashscope.aliyuncs.com/compatible-mode/v1" \
  --api-key "$DASHSCOPE_API_KEY" \
  --log_dir ./log
```

> 建议把真实密钥放在环境变量里，例如 `export DASHSCOPE_API_KEY=...`，不要直接写进仓库笔记。
