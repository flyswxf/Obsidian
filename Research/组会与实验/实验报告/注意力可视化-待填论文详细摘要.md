### **研究问题与动机**

CLIP 依靠大规模图文对比学习对齐图像与文本表示，广泛用于零样本分类、开放词表检测，并作为 LLaVA、DALL-E 等大模型的即插即用组件 #文献 Zotero key QYEMZ8KF。然而其视觉编码器可解释性不佳：Simple Gradient 与 Grad-Cam 显著性图噪声大、近似随机，且编码器内的概念探测器数量有限 #文献 Zotero key QYEMZ8KF。作者将原因部分归于 ViT 的固有性质，部分归于对比学习中假阴性样本导致的不光滑性（non-smoothness）#文献 Zotero key QYEMZ8KF。

由于 CLIP 视觉编码器常被当作下游任务的插件，提升其可解释性对医疗诊断、自动驾驶等高风险决策意义重大 #文献 Zotero key QYEMZ8KF。已有工作表明对抗训练（AT）能抑制无关特征、强化判别性特征，但多局限于单模态分类设置，且 AFT 对可解释性的效果是否具备零样本泛化性、能否迁移到下游任务尚不清楚 #文献 Zotero key QYEMZ8KF。论文因此系统研究 AT 与 CLIP 视觉可解释性的关系，并采用计算开销更小的对抗微调（AFT）而非从头训练 #文献 Zotero key QYEMZ8KF。

### **方法**

AFT 在语言-图像对比学习框架下定义目标函数，令 $x$、$I_x$、$T_x$ 分别为输入图像、其图像嵌入与配对文本嵌入（$I_x$ 与 $T_x$ 已归一化为单位长度，相似度为 $T_x^\top I_x$）#文献 Zotero key QYEMZ8KF。目标是让微调后的图像编码器 $f_\theta(\cdot)$ 对微小扰动鲁棒，即使加扰动前后图文相似度基本不变 #文献 Zotero key QYEMZ8KF：

$$\min_\theta \mathbb{E}_{x\sim D_{train}} \max_{\delta_x} \frac{1}{2}\left(T_x^\top \mathbb{E}_{z\sim N(0,\sigma^2 I)}[f_\theta(x+z+\delta_x)] - T_x^\top I_x\right)^2 - h(\delta_x). \tag{1}$$

其中平方损失项促进对扰动的鲁棒性，正则项 $h(\cdot)$ 保证扰动不可感知；对原函数加入高斯平滑（Gaussian Smoothing），以避免停在预训练原参数这一非平凡驻点，并提升损失的光滑性 #文献 Zotero key QYEMZ8KF。

对式 (1) 取一阶泰勒近似可得式 (2)，其中 $\omega_x=|T_x^\top \mathbb{E}_{z\sim N(0,\sigma^2 I)}[f_\theta(x+z)] - T_x^\top I_x|$ #文献 Zotero key QYEMZ8KF。定理 1 给出两者最优扰动的相对误差上界：对任意 $\mu$-强凸的 $h(\cdot)$，

$$\left\|\delta^*_{1\theta}(x) - \delta^*_{2\theta}(x)\right\| / \left\|\delta^*_{1\theta}(x)\right\| \le \frac{5}{2\mu\sigma^2}, \tag{3}$$

说明在合理的 $\mu\sigma^2$ 下式 (2) 是式 (1) 的良好近似 #文献 Zotero key QYEMZ8KF。

**与 SmoothGrad／输入梯度的等价关系：** 借助 Fenchel 共轭 $h^\star(\cdot)$，式 (2) 可改写为 $\min_\theta \mathbb{E}_{x\sim D_{train}} m_x(0) + h^\star\!\left(\omega_x \nabla_x \mathbb{E}_{z\sim N(0,\sigma^2 I)}[T_x^\top f_\theta(x+z)]\right)$ #文献 Zotero key QYEMZ8KF。括号内的梯度项正是相似度对输入的 **SmoothGrad**，因此 AFT 等价于对输入梯度的隐式正则，且由 $h^\star(\cdot)$ 施加 #文献 Zotero key QYEMZ8KF。

**范数正则项与稀疏显著性：** 为诱导稀疏显著性，取 $h^\star$ 为 L1 范数的平滑版本（Huber 形式）#文献 Zotero key QYEMZ8KF：

$$h^\star(u) = \varepsilon \sum_i H_\eta(u_{(i)}), \quad H_\eta(u_{(i)}) = \begin{cases} \frac{1}{2\eta} u_{(i)}^2, & |u_{(i)}| \le \eta \\ |u_{(i)}| - \frac{\eta}{2}, & \text{otherwise}, \end{cases} \tag{4}$$

其对应的 $h(\cdot)$ 为强凸函数：

$$h(v) = \begin{cases} \frac{\eta}{2\varepsilon}\|v\|^2, & \|v\|_\infty \le \varepsilon \\ +\infty, & \text{otherwise}, \end{cases} \tag{5}$$

其中 $\varepsilon>0$ 控制正则强度，$\eta$ 决定 $h^\star$ 的光滑度进而决定 $h$ 的凸性 #文献 Zotero key QYEMZ8KF。**诱导稀疏显著性的机制**：该稀疏正则迫使视觉编码器只关注少量关键输入特征，一方面缓解显著性图的噪声、提升视觉质量，另一方面提升概念编码阶段的简洁性，使概念结构可能架构无关，从而让视觉编码器的推理过程更可解释 #文献 Zotero key QYEMZ8KF。

**无监督上界最小化与只调图像编码器：** 式 (1) 需计算文本嵌入 $T_x$，既昂贵又要求图文配对数据 #文献 Zotero key QYEMZ8KF。作者发现内层最大化项存在一个不含文本嵌入的一致上界，于是改为最小化该上界 #文献 Zotero key QYEMZ8KF：

$$\min_\theta \mathbb{E}_{x\sim D_{train}} \max_{\delta_x} \frac{1}{2}\left\|\mathbb{E}_{z\sim N(0,\sigma^2 I)}[f_\theta(x+z+\delta_x)] - I_x\right\|^2 - h(\delta_x). \tag{7}$$

此时目标变为「扰动图像嵌入」与「原始图像嵌入」之间的 L2 距离，可绕过文本编码器 #文献 Zotero key QYEMZ8KF。观察 1 进一步说明：若 $\|\mathbb{E}_{z\sim N(0,\sigma^2 I)}[f_\theta(x+z)] - I_x\| \le \lambda$，则 $|T_x^\top \mathbb{E}_{z\sim N(0,\sigma^2 I)}[f_\theta(x+z)] - T_x^\top I_x| \le \lambda$，故微调后的图像编码器仍与原始文本编码器、以及用它调过的下游大模型兼容 #文献 Zotero key QYEMZ8KF。框架可推广到任何以中间嵌入连接模态的基础模型 #文献 Zotero key QYEMZ8KF。代码实现与本方法一致：仅微调 `visual` 编码器，文本编码器冻结，损失为对抗扰动嵌入与原始嵌入的平方 L2（`loss='l2'`，`inner_loss='l2'`，即式 (7) 的无监督形式）#代码事实 D:\code\CLIP_AFT\train\adversarial_training_clip.py。

作者自述贡献有三 #文献 Zotero key QYEMZ8KF：(1) 提出带范数正则的无监督 AFT，迫使预训练 CLIP 稀疏编码视觉特征、提升视觉可解释性；(2) 理论证明对抗扰动正则范数与输入梯度之间的对偶关系，解释 AFT 为何提升可解释性；(3) 通过大量定量与定性实验证明 AFT 提升 CLIP 及其派生大视觉语言模型的可解释性。结论：AFT 使 CLIP 视觉编码器更聚焦显著输入特征、神经元与人类可理解概念对齐更好，效果可泛化到分布外数据并迁移到下游任务 #文献 Zotero key QYEMZ8KF。作者也给出限制：仅用单一数据集微调，未研究数据量与多样性影响，未探索不同极小极大优化算法 #文献 Zotero key QYEMZ8KF。

### **契合判定**

- **同类性——不符合需求。** 本方法改造对象是 CLIP 的视觉编码器；CLIP 是对比／分类式模型，而非「生成式、产出文本」的 decoder-only VLM #文献 Zotero key QYEMZ8KF。论文虽在 4.3 与附录 A.4 将 AFT 后的 CLIP 视觉编码器接入 LLaVA 等做可视化与定量，但那是把 CLIP 当作被替换的插件组件，方法本身并未面向生成式多模态模型的生成过程 #文献 Zotero key QYEMZ8KF。
- **迁移便利性与通用性——需改造（且代价高）。** 论文声明框架可推广到任何「以中间嵌入连接模态」的基础模型，并在附录 A.4 演示对监督式 ViT-B、医学图文模型 MONET、GLoRIA 的适用，也把 AFT-CLIP 接入 LLaVA #文献 Zotero key QYEMZ8KF。改造点明确：属于**训练时改造模型权重**而非免训练的后验归因；需要可微的图像嵌入 L2 目标（式 (7)，无监督版无需文本编码器），访问的是图像编码器输出的**嵌入张量**而非注意力张量；需重训／微调视觉编码器（PGD 10 步、ImageNet 2 epoch，ViT-L-14 约 94.28h／4 GPU），不改结构、不新增参数、推理成本不变，但会改变模型权重并带来 clean 精度下降 #文献 Zotero key QYEMZ8KF #代码事实 D:\code\CLIP_AFT\train\adversarial_training_clip.py。
- **契合度——仅与 `vision_attention_raw` 相关，与 `cross_attention_raw` 关系弱。** AFT 直接改变 CLIP ViT 最后一层 CLS→patch 自注意力（图 4 显示 AFT 后注意力图更细粒度），因此与 `vision_attention_raw`（CLIP ViT CLS→patch 自注意力）契合度高 #文献 Zotero key QYEMZ8KF。但项目主用的 `cross_attention_raw`（LLaVA 逐生成步「当前 query token→图像 patch」）在论文中并未给出可迁移的度量口径；论文的 LLaVA 分析是把 LLM 注意力与 ViT 注意力**加权组合**成一张复合图再做 PG 等评估，属于后处理可视化而非直接度量逐生成步 query→patch 分量 #文献 Zotero key QYEMZ8KF。

**一句话结论：不符合需求。** 本方法是对比式 CLIP 的「训练时权重改造」，而非面向生成式多模态模型的「免训练注意力度量口径」；它只与 `vision_attention_raw` 信号相关、需重训且改变权重并掉 clean 精度，无法直接用作研究 LLaVA 对抗文本贴片「位置」变量的注意力度量口径 #文献 Zotero key QYEMZ8KF #猜想。

### **论文信息**

- arXiv 编号：arXiv:2506.18985v3 [cs.CV]，2025-07-29

### **研究问题与动机**

现代生成式大视觉语言模型（LVLM）能依据图像与提示词自回归地生成多句、自由形式的答复，但其内部「究竟把视觉注意投向何处」依旧不透明。可解释性对暴露虚假相关、揭示偏见与幻觉、理解模型行为至关重要；VQA 的人类注视研究还表明，学到的注意力与人类注视越吻合的模型往往准确率越高 #文献 ATGW7RFS。

论文指出，现有解释方法在生成式 LVLM 上普遍不足：基于注意力的方法（原始 cross-attention、Attention Rollout）高效但噪声大、缺乏因果性；基于梯度的方法（Gradient×Input、Grad-CAM、Integrated Gradients）受梯度破碎影响，热图零散；LRP 类方法实现复杂、收益有限；扰动/迭代方法（SHAP、PixelSHAP、iGOS++）计算开销大、难扩展到长序列，且多只给标签级或 token 级归因 #文献 ATGW7RFS。作者归纳出四个专属于生成式 LVLM 的挑战：多句解码要求跨整段序列聚合、视觉与文本 token 交错纠缠、深层堆叠放大噪声、长上下文使扰动类方法不可行 #文献 ATGW7RFS。因此需要一个轻量、整体（holistic）、序列级、跨模态的归因框架，GLIMPSE 即为此设计。

### **方法**

GLIMPSE 是一个「梯度 × 注意力」框架，把模型输入拼成一条因果序列 $x=[v_{1:K}\,\|\,p_{1:M}\,\|\,y_{1:T}]$，总长 $N=K+M+T$，用索引集 $V,P,Y$ 分别标记图像 token、提示 token、生成 token #文献 ATGW7RFS。设第 $l$ 层第 $h$ 头的注意力矩阵为 $A_l^h\in\mathbb{R}^{N\times N}$，目标 token $t$ 的 logit 对该注意力的梯度为 $g_l^h=\partial z_t/\partial A_l^h$。方法分三阶段。

（1）**Layer Relevance Extraction（梯度加权注意力）**。先对每头做逐元素正梯度加权，突出「既被强注意、又受正向回传」的位置：

$$G_l^h = \mathrm{ReLU}\!\left(g_l^h \odot A_l^h\right)$$

不同于 TMME 的均匀头平均，这里给每头一个全局权重，用其梯度加权注意力与正梯度总质量之比衡量头的贡献：

$$w_l^h = \mathrm{softmax}\!\left(\frac{1}{\lambda}\cdot \frac{\sum_{i,j} G_l^h(i,j)}{\sum_{i,j}\mathrm{ReLU}\left(g_l^h(i,j)\right)}\right)$$

该比值等于「在正梯度分布下注意力的期望」，只在头把注意力集中于梯度相关位置时才大。随后按头加权融合、逐行归一化：

$$E_l = \sum_{h=1}^{H} w_l^h G_l^h$$

（2）**Adaptive Layer Propagation（自适应层传播）**。用层梯度 L1 范数量化层重要性 $g_l=\sum_{h=1}^{H}\lVert g_l^h\rVert_1$，再叠加一个偏向深层的深度先验：

$$s_l = \frac{\exp\!\left(\lambda_d(l+1)\right)}{\sum_{k=1}^{L}\exp\!\left(\lambda_d(k+1)\right)}$$

两者相乘归一化得层权：

$$\alpha_l = \frac{g_l\,s_l}{\sum_{k=1}^{L} g_k\,s_k}$$

从而让强梯度信号能在必要时覆盖深度先验。对每个生成 token，初始化运行相关性矩阵 $R\leftarrow I_N$，并构造逐层变换 $L_l = I_N + \alpha_l E_l$，采用加性累积而非全层矩阵连乘以抑制噪声：

$$R \leftarrow R + L_l R$$

最终 $R\in\mathbb{R}^{N\times N}$ 统一刻画跨模态交互，行 $R_{t,:}$ 给出 token $t$ 对所有模态元素的相关性。

（3）**Cross-Modal Token Relevancy（相关性加权 token 聚合）**。为抑制无意义/幻觉 token 稀释证据，引入三类权重。提示对齐 $a_t=\frac{1}{|P|}\sum_{i\in P}R(t,i)$、视觉对齐 $v_t=\frac{1}{|V|}\sum_{i\in V}R(t,i)$、以及置信度 $p_t=\frac{\exp(z_t)}{\sum_{w\in\Omega}\exp(z_w)}$。综合权重为

$$\beta_t^{(m)} = \frac{p_t\,w_t^{(m)}}{\sum_{k\in Y} p_k\,w_k^{(m)}},\quad w_t^{(m)}=\begin{cases}a_t, & m=V\\ v_t, & m=P\end{cases}$$

即 token 对模态 $m$ 显著性图的贡献由「与互补模态的对齐」再受「预测置信度」调制。跨模态联合相关性取几何平均：

$$\gamma_t = \sqrt{\beta_t^{(V)}\times \beta_t^{(P)}}$$

它同时识别出既强提示对齐、又有视觉落地的 token。另有可选的 **relevance flow redistribution**：把功能词（如 is、of）的相关性按归一化流向 $F_{i\to j}=\frac{R(j,i)}{\sum_{k>i}R(k,i)}$ 转移到其句法关联的实词上（$\beta_t^{(m)\prime}=\beta_t^{(m)}+\lambda_f\sum_{i<t} f_{i\to t}$），仅用于提升 token 可读性，故意不参与最终聚合。

（4）**Holistic Saliency Aggregation**。用 $\beta_t^{(m)}$ 聚合各 token 的模态相关性向量，得到 response 级的视觉显著图与提示显著图：

$$\tilde R^{m} = \sum_{t\in Y}\beta_t^{(m)}\,R(t,m)$$

其中 $\tilde R^{V}$ 把每 patch、经提示条件化的相关性投影回原图，给出最关键的图像区域（即跨模态空间热图）；$\tilde R^{P}$ 量化各提示 token 对模型聚焦的贡献；$\gamma_t$ 给出每个生成 token 的跨模态相关性。三者合起来构成「图像区域—提示语义—输出 token」的统一解释范式 #文献 ATGW7RFS。

计算成本：完整解释需 **一次前向**（生成响应并抽取注意力张量）＋ **每个生成 token 一次反向**（算梯度）#文献 ATGW7RFS。

### **研究问题与动机**

核心问题：LVLM 生成开放式回答时究竟「看」图像的哪些区域，以及回答在多大程度上依赖视觉输入。既有显著性/热图解释方法多针对单标签输出或句内单个 token，无法处理 LVLM 自回归生成的、变长、开放式的整段回答，需要的是一个对整段输出整体的「全局解释」。论文指出三大挑战：一是视觉—语言交互复杂，模型存在强语言先验，难以判断各模态对回答的贡献；二是自回归生成使整段输出的解释困难；三是当前 LVLM 常用多分辨率或多编码器结构，跨层特征难以可靠对齐回图像空间区域。动机在于：关注区域可揭示答案为何正确或错误，从而指导模型改进，而仅看准确率不足以反映模型能力（论文举出「关注正确区域却答错」「关注无关区域却答对」等情形）。论文声称这是首个适用于任意 LVLM 结构、且能为开放式回答生成全局解释的热图可视化方法 #文献 Zotero key VAI8N77N。

### **方法**

方法把图像显著性解释建模为对图像掩码 $M$ 的优化问题，基础是优化式热图方法 iGOS++（Integrated Gradient Optimized Saliency）。给定图像 $I$ 与问题 $Q$，模型自回归地产生答案：

$$a_t \sim P(a_t \mid a_1, a_2, \dots, a_{t-1}; I, Q)$$

扰动合成由原图 $I$ 与无视觉信息的基线图 $\tilde I$（如全模糊图）按掩码混合：

$$\Phi(I, \tilde I, M) = I \odot M + \tilde I \odot (1 - M)$$

iGOS++ 含两个目标：删除（deletion）按掩码值逐步移除像素以最小化预测分数 $f$，插入（insertion）从基线图按掩码值逐步恢复像素以最大化 $f$。两掩码版目标为

$$\min_{M=(M_x,M_y)} f(\Phi(I,\tilde I,M_x)) - f(\Phi(I,\tilde I,1-M_y)) + f(\Phi(I,\tilde I,M)) - f(\Phi(I,\tilde I,1-M)) + g(M)$$

其中 $g(M)=\lambda_1\lVert 1-M\rVert_1 + \lambda_2 \mathrm{BTV}(M)$，前者促稀疏，后者（Bilateral Total Variation）促平滑 #文献 Zotero key VAI8N77N。

适配 LVLM 的关键改动有以下三点。

（1）视觉相关 token 选择：LVLM 不天然给出标量预测分数，且变长回答中各 token 与图像相关性差异极大（句法可推断的 token、词内子词 token 对图像基本不敏感）。为此用对数似然比 LLR 度量每个 token 对视觉信息的依赖：

$$\mathrm{LLR} = \log P(a\mid I,Q) - \log P(a\mid \tilde I,Q) = \sum_t \log P(a_t\mid a_{<t}) - \sum_t \log \tilde P(a_t\mid a_{<t})$$

$\tilde P$ 通过把 $Q$ 与 $a$ 拼接为文本 prompt 单次前向即可得到。筛选出最依赖视觉的关键 token 集合

$$K=\{a_k \mid \mathrm{LLR}_k>\alpha,\ k\neq 1\}$$

并把预测分数定义为关键 token 的累计对数似然

$$f=\sum_{a_k\in K}\log P(a_k\mid a_1\dots a_{k-1})$$

如此只让回答中与视觉相关的部分参与解释，滤除语言结构带来的影响 #文献 Zotero key VAI8N77N。

（2）非凸优化的稳定化：为缓解散乱注意力图导致的收敛困难，把删除与插入的两掩码合并为单一掩码 $M$ 联合优化；并引入渐进非凸（GNC, graduated non-convexity）——从凸近似起步、逐步加入非凸性，具体为加入指数衰减的 $L_2$ 项：

$$\min_{M} f(\Phi(I,\tilde I,M)) - f(\Phi(I,\tilde I,1-M)) + g(M)$$

$$g(M)=\lambda_1\lVert 1-M\rVert_1 + \lambda_2 e^{-\gamma t}\lVert 1-M\rVert_2 + \lambda_3 \mathrm{BTV}(M)$$

论文默认取 $\lambda_1=1,\ \lambda_2=0.1,\ \lambda_3=10$ #文献 Zotero key VAI8N77N。

（3）适配多编码器/多分辨率结构：对多编码器，在送入所有编码器之前施加同一张统一掩码，保证各特征提取器一致；对多分辨率，原始裁剪操作基于 pillow/numpy、不可微，改写成等价的、纯张量的可微裁剪，使掩码与图像块经历相同变换，从而保持优化可微 #文献 Zotero key VAI8N77N。

全局解释热图：优化得到的掩码 $M$ 即整段回答对应的图像关注热图 #文献 Zotero key VAI8N77N。

代码层面：目标分数由模型前向输出的 logits 计算——`pred_probs` 读取 `outputs['logits']`、softmax 后在生成 token 位置 gather 概率，且 `output_attentions=False`（读取的并非注意力张量）；优化目标为关键 token 位置的 log 概率之和（`torch.log(probs)[positions].sum()`）。模型参数全部冻结、无需重训（`param.requires_grad = False`）。关键 token 选择按 LLR 阈值实现（代码中阈值为 1.0）。掩码优化分辨率由 `--size` 控制，默认 32（即 32×32 网格，与实验的 24×24 网格不同）#代码事实 D:\code\LVLM_Interpretation\utils.py #代码事实 D:\code\LVLM_Interpretation\methods_helper.py #代码事实 D:\code\LVLM_Interpretation\args.py #代码事实 D:\code\LVLM_Interpretation\main.py。

## LVLM-Interpret（CVPRW 2024）

### **论文信息**

- 标题：LVLM-Interpret: An Interpretability Tool for Large Vision-Language Models
- 作者：Gabriela Ben Melech Stan、Estelle Aflalo、Raanan Yehezkel Rohekar、Anahita Bhiwandiwalla、Shao-Yen Tseng、Matthew Lyle Olson、Yaniv Gurwicz、Chenfei Wu、Nan Duan、Vasudev Lal（Intel Labs；Microsoft Research Asia）
- venue／年份：CVPRW 2024
- arXiv：2404.03118v3 [cs.CV]（2024-06-24）
- Zotero key：YXRLTYZC

### **研究问题与动机**

大视觉语言模型（LVLM）把视觉编码器接到 LLM 上并做多模态指令微调，能完成文本与视觉任务，但参数量巨大使其内部机制难以理解，且幻觉问题在视觉维度上更复杂，因此需要能解释「答案究竟依赖图像哪些区域」的工具 #文献 Zotero key YXRLTYZC，§1。论文的动机是提供一个交互式应用，帮助用户系统排查 LVLM、揭示失效机制，并为提升模型能力提供线索 #文献 Zotero key YXRLTYZC，Abstract、§1。作者强调工具目标是补足而非替代领域专用解释方案 #文献 Zotero key YXRLTYZC，§2.2。论文自述三项贡献：提出解释 LVLM 内部注意力机制的交互工具；给出一个揭示 LVLM 失败原因的案例研究；通过对因果解释的研究，推测 LVLM（如 LLaVA）隐式学到了因果结构 #文献 Zotero key YXRLTYZC，§1。

### **方法**

工具基于 Gradio 构建，采用多模态聊天布局：用户上传图像、以多模态形式提问，模型生成回答时内部保存注意力权重，再据此构造可视化；并提供图像基础编辑功能，用于以对抗性变体探测模型 #文献 Zotero key YXRLTYZC，§3。论文提供三类解释功能。

**(1) 原始注意力（raw attention）。** 沿 VL-Interpret 思路，交互式可视化逐头、逐层的跨模态注意力 #文献 Zotero key YXRLTYZC，§3.1。对第 $l$ 层、第 $h$ 个头、生成步 $t$，取当前 query token 到图像 patch 的分量：

$$
\text{CrossAttn}^{(l,h)}_{t\to p}=A^{(l,h)}_{t,\,p},\qquad p\in\mathcal{P},\ |\mathcal{P}|=576=24\times 24
$$

代码中对指定头取其图像 patch 切片并 reshape 成 $24\times24$ 网格，再归一化叠加到原图 #代码事实 `D:\code\lvlm-interpret\utils_attn.py` 第 138–143 行。用户既可选中生成 token 观察其对各 patch 的注意力，也可选中图像 patch 反查哪些输出 token 关注该区域 #文献 Zotero key YXRLTYZC，§3.1、图 2。

**(2) 相关性图（relevancy map）。** 采用 Chefer 等人的通用注意力解释方法，为输入中每个元素分配局部相关性分数，以刻画其对输出的贡献 #文献 Zotero key YXRLTYZC，§3.2。相关性分数沿 LLM 与作为视觉编码器的 ViT 反向传播，机制对应逐层相关性传播（LRP 式）：

$$
\bar{A}^{(l)}=\frac{1}{H}\sum_h \operatorname{ReLU}\!\left(A^{(l,h)}\odot \nabla A^{(l,h)}\right),\qquad R\leftarrow R+\bar{A}^{(l)}R
$$

其中 $\odot$ 为逐元素乘、$\nabla A$ 为注意力对目标标量的梯度，$R$ 由单位矩阵迭代累积 #代码事实 `D:\code\lvlm-interpret\utils_relevancy.py` 第 32–69 行。反向传播的驱动信号是对生成 token 的 one-hot 目标做反传得到的注意力梯度：

$$
L=\mathbf{1}_{y_t},\qquad \frac{\partial L}{\partial A^{(l,h)}}
$$

#代码事实 `D:\code\lvlm-interpret\utils_relevancy.py` 第 214–239 行。LLaMA 侧对全部自注意力层做上述传播，ViT 侧再以 LLM 侧结果初始化、按其自注意力层继续传播，ViT 最后一层不参与 #代码事实 `D:\code\lvlm-interpret\utils_relevancy.py` 第 165–208 行。传播后还做残差归一化（去单位阵、按行归一、再加回单位阵）：

$$
\tilde{A}=\frac{A-I}{\sum_j (A-I)_{\cdot j}}+I
$$

#代码事实 `D:\code\lvlm-interpret\utils_relevancy.py` 第 125–134 行（对应论文式 8+9）。

**图像 patch 分数 reshape。** 图像 patch 对应的相关性分数被重排成与原图布局一致的网格，作为相关性图基础，再用双线性插值上采样到原图尺寸，从而标出与每个生成 token 最相关的图像区域 #文献 Zotero key YXRLTYZC，§3.2。代码里取该行第 `img_idx:img_idx+576` 段并 reshape 为 $24\times24$，叠加到复原图上 #代码事实 `D:\code\lvlm-interpret\utils_attn.py` 第 197、209 行。

**(3) 因果解释（causal interpretation）。** 采用 CLEANN，在输入-输出 token 序列上学习因果结构：序列中每个 token 的出现是一个事件（图节点），输出 token 由输入 token 子集解释 #文献 Zotero key YXRLTYZC，§3.3。流程为：先取对目标 token（如「yellow」）注意力最高的 top-$k$（案例取 50）图像 token 作节点，再用**最后一层完整注意力矩阵**学习因果图；该图为部分祖先图，圆圈边标记表示不可识别边。从图中提取以目标节点为根的树，CLEANN 沿树逐步增大搜索半径寻找最小解释集 #文献 Zotero key YXRLTYZC，§3.3、图 3、图 4。作者指出原始注意力描述成对边际依赖，而因果发现算法识别条件独立关系，故可仅凭当前权重找出「若被扰动就会改变生成 token」的 token #文献 Zotero key YXRLTYZC，§3.3。

### **实验设置与结果**

案例研究在 LLaVA（LLaVA-v1.5-7b）上进行，样本取自 MMVP 基准；MMVP 专门收集 LVLM 难以推理的「CLIP-blind」图像 #文献 Zotero key YXRLTYZC，§4。由于 LLaVA 微调时文本与视觉 transformer 均冻结，作者先计算每个生成输出相对 LLaMA 输入特征的相关性分数，聚焦 LLaMA 自注意力层 #文献 Zotero key YXRLTYZC，§4。

关键发现：

- 观察到 LLaVA 主要关注文本 token、对图像 token 关注较少（图像 token 相关性分数低于输入文本 token），此时模型更易被操纵，甚至依据提问措辞改变回答而几乎不顾图像内容；论文以垃圾车案例为例：图像不变，模型因问法给出「门是开着的」与「门是关着的」两种矛盾回答，相关性图与柱状图显示文本相关性高于图像 #文献 Zotero key YXRLTYZC，§4、图 5。
- 反之，当生成输出对图像 token 的相关性高于对文本 token 时，LLaVA 的准确率似乎不受问法影响；论文以衬衫颜色为例：固定提问「What color is the man's shirt?」，手动改衬衫颜色（紫、绿）会改变回答且与图像变化一致；固定图像、改变问法（三句不同问法）时回答保持一致，黄色 token 对视觉输入的相关性显著高于文本变体 #文献 Zotero key YXRLTYZC，§4、图 6。
- 因果解释方面，论文以「The man's shirt is yellow」中的 yellow 为例，展示 top-50 高注意力 token、以及不同搜索半径下 CLEANN 找到的解释集 #文献 Zotero key YXRLTYZC，图 3。

可复现性证据：官方仓使用 transformers 的 `LlavaForConditionalGeneration`，对 `language_model.model.layers` 与 `vision_tower.vision_model.encoder.layers` 的自注意力模块注册前向钩子并开启 `output_attentions=True`，未做重训或微调 #代码事实 `D:\code\lvlm-interpret\utils_model.py` 第 39–87 行。论文未给出量化评测表格；上述均为定性案例观察。

### **作者结论与贡献**

论文的结论是：LVLM-Interpret 通过原始注意力、相关性图与因果解释三类功能，让用户可视化解码器生成输出与输入图像的关系、探索 LVLM 内部机制并获得失效案例洞见；该应用也能揭示提升 LVLM 性能的若干潜在路径 #文献 Zotero key YXRLTYZC，§5。自述贡献为：交互式解释工具；揭示 LVLM 某些失败原因可能来源的案例研究；通过对因果解释的研究推测 LLaVA 等 LVLM 隐式学到了因果结构 #文献 Zotero key YXRLTYZC，§1。未来工作包括把多种解释方法整合为更综合的解释度量 #文献 Zotero key YXRLTYZC，§5。
