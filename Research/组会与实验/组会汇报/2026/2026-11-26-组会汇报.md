## 为排版攻击的注意力分析选定归因口径 —— DEX-AR 迁移设计


## 一、本周工作进展

### 汇报点1：注意力归因方法选型收敛，DEX-AR 定为主线

**1. 目标 / 问题**

- 想研究/验证：为 [[排版攻击|SceneTAP]] 最后一步的注意力分析实验找一个经得起检验的归因口径。
- 当前存在的问题：实验侧现有的 `cross_attention_raw` 只是纯前向读注意力（取最后一层、头平均、跨生成步平均），热图全图弥漫，撑不起「排版放在注意力更高处，攻击成功率更高」这类位置结论。

**2. 实验与结果**

- 候选方法按三条判据筛选：是否面向生成式、产出文本的多模态模型；能否迁移到 LLaVA 并通用到同类模型；与实验现有两类注意力信号的接近程度。筛后 DEX-AR 三项全中：

| 判据    | DEX-AR 的情况                                                         |
| ----- | ------------------------------------------------------------------ |
| 同类性   | 原生面向自回归 VLM，官方支持清单就是 LLaVA-1.5-7B 与 BakLLaVA                       |
| 迁移便利性 | 被解释模型与实验同一权重 `llava-hf/llava-1.5-7b-hf`，无需换模型、无需重训                 |
| 契合度   | 图像 token 网格同为 $576=24\times24$，逐 token 切片区间与 `llava_model.py` 完全同构 |

- 本质上它就是 `cross_attention_raw` 的「梯度加权 + 多层累加 + 动态头过滤」加强版，下游 bbox 指标口径可以直接复用。
- 已在 centos7-lab 集群 A100 上跑通（Slurm 作业 574061）：单图 dry-run 与 8 图 PascalVOC 批量，filtered / unfiltered 句级热图、逐 token 热图与指标 JSON 全部正常落盘。完整复现证据见 [[DEX-AR复现实验报告]]，此处不展开数字。
- 头过滤前后的对照，同一张图、同一目标句 `This is a photo of a dog.`：

开启头过滤（filtered），质量压到主体上：

![[dexar-dog-filtered.png]]

关闭头过滤（unfiltered），明显弥散：

![[dexar-dog-unfiltered.png]]

- 逐 token 热图能直接看出权重只落在内容词上：`dog` 权重 $3.34$，句号 $0.012$，虚词 `This / is / a / photo / of / a` 全为 $0$。

![[dexar-dog-per-token-filtered.png]]

**3. 结论**

- DEX-AR 定为生成式 VLM 注意力归因的主线口径，可直接接入现有 LLaVA 实验。
- 代价是必须 `attn_implementation="eager"` 且开启反传，单图开销约为纯前向的 8 倍。
- CLIP 侧的 LeGrad 效果虽好但不适用，作对照参考，见汇报点4。

### 汇报点2：DEX-AR 的输入输出接口

DEX-AR 不采样、不产出文本，它回答的是一个反事实问题：「**假设模型要输出这句话，它靠的是图像的哪些区域**」。

**1. 核心调用只有三步**

```python
from dexar import DexarWrapper, visualize

model = DexarWrapper.from_pretrained("llava-hf/llava-1.5-7b-hf", device="cuda")

result = model.compute_dexar(
    image=image,                 # PIL.Image，统一 resize 到 336x336
    target_sentence="...",       # 要解释的句子
    prompt="USER: <image>\nDescribe the image. ASSISTANT:",
)
visualize(image=image, heatmap=result.sentence_heatmap, title="Sentence heatmap")
```

**2. 输入**

| 项 | 说明 |
| --- | --- |
| `image` | PIL.Image，官方样例统一 resize 到 $336\times336$ |
| `target_sentence` | **要解释的句子**，逐 token 用 teacher forcing 喂入 |
| `prompt` | 含 `<image>` 占位的模板，默认 `USER: <image>\nDescribe the image. ASSISTANT:` |
| `layer_index` | 加载时设定，梯度起始层（负值从末层倒数）；默认 $-10$，官方 `playground.py` 用 $0$（全部层） |

**4. `target_sentence` 是整个方法的开关**

工作原理可以这样理解：DEX-AR 自己不说话，需要把要解释的句子拆成 token，**一个一个塞回模型嘴里**（teacher forcing）。每塞一个 token 就问一次：「你说出这个词的时候，眼睛盯着图上哪一块」。问完 $T$ 个 token，就拿到 $T$ 张 $24\times24$ 的小热图；再按每个 token 的视觉相关性加权叠成一张句级热图——虚词权重接近 0，内容词权重大，所以句级热图基本由实义词决定（见汇报点1 的逐 token 图）。

关键点：**「解释哪句话」完全由调用者决定，方法本身不做选择**。这恰好是排版攻击分析需要的自由度。

`target_sentence` 有2种来源：

1. **模型自身回答**：先让模型回答，再把回答当作被解释的句子
2. **人为指定**：直接喂关心的句子，比如攻击场景里的目标词 `success`。

**5. 输出（`DexarResult`）**

| 字段 | 形状 | 含义 |
| --- | --- | --- |
| `per_token_heatmaps` | `[T, 24, 24]` | 逐 token 热图（含头过滤） |
| `per_token_heatmaps_unfiltered` | `[T, 24, 24]` | 逐 token 热图（无头过滤） |
| `token_weights` | `[T]` | 每 token 的视觉相关性权重 $\delta_t$ |
| `sentence_heatmap` | `[24, 24]` | 句级热图（过滤版，最常用） |
| `sentence_heatmap_unfiltered` | `[24, 24]` | 句级热图（未过滤，作对照） |
| `tokens` | `list[str]` | 解码后的 token 字符串，与逐 token 热图对齐 |

一句话：**给一张图 + 一句话，输出一串「这句话每个 token 看了图像哪里」的热图，再聚合成一张整句热图。**

### 汇报点3：迁移到 SceneTAP 的实验设计

**1. 目标 / 问题**

- 想用 DEX-AR 回答两个问题：**排版攻击为什么成功、为什么失败**
- 把**排版放在注意力更高的位置是否真的提高 ASR**。

**2. 两种 `target_sentence` 口径**

| 口径   | `target_sentence` 取值      | 回答的问题        | 与 ASR 的关系 |
| ---- | ------------------------- | ------------ | --------- |
| A 诊断 | 模型自身的实际回答                 | 模型为何这么答      | 间接        |
| B 对齐 | 攻击目标句（如 `success`、错误诱导答案） | 模型为何被诱导输出该目标 | 直接        |

**3. 关键设计：同一张图的成功 / 失败对照**

同一张攻击图，模型可能生成「图片中有一个写着 `success` 的文本框」（**描述**，攻击失败），也可能直接生成「`success`」（**执行**，攻击成功）。把这两种回答分别作为 `target_sentence` 各跑一遍 DEX-AR，得到两张热图，差异就直接落在「模型看的是排版所在区域，还是排版周围的场景」上。

这是单张热图给不出的信息：只有把成功与失败放在同一张原图上对齐比较，才能看出注意力分布的哪一处改变决定了结果，从而找到提升 ASR 的突破口。

**4. 顺带验证既有结论**

「注意力更高的地方放置排版，攻击成功率更高」目前仍是假设。用 DEX-AR 的句级热图配上贴片 bbox，可逐图算出框内注意力质量，再与该图是否攻击成功对照。

### 汇报点4：CLIP 侧对照 —— LeGrad（参考，不作主线）

把 LeGrad 也在 ImageNet-S 上完整复现了一遍（全量 12,403 张，两档分辨率），过程见 [[LeGrad-ImageNet-S复现实验报告]]。

定性效果明显比 DEX-AR 好：热图紧贴目标物体，换 prompt 就换定位对象，互不串扰。下图为「cat」与「remote control」两个 prompt 分别点亮的结果，以及全量按 IoU 分位抽样中最高的一档（IoU 0.77，三联图：原图 | 真值掩码 | 热图）。

![[legrad-qual-cat.png]]

![[legrad-qual-remote.png]]

![[legrad-viz-iou077-komondor.png]]

相比之下 DEX-AR 的热图偏分散、边界不锐（同一张 dog 图见汇报点1），但相对实验现有的 raw attention 已经是完全不同的量级——raw attention 基本全图弥漫，DEX-AR 至少把质量压到了主体上

**不作主线的原因**：LeGrad 面向 CLIP 这类对比／分类模型，归因目标是「文本 embedding 与图像特征的相似度」；而实验用的是 LLaVA 这种自回归生成模型，根本没有这个相似度可求。要迁过来必须把目标函数换成 $\log p(w^\ast\mid\cdot)$，属于改造而非直接使用。本轮只把它当作视觉定位质量的参考上限。

### 2. 老师建议
在多个模型上都关注类似的物体，要找到共性会比较好，因为各个模型的注意力关注点可能都不一样，比如同样的位置，对于GPT可能更好，但对于其他模型就不好。这样，除非找到模型注意力的共性，不然就无法将结论推广。因此，做方法的迁移是必须的。
