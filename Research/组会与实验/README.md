## 使用约定

- 能形成正式结论的内容优先写成 `组会汇报` 或明确标题的计划笔记。
- 临时草稿如果后续有保留价值，尽快改名并移动到对应目录；没有价值就直接删除。
- 图片与 PPT 不混放在 Markdown 目录里，统一走 `附件`。
- 实验规划笔记中引用代码时，标注对应的代码文件路径。
