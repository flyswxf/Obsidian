**目标**

建一个共享基线仓（`D:\code\attn-xai-baselines`），按各原文实现所需基线解释器与评测指标，保证对照口径与论文一致。

**约束**

- 只做原文基线，不掺入本项目自创口径；每个方法按其原论文实现并标注出处与层／头选择 #文献。
- 解释器统一适配 decoder-only VLM，输出 sequence-level 热图（逐 token 图按序列平均，即 GLIMPSE Table 1 的适配方式）#文献 Zotero key ATGW7RFS。
- 指标与论文一致：NSS（人类注意力取 θ=95 百分位点）、Spearman 秩相关、Deletion／Insertion AUC（按原图与基线图分数归一化）#文献 Zotero key ATGW7RFS、#文献 Zotero key VAI8N77N。
- 解释器统一接口 `(model, image, question) -> H×W 热图`；指标统一 `(热图, 人类图／模型) -> 标量`。
- 集群任务遵守 `cluster-safety`，代码同步按 `git-cluster-sync` 登记。
- 下载论文到本地查看，阅读后再进行复现，禁止凭感觉复现
- 可同时启用多个agent进行工作，只需确保他们都各自创建了conda环境，并在集群上分配计算任务

**待验证假设**

- H1 `[文献]` 各方法在相同模型与数据上能复现论文报告的量级（VQA-HAT：Raw Attention NSS 0.485、Rollout −0.082、Grad-CAM 0.267、TMME last-12l 0.591）#文献 Zotero key ATGW7RFS。
- H2 `[猜想]` 官方参考实现可复用：Attention Rollout（samiraabnar/attention_flow）、Grad-CAM（jacobgil/pytorch-grad-cam）、Chefer 相关性传播（hila-chefer/Transformer-Explainability）。
- H3 `[猜想]` TMME 与 IIA 无直接可复用仓，须按论文自实现，工作量最大。也可在github上搜索可能可用仓

- 单测：每个方法在小样上与其论文数值同量级即 pass；偏差偏大先排查适配（层选、头平均、归一化）。
- 交付：解释器与指标打包为可 import 的库，附最小示例与数值自检脚本。
- fail 归因「实现错误」或「结论不成立」；前者修实现重跑，连续两次未修通 → 暂停该行转做他行。
