## 一、背景：为什么要有下一阶段

上一轮三路复现得到三个互相印证的事实：

| 路 | 结论 | 对下一阶段的约束 |
| --- | --- | --- |
| A（Chefer） | 梯度修正的相关性传播能按 query 语义定位，质心位移 87–134 px；Grad-CAM 不稳定（`ln_2` 完全退化） | **有梯度信号的方法优于纯注意力聚合**，应作为主力 |
| B（Abnar + Kobayashi） | rollout 被 `[CLS]` 主导、flow 在 BERT 上饱和退化（ratio ≡ 1.000）；$\rho(\alpha,\text{2021 范数})=-0.43/-0.87$ | 纯聚合方法只能当参考；权重不等于贡献，且计入残差与 LN 后可能反向 |
| C（SAGA + ATPI） | 生成时注意力可移植，热/冷区对比度 2.3～3.6×，但 2B 上各层 Spearman 全负、最优层显著性重叠仅 0.154；ASR 样本量 9，无统计效力 | 小模型语义对齐弱，关联分析必须上 7B/8B 且每条件 ≥ 100 样本 |

主线研究此前的矛盾结论是「注意力与 ASR 无稳定关联」，而当时用的指标是**单层 raw attention 的区域均值**——同时踩了「被特殊 token 吸走权重」和「层没选对」两个坑。下一阶段的核心任务就是把指标换掉，重跑关联分析，判断矛盾来自指标还是来自现象。

## 四、T1 — decoder-only 版梯度修正相关性传播

### 目标

把 A 路的 Chefer 规则从 CLIP 双编码器迁到 Qwen2-VL 这类 decoder-only VLM，接到 C 路已经跑通的生成时注意力提取管线上，产出一张**带梯度修正**的视觉热图，与现有 raw 热图同图对比。

### 方法

设目标生成 token 的对数概率为 $y=\log p(w^{*}\mid \cdot)$，对第 $\ell$ 层第 $k$ 个头的注意力矩阵求梯度并做修正：

$$\bar{A}^{(\ell)}=\frac{1}{h}\sum_{k=1}^{h}\left(\nabla A^{(\ell)}_{k}\odot A^{(\ell)}_{k}\right)^{+},\qquad R\leftarrow R+\bar{A}^{(\ell)}R$$

其中 $(\cdot)^{+}$ 为逐元素取正部。逐层从 $\ell=1$ 累积到 $\ell=L$，初始 $R=I$；最后取目标行的视觉列切片，按 `image_grid_thw[0][1:]//2` 还原为 $(g_h,g_w)$ 网格并做 minmax 归一化。

### decoder-only 的三个必须处理的差异

1. **没有 cross-attention**，图像与文本 token 在同一个 self-attention 里，`cross_attentions` 恒为 `None`。
2. **因果掩码**使 $\bar{A}^{(\ell)}$ 严格下三角，上三角恒为 0。逐层矩阵乘会把这些结构性零当成"无贡献"，必须在归一化时按行有效长度重归一，否则深层热图会被系统性压平。
3. **反向传播需要 `retain_graph=True`**，且 `output_attentions=True` + `attn_implementation="eager"`；**不得使用 `torch.no_grad()`，也不得调用 `requires_grad_(False)`**——A 路正是因此报过两次 `cannot register a hook on a tensor that doesn't require gradient`。

### 判据（全部量化，逐条给 pass / fail）

| 编号 | 判据 | 阈值 | 参照 |
| --- | --- | --- | --- |
| G1 | 谱残差显著性 top-15% 重叠率 | **> 0.154** | C 路 raw layer 27 |
| G2 | top-2 网格行下沉质量（sink） | **< 0.208** | C 路 raw layer 27 |
| G3 | 质心落在人工标注的主体框内（IoU ≥ 0.3） | 3 张底图**至少 2 张**通过 | 需先为 3 张底图标 GT 框，写入 JSON |
| G4 | query 切换敏感度：换 prompt 后质心位移与方向 | 位移 ≥ 30 px 且 Pearson > 0.5 | A 路 Chefer 全层 0.6656 / 0.8338 |
| G5 | sanity：$\bar{A}$ 无 NaN/Inf、行和非负、逐层 rollout 与仅末层结果不同 | 全部通过；仅末层 SSIM 应显著更低 | A 路 0.8338 vs 0.5574 |
| G6 | 显存峰值 | ≤ 8 GB；超限则降 `max_pixels` 或退回 CPU 并记录耗时 | C 路前向 5.15 GB |

G4 的做法：同一张图分别用「描述图中的人物」与「描述图中的交通工具/动物」两类 prompt，比较热图质心。这是 A 路证明 Chefer 有效的关键判据，必须保留。

### 失败时的处置

Qwen2-VL-**2B** 本身语义对齐就弱（各层 Spearman 全负）。若 G1/G3 不达标而 G5 全部通过，**不得直接判定方法失败**，正确结论是「实现正确，但 2B 模型的注意力语义对齐不足以支撑该判据」，并在报告中标注需在 7B 上复测（归入 T4）。

### 交付物

`D:\code\attn-repro\D\{d1_grad_relevance,d2_compare,d3_probe}.py` + `REPORT.md` + `D:\checkpoints\outputs\D\metrics.json` + 对比图（raw / 梯度修正 / 叠加 GT 框，三列并排）。

## 五、T2 — 选层与 sink 通用体检脚本

### 目标

把 C 路一次性的选层逻辑固化成可复用工具，输入任意模型与图像，输出选层建议与 sink 诊断，并带回归测试。

### 要输出的指标（逐层）

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 谱残差重叠率 | 注意力图 top-15% cell 与 Hou & Zhang 谱残差显著图 top-15% cell 的重叠 | 语义对齐代理，越高越好 |
| top-$k$ 行下沉质量 | 网格最上 $k$ 行的注意力质量占比（$k=2$） | sink 伪影检测，越低越好 |
| 特殊 token 汇聚度 | `[CLS]`/`<s>`/BOS 等行的质量占比 | B 路教训：raw 会被特殊 token 吸走权重 |
| 归一化熵 | $-\sum p\log p / \log N$ | 仅作参考，**不得**用作选层主判据（C 路已证集中度指标会选出 sink 伪影层） |

### 判据

- **回归测试**：在 Qwen2-VL-2B + 原 3 张底图上，必须复现 layer 27 的 0.154 / 0.208（容差 ±0.005）。复现不了说明重构引入了 bug。
- **一致性**：3 张图各自的最优层必须一致（原实验均为 27）。若不一致，输出分歧报告而非强行取均值。
- **可扩展**：脚本接受 `--model` 与 `--layers`，能在 7B 上直接跑（集群提交时复用同一份代码）。

### 交付物

`D:\code\attn-repro\D\t2_layer_probe.py` + `tests/test_regression.py` + 使用说明。

## 六、T3 — 热力图产出规范

### 目标

固化六道闸门，使每张对外产出的热力图都自带可证伪的对照，而不是插画。

### 六道闸门（缺一不可）

1. **能力前置证明**：先证明模型会做这道题（B 路关卡 0 的 cloze ratio 思路）。模型都不会做，热图无意义。
2. **客观选层**：用 T2 的双判据，**禁止**「挑看着最清楚的那层」。报告所选层的两项数值。
3. **sink 检查**：出图前报告 top-2 行下沉质量与特殊 token 汇聚度；超阈值时说明是剔除 sink 行还是改范数加权。
4. **对照条件**：至少一组（换 query / 换注入位置 / 换层）。给出 Pearson、SSIM、质心位移中的至少两项。
5. **批量数字 + 代表图**：结论靠批量样本，热力图只挑代表性例子。每条件样本量 **≥ 100**（SAGA 原文 Fig.7 消融用 $n=1000$；C 路 $n=9$ 是明确的反面教材）。
6. **perceive 与 obey 分开统计**：关键词子串匹配会把纯 OCR 命中误计为劫持（C 路 hot 的 2 次命中里有 1 次只是感知）。自动判据必须配人工复核，报告细分表。

### 绘图约定

统一色标与归一化方式（minmax）、中文字体走 `common.setup_cjk_font()`（否则豆腐块）、每图标注质心坐标与所用层号、对比图固定「原图 / 基线 / 本方法」三列。

### 交付物

`Research\组会与实验\实验规划\注意力热力图产出规范.md`（含 checklist 表格）+ `D:\code\attn-repro\D\t3_plot_template.py`。

## 七、T4 — 三指标并行的注意力—ASR 关联分析（集群）

### 目标

在同一批样本上并行计算三组区域注意力指标，与 ASR 做相关分析，判定「注意力与 ASR 无稳定关联」这一矛盾来自指标还是来自现象。

### 三组指标

| 组   | 定义                               | 来源                                         |
| --- | -------------------------------- | ------------------------------------------ |
| M1  | 单层 raw attention 的区域均值           | 主线原做法（对照组）                                 |
| M2  | Kobayashi 范数归因（计入残差 + LayerNorm） | B 路，$\rho(\alpha,\text{2021})$ 为负说明与权重可能反向 |
| M3  | T1 的梯度修正相关性传播区域均值                | 本阶段主力                                      |

### 实验设计

- **模型**：Qwen2.5-VL-7B-Instruct 或 Qwen3-VL-8B-Instruct（与 SAGA 同族；SAGA 对 Qwen3-VL-8B 用相关性分析选出的是 layer 29，可作起点，但仍须用 T2 重新客观选层）。
- **样本量**：每条件 ≥ 100。
- **条件**：clean / hotspot 注入 / coldspot 注入（沿用 C 路的三组攻击文本，扩充数量）。
- **判据**：报告三组的 Spearman $\rho$ 与 bootstrap 95% 置信区间；perceive / obey 分开。
  - 若符号或显著性**随指标翻转** → 结论为「矛盾来自指标选择」，主线原结论需修订；
  - 若三组**一致不显著** → 结论为「注意力确实无法预测 ASR」，这是一个可发表的真结论。

### 集群纪律（强制）

1. 登录节点只做检查、编辑、提交，**不得**在登录节点加载模型或跑推理。
2. GPU 工作一律 `sbatch` 提交，默认申请 1 GPU、1 节点、最小够用的 CPU/内存/时长；`srun --pty` 仅用于小样本验证。
3. 提交前先 `squeue -u $USER` 与分区占用检查；进入计算节点后确认 `hostname`、作业信息与 `nvidia-smi`。
4. 长任务记录作业 ID、日志路径、输出目录，支持 `--resume`；断线后先查 `squeue`、`sacct`、日志与产物更新时间，确认进入终态且无残留进程后才可重提。
5. 一次远程调用只执行一个目的明确的命令，不用 `&&`/`;` 串联；复杂逻辑写成脚本再运行。
6. 先单样本 dry-run 验证显存与耗时，再扩大到全量。

`D:\code\attn-repro\E\` 代码 + Slurm 脚本 + `REPORT.md`；实验报告写入 `Research\组会与实验\实验报告\`。
