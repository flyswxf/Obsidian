## 实验计划：验证 Patch 是否将注意力拉向文字邻域

### 1. 当前结果与问题

当前实验已经支持按 `status` 与 `patch` 两个维度进行分组分析。

已有结果显示：

- 在 `patch=WITH_PATCH` 条件下，`text bbox` 内的交叉注意力与视觉注意力都没有提升，反而略有下降。
- 攻击成功率也从 `NO_PATCH` 的 `37.04%` 下降到 `WITH_PATCH` 的 `22.22%`。

这说明当前 `red_box` patch 没有实现“提升文字区域内部注意力”的目标。

但现有指标只统计了 **文字框内部 (`text bbox`)** 的注意力，因此还无法区分以下两种情况：

1. patch 根本没有吸引注意力；
2. patch 吸引了注意力，但注意力落在了 **文字外围红框本身** 或其邻域，而不是文字框内部。

因此，下一步实验的关键是把注意力统计区域从单一 `text bbox` 扩展为三个层级。

### 2. 下一步实验目标

本轮实验希望回答三个问题：

1. patch 是否提升了 **文字框内部** 的注意力；
2. patch 是否提升了 **红框区域本身** 的注意力；
3. patch 是否至少把注意力拉到了 **文字附近的大邻域**。

### 3. 新的统计区域设计

后续实验对每张图统一计算三类区域指标：

- `text bbox`
  - 即注入文字的原始边界框；
  - 用于回答“模型是否真正看到了文字本身”。
- `patch bbox`
  - 即以文字框为中心、向外扩展得到的红框区域；
  - 用于回答“模型是否被红框这一视觉提示吸引了过去”。
- `expanded bbox`
  - 即在 `patch bbox` 的基础上再向外扩展一圈的邻域；
  - 用于回答“注意力是否至少被拉到了文字附近的大区域”。

### 4. 实验变量与分组方式

仍然保留原有的两种分组方式：

- `status`
  - `SUCCESS` / `FAIL`
  - 用于验证“攻击成功是否对应更高的区域注意力”。
- `patch`
  - `NO_PATCH` / `WITH_PATCH`
  - 用于验证“加 patch 是否改变了不同区域内的注意力分布”。

### 5. 重点比较指标

每个区域都分别统计两类注意力：

- `cross_*`
  - 生成答案时的交叉注意力；
- `vision_*`
  - 视觉编码阶段的视觉自注意力。

每类注意力先聚焦两个核心指标：

- `*_attention_ratio`
  - 区域内注意力占整图总注意力的比例；
- `*_mean_attention`
  - 区域内部的平均注意力强度。

### 6. 预期分析逻辑

#### 6.1 按 `patch` 分组

比较 `NO_PATCH` 与 `WITH_PATCH` 在三个区域上的注意力差异：

- 如果 `text bbox` 上升：说明 patch 确实把注意力拉到了文字本身；
- 如果 `text bbox` 不升，但 `patch bbox` 上升：说明 patch 主要吸引了对红框的注意；
- 如果 `expanded bbox` 上升而前两者不明显：说明 patch 只把注意力拉到了文字附近的大邻域；
- 如果三者都不上升：说明当前 patch 设计无效。

#### 6.2 按 `status` 分组

比较 `SUCCESS` 与 `FAIL` 在三个区域上的注意力差异：

- 如果成功组在 `text bbox` 上显著更高，支持“攻击成功依赖于模型关注文字内容”；
- 如果成功组主要在 `patch bbox` 或 `expanded bbox` 上更高，而 `text bbox` 不明显，则说明“注意力被引到附近”不等于“模型真正读懂文字”。

### 7. 本轮代码改动目标

为支持上述实验，需要完成以下代码准备：

1. 在实验流程中统一生成并保存：
   - `text bbox`
   - `patch bbox`
   - `expanded bbox`
2. 在结构化记录中新增三类区域的注意力指标；
3. 在分析脚本中支持对三类区域分别汇总与绘图；
4. 保留现有 `status` 与 `patch` 两种分组入口。

### 8. 本轮实验结束后的判断标准

本轮实验结束后，需要重点看以下结论是否成立：

- `WITH_PATCH` 是否提高了 `text bbox` 内的注意力；
- `WITH_PATCH` 是否只提高了 `patch bbox` 或 `expanded bbox` 的注意力；
- 注意力变化是否与 ASR 的变化方向一致。

如果结果显示：

- patch 只提高了 `patch bbox` 注意力，但没有提高 `text bbox` 注意力；
- 同时 ASR 也没有提升；

则可以初步判断：当前 `red_box` patch 更像是一个“视觉干扰物”，而不是一个有效的“文字注意力引导器”。
