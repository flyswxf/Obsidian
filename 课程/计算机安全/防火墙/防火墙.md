防火墙是部署在受保护网络与外部网络之间的安全屏障，依据访问控制策略对进出流量进行审查和过滤，是网络安全体系的**第一道防线**。

1. **强制流量经过防火墙** — 内外所有通信必须经过防火墙，通过物理手段阻断其他一切访问路径
2. **仅放行授权流量** — 只允许符合本地安全策略的通信通过
3. **防火墙自身免疫** — 使用强化操作系统（Hardened OS），确保防火墙本身不被攻破

## 网关

网关是连接两个不同网络的边界节点，通常负责在不同通信协议、数据格式或体系结构之间进行转换。在网络安全体系中，网关构成了内部受保护网络与外部不可信网络（如 Internet）之间的唯一出入口。

防火墙与网关在实际应用与部署中高度重合，两者的联系主要体现在以下两个方面：
- **边界防御部署**：防火墙通常物理或逻辑地部署在网关处，利用网关作为单一扼流点（Choke Point）的特性，强制所有进出流量接受安全策略的审查。
- **代理型防火墙**：部分防火墙直接以网关的形态运行。例如，[[应用层网关]]（Application-Level Gateway）和[[电路级网关]]（Circuit-Level Gateway）通过代理机制阻断内外网络的直接数据链路连接，从而提供更深层次的协议审查与隔离。

## 防火墙能力

防火墙可提供以下四方面能力：

| 能力               | 说明                                           |
| ------------------ | ---------------------------------------------- |
| **单一扼流点**     | 所有流量汇聚于一处，便于统一控制和管理         |
| **安全事件监控**   | 提供审计与告警的实施场所                       |
| **非安全功能平台** | 承载 NAT（网络地址转换）、网络管理、日志记录等 |
| **IPSec 平台**     | 利用隧道模式实现虚拟专用网（VPN）              |

> [!example] 举例
> 企业出口防火墙既是流量的唯一通道，又同时承担 NAT 地址转换、流量日志记录和 IPSec VPN 网关等多种职责。

---

## 防火墙局限性

1. **无法防御绕过防火墙的攻击** — 内部主机可能通过无线宽带直连外部网络，或与合作伙伴存在直连链路，流量完全绕过防火墙
2. **无法防御内部威胁** — 满怀不满的员工或无意配合外部攻击者的内部人员不受防火墙约束
3. **无线 LAN 可能被外部接入** — 配置不当的无线网络可从外部直接访问；内部防火墙无法阻止同一企业内不同网段之间通过无线通信
4. **可移动设备风险** — 笔记本电脑、U 盘等设备在外部被感染后，接入内部网络即成为攻击载体
