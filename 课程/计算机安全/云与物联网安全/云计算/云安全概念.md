
云环境引入了许多传统的本地基础设施所不具备的安全挑战。由于数据和计算资源的控制权发生了转移，云安全的核心在于理解服务提供商与客户之间的责任边界。

### 云计算安全威胁
根据云安全联盟 (CSA) 的研究，云环境面临的顶级威胁包括但不限于：
- **数据泄露**：云环境多租户特性增加了数据被未授权访问的风险。
- **身份和凭证管理不足**：弱密码或缺乏多因素认证（MFA）会导致账户劫持。
- **不安全的接口和 API**：云服务严重依赖 API，若 API 存在漏洞，将直接暴露云内资产。
- **系统漏洞与恶意内部人员**：虚拟化层的漏洞或提供商内部人员的恶意行为。

### 责任共担模型
在云环境中，安全是由云服务提供商（CSP）和客户共同承担的，这种机制被称为**责任共担模型**。具体的责任划分取决于所采用的[[云计算基础#云计算服务模型 SPI 模型|服务模型 (SPI 模型)]]：

- **IaaS 环境**：CSP 负责底层基础设施（计算、存储、网络）和虚拟化层的物理与逻辑安全；客户负责操作系统、中间件、运行时环境、数据和应用的安全。
- **PaaS 环境**：CSP 扩展了其责任范围，接管了操作系统和中间件的安全；客户主要负责自身部署的应用程序和相关数据的安全。
- **SaaS 环境**：CSP 负责绝大部分架构的安全；客户仅负责自身的数据输入、访问控制和端点设备安全。
