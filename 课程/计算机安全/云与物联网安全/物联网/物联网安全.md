由于设备资源受限、部署环境物理分散以及缺乏统一的标准，物联网面临着比传统IT网络更为严峻的安全威胁。

### 物联网攻击面
结合[[物联网基础#物联网核心架构|物联网架构]]，其攻击面广泛分布于各个层级：
- **设备层（感知层）攻击**：
  - **物理破坏与篡改**：攻击者直接接触传感器或执行器，提取固件或注入恶意代码。
  - **资源耗尽攻击**：针对电池供电设备发起微型的 DoS 攻击（如“睡眠剥夺”攻击），导致设备电量枯竭。
- **网络层攻击**：
  - **窃听与中间人攻击 (MitM)**：利用未加密的无线通信链路（如老旧的蓝牙或 Zigbee 协议）截获或篡改数据。
  - **路由攻击**：如黑洞攻击、选择性转发，破坏物联网自组网的拓扑结构。
- **云与应用层攻击**：
  - 针对后端 API 的注入攻击或未授权访问。

### 资源受限环境下的密码学
物联网设备（如微控制器）通常计算能力弱、存储空间小，无法运行标准强度的加密算法（如 RSA-2048 或高负载的哈希函数）。
为了解决这一问题，学术界和工业界引入了**轻量级密码学 (Lightweight Cryptography)**：
- 设计目标：在极低的逻辑门数量和功耗下提供足够的安全性。
- 例如：使用椭圆曲线密码学 (ECC) 替代 RSA，因为在相同安全强度下，ECC 需要的密钥长度更短（如 256 位 ECC 可媲美 3072 位 RSA）。

### 物联网安全框架
为系统性地保障物联网安全，需构建包含以下核心能力的安全框架：
1. **设备身份认证**：为每个设备分配唯一且不可伪造的身份（如基于硬件的 PUF - 物理不可克隆函数）。
2. **安全启动 (Secure Boot)**：设备启动时，通过密码学校验固件签名，确保系统未被篡改。
3. **安全通信**：在网络层实施端到端加密（如 TLS/DTLS），保障数据在传输过程中的机密性与完整性。
4. **生命周期管理与固件更新 (OTA)**：确保设备能够安全地接收并安装安全补丁，防止已知漏洞被利用。
