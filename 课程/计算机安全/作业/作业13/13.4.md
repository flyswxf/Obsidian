# 13.4 云环境面临的主要安全威胁

## 题目

描述一些主要的特定于云的安全威胁。
(Describe some of the main cloud-specific security threats.)

## 讲解

云环境引入了许多传统的本地基础设施所不具备的安全挑战。根据云安全联盟（CSA）的研究，由于云计算的架构特性（如多租户、资源共享），云环境面临的主要顶级威胁包括：

- **数据泄露（Data Breaches）**：由于多租户环境中不同客户的数据存储在共享资源上，如果隔离不当或存在配置错误，可能导致敏感数据被未授权访问、窃取或泄露。
- **身份、凭证和访问管理不足（Insufficient Identity, Credential, and Access Management）**：云服务中的弱密码、缺乏多因素认证（MFA）、过度授权或不当的密钥管理极易导致账户被劫持，攻击者可借此访问敏感数据或操纵云资源。
- **不安全的接口和 API（Insecure Interfaces and APIs）**：云服务提供商通常公开了一组软件接口或 API 供客户管理和交互。这些 API 构成了云环境的外部边界，若其存在漏洞（如身份验证缺陷、注入漏洞），将直接暴露云内资产。
- **系统漏洞（System Vulnerabilities）**：操作系统、虚拟化层（Hypervisor）或网络组件中的可利用漏洞。由于云环境的多租户特性，底层漏洞的影响可能被放大，甚至导致虚拟机逃逸（VM Escape）攻击。
- **恶意内部人员（Malicious Insiders）**：云服务提供商的内部员工或具备高级权限的系统管理员可能滥用其访问权限，窃取客户数据或破坏系统完整性。
- **高级持续性威胁（Advanced Persistent Threats, APTs）**：一种长期的、针对性强的网络攻击，攻击者潜伏在云基础设施中，旨在长期窃取敏感数据，且极难被检测。

---

## 参考答案

主要的特定于云的安全威胁包括：由于多租户环境资源共享和隔离不足导致的数据泄露；弱密码和缺乏多因素认证引发的身份访问管理不足及账户劫持；云服务对外暴露的不安全接口和 API 被攻击者利用；操作系统及虚拟化层存在的系统漏洞；云服务提供商恶意内部人员的数据窃取或破坏；以及潜伏在云基础设施中长期窃取敏感数据的高级持续性威胁（APT）。
