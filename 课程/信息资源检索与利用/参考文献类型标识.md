依据 **GB/T 7714-2015**《信息与文献 参考文献著录规则》，不同文献类型以单字母标识，在参考文献著录时置于方括号内，如 `[M]`、`[J]`。

## 常见文献类型标识

| 文献类型 | 标识 | 英文全称 |
|---------|------|---------|
| 图书 | M | Monograph |
| 期刊 | J | Journal |
| 报纸 | N | Newspaper |
| 专利文献 | P | Patent |
| 学位论文 | D | Dissertation |
| 会议论文 | C | Conference |
| 研究报告 | R | Report |
| 标准文献 | S | Standard |
| 档案文献 | A | Archive |
| 政府出版物、产品资料、年鉴等 | Z | — |

## 记忆要点

- **M**：图书 Monograph，专著类文献
- **D**：学位论文 Dissertation，硕博论文
- **J / N**：期刊与报纸，均属连续出版物
- **C**：会议论文，Conference Proceedings
- **R / S / A**：研究报告、标准、档案
- **P**：专利
- **Z**：其他未归类文献（政府出版物、产品资料、年鉴等）
