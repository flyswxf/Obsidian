为了减少IO操作
数据库进行查询(selection)操作时, 一般会通过索引来提高速率

#### 分类:
- Ordered Index
	- 索引有序, 即根据建索引的数据表列(search key)的值来排序
- Primary Index/Clustering Index
	- 数据和索引按相同顺序存储, 比如search key从小到大
	- ![[主键索引示例图.png]]
	- Dense Index
		- 每一条数据都有相应的索引
	- Sparse Index
		- 一些数据有索引, 索引指向一个数据块, 数据块中存放多条数据
		- 要求数据和索引有序(类似[B+树]结构, 这样才能确定没有索引的数据在哪个数据块中)
- Secondary Index
	- 数据和索引顺序不同, 例如数据的物理存储顺序是无序的, 而索引是有序的
	  _A non-clustering, non-clustered, or secondary index specifies an order that is different from the file/table/relation’s sequential order._
	- 一定是Dense Index
