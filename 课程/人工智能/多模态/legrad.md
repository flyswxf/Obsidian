先给一个具体场景，后面所有记号都套在这个场景里，就容易懂了。

## 0. 一个具体例子（后面都用这组数字）

一张 **224×224** 的图，切成 **16×16** 的小方块（patch），得到 $14\times14=196$ 个 patch。再额外加 **1 个 `[CLS]`**（专门存放"整张图的总结"）。于是：

- 一张图 = **197 个 token**（1 个[CLS] + 196 个 patch）
- 每个 token 是一个**长度 768 的向量**
- 模型的层数 $L=12$，注意力头数 $h=12$

## 1. 逐个记号（形象版）

| 记号           | 形状             | 人话解释                                                                             |
| ------------ | -------------- | -------------------------------------------------------------------------------- |
| $Z^l$        | 197 × 768      | **第 $l$ 层的"账本"**：197 行（每个 token 一行），每行 768 个特征数字。图的每一次变换都写在这本账上                  |
| $z_i^l$      | 768            | 账本的第 $i$ 行，即"第 $i$ 个 token 当前的样子"。$z_0^l$ 就是 `[CLS]`                             |
| $\bar z^l$   | 768            | 把 197 行**上下求平均**，压成一行 → 这张图在第 $l$ 层的"整体摘要"                                       |
| $C$          | 768 × 1000     | **一本"类别对照词典"**：每列是一个类别（或一个文本 prompt）的模板。有监督时 1000 列=1000 类；VLM 时列数=prompt 个数     |
| $\bar y^l$   | 1000           | 摘要 $\bar z^l$ 和词典 $C$ 做矩阵乘 → 得到 **1000 个分数**，每个类别一个分数，就是"预测"                     |
| $\hat c$     | 1 个数           | 想解释的**目标类的下标**（比如第 285 类是"埃及猫"）                                                  |
| $s^l$        | 1 个数           | 从 1000 个分数里**挑出目标类那一个**，$s^l=\bar y^l[\hat c]$。后面所有梯度都是对它求的                      |
| $A^l$        | 12 × 197 × 197 | **注意力图**："谁在看谁"的表格。每个头一张 197×197 表，第 $(i,j)$ 格=第 $i$ 个 token 关注第 $j$ 个 token 的强度 |
| $\nabla A^l$ | 12 × 197 × 197 | **敏感度**：单元格 $A^l_{i,j}$ 稍微动一点，目标类分数 $s^l$ 会变多少。正=有帮助，负=帮倒忙                       |
| $[\cdot]_+$  | 同形状            | **ReLU**：负数全变成 0，只留"有帮助"的正梯度                                                     |
| $\hat E^l$   | 197            | 对 head 和"看的那一方(query)"求平均 → **每个 token 一个重要性分数**                                 |
| $1:$         | 196            | 把开头的 `[CLS]` 那一项**扔掉**，只留 196 个 patch                                            |
| reshape      | 14×14          | 把 196 个数**摆回 2D 网格** → 变成热图                                                      |
| norm         | 0~1            | min-max 归一化，把数值压到 0~1 方便画图                                                       |

**核心直觉一句话**：对每一层，问一句"如果把这张注意力表的某格拧一下，目标类的分数会变多少？" 变化大的格子，对应的 patch 就越重要。

## 2. 把公式翻译成流程

1. 前向走一遍模型，**沿途把每层的 token 账本 $Z^l$ 和注意力图 $A^l$ 都存下来**。
2. 对第 $l$ 层：$Z^l$ 上下平均 → $\bar z^l$ → 乘词典 $C$ → 得到分数 $\bar y^l$ → 取出目标类 $s^l$。
3. 反向求 $\partial s^l/\partial A^l$，ReLU 去负，对 head 和 query 求平均 → 每个 patch 一个分数。
4. 去掉 [CLS]，摆成 2D → 单层热图。
5. **12 层各做一遍，热图相加求平均** → 最终热图，再归一化。

（Eq.7/8/9 就是把第 2~4 步对"所有层"重复一遍再平均。）

## 3. numpy 伪代码

```
import numpy as np

# ===== 设定 (以 ViT-B/16, 224x224 为例) =====
n    = 196    # patch 数 = 14*14
h    = 12     # 注意力头数
d    = 768    # token 特征维度
C    = 1000   # 类别数
L    = 12     # 层数
chat = 285    # 目标类的下标, 例如 "埃及猫"

# ===== 第 1 步: 前向, 沿途保存每层结果 =====
Z = embed(image)                          # (197, 768), 第 0 行是 [CLS]
cache = []                                # 保存 (Z_l, A_l)
for l in range(L):
    Z, A = vit_block(Z)                   # A: (12, 197, 197)
    cache.append((Z, A))

# ===== 第 2~4 步: 逐层算显著性图 =====
per_layer = []                            # 收集每层的 patch 重要性 (长度 196)
for (Z, A) in cache:
    z_bar = Z.mean(axis=0)                # (768,)        对 197 个 token 求平均
    y_bar = z_bar @ C                     # (1000,)       和类别词典比对, 得每类得分
    s     = y_bar[chat]                   # 标量          目标类得分

    A_grad = backward(s, A)               # (12, 197, 197) 反向传播得到 ds/dA
                                          # (真实实现靠 autograd; 纯 numpy 需手写 VJP)

    A_grad = np.maximum(A_grad, 0)        # ReLU: 丢弃负梯度
    E_hat  = A_grad.mean(axis=(0, 1))     # (197,)        对 head 和 query 求平均

    E_hat  = E_hat[1:]                    # (196,)        丢掉 [CLS], 只留 patch
    per_layer.append(E_hat)

# ===== 第 5 步: 跨层融合并出图 =====
E_bar = np.mean(per_layer, axis=0)        # (196,)        12 层求平均
E     = E_bar.reshape(14, 14)             # (14, 14)      摆回 2D 网格

# min-max 归一化到 [0,1]
E = (E - E.min()) / (E.max() - E.min() + 1e-8)

# E 即最终热图: 数值越大, 该位置 patch 对 "埃及猫" 越关键
```

## 4. 变体：Attentional Pooler（如 SigLIP）

只有取激活和求梯度的对象变了：激活改用池化得到的 query 算，梯度对**池化注意力图**求。

```
for (Z, A_pool) in cache:                 # A_pool: (12, 1, 197), 形状不同!
    q     = attn_pool(Z)                  # (768,)        池化 query
    s     = q @ C[:, chat]                # 标量          目标类得分
    A_grad = backward(s, A_pool)          # (12, 1, 197)
    A_grad = np.maximum(A_grad, 0)
    E_hat  = A_grad.mean(axis=(0, 1))     # (197,)
    per_layer.append(E_hat[1:])
# 之后的融合、reshape、归一化完全一样
```

记忆钩子：**普通 ViT 求"自注意力图"的梯度；池化 ViT 求"池化注意力图"的梯度。其余流程完全相同。**
