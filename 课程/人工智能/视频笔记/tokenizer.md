## 知识点分组

### 1. Tokenizer、BPE 与文本表示

对应笔记：[[../tokenizer/Tokenizer原理与BPE|Tokenizer 原理与 BPE]]

- GPT-2、GPT-4 的空格、连续空格和代码缩进是如何被处理的？
- Tokenizer 和 embedding model 的输入、输出与训练方式有什么区别？

对应笔记：[[../tokenizer/Special Token与Byte Fallback|Special token 与 byte fallback]]

- Byte fallback 如何把未覆盖文本转换为 UTF-8 bytes？它在词表构建、训练编码和推理解码中分别扮演什么角色？

- “模型记忆”与文件、数据库、任务状态等外部持久化有什么区别？

### 4. 多模态表示、回归与扩散

对应笔记：[[../多模态学习/回归模型与扩散模型|回归模型与扩散模型]]
