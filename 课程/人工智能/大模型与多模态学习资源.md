# 大模型与多模态学习资源

> 配合 `aiLearning` 仓库中的 24 周学习计划使用。代码实践放在仓库，概念、论文和源码导读放在本目录。

## 一、推荐原则

资源分为四类：

1. **主教材**：按章节学习，建立系统知识。
2. **从零实现课程**：必须写代码，验证理解。
3. **论文与官方技术报告**：理解模型为什么这样设计。
4. **源码与工程文档**：理解真实模型的 `forward`、缓存、数据和部署。

建议遵循：

```text
先看教材理解概念
 -> 再看论文理解动机
 -> 再读源码理解实现
 -> 最后在 aiLearning 中复现和测试
```

不要把博客、课程和论文全部同时学习。每个阶段保留一个主教材、一个实现项目和若干参考资料即可。

## 二、主教材

### 1. Dive into Deep Learning

- [英文在线版](https://d2l.ai/)
- [Transformer 与 Vision Transformer 章节](https://d2l.ai/chapter_attention-mechanisms-and-transformers/index.html)

**定位**：深度学习、注意力、Transformer、ViT 的第一本系统教材。

**建议阅读**：

- 2.1-2.6：张量、线性代数、自动微分；
- 7：现代 CNN；
- 11：注意力机制与 Transformer；
- 11.8：Vision Transformer；
- 11.9：大规模 Transformer 预训练。

这本书适合边读边运行代码，优先于零散博客。

### 2. Stanford CS336: Language Modeling from Scratch

- [课程主页](https://cs336.stanford.edu/)
- [课程视频](https://www.youtube.com/playlist?list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV)
- [Assignment 1: Basics](https://github.com/stanford-cs336/assignment1-basics)
- [Assignment 2: Systems](https://github.com/stanford-cs336/assignment2-systems)
- [Assignment 3: Scaling](https://github.com/stanford-cs336/assignment3-scaling)
- [Assignment 4: Data](https://github.com/stanford-cs336/assignment4-data)
- [Assignment 5: Alignment](https://github.com/stanford-cs336/assignment5-alignment)

**定位**：从 BPE tokenizer、Transformer、训练循环、FlashAttention、分布式训练、数据清洗一直做到 SFT 和推理强化学习。

**使用方式**：

- 阶段 1：只完成 Assignment 1；
- 阶段 2：重点学习 Assignment 2 的 Attention 和显存优化；
- 阶段 3：阅读 Assignment 3 的 scaling law；
- 阶段 4：学习 Assignment 5 的 SFT、DPO、GRPO/RL 思路。

CS336 是本学习计划的 LLM 主线，不建议只看视频而跳过作业。

### 3. Hugging Face LLM Course

- [官方课程](https://huggingface.co/learn/llm-course/chapter1/1)
- [Transformers 文档](https://huggingface.co/docs/transformers/index)
- [Model documentation](https://huggingface.co/docs/transformers/model_doc/llama)

**定位**：从自己实现的模型过渡到真实开源模型。

**重点章节**：

- tokenizer 与 datasets；
- Transformers 模型调用和 `generate`；
- Trainer、Accelerate 和 PEFT；
- 数据集处理与微调；
- 推理模型和模型分享。

阅读真实模型源码时，重点关注：

```text
configuration_*.py
modeling_*.py
processing_*.py
generation/
```

### 4. Build a Large Language Model From Scratch

- [作者主页与配套资料](https://sebastianraschka.com/)
- [配套代码仓库](https://github.com/rasbt/LLMs-from-scratch)

**定位**：适合把 Transformer 的每个组件手写一遍。

**重点**：

- BPE tokenizer；
- GPT 架构；
- causal attention；
- pretraining；
- instruction fine-tuning；
- LoRA 和评测。

它比 CS336 更适合第一次完整实现 GPT；CS336 更适合深入训练系统。

## 三、基础解释型资料

### 1. The Illustrated Transformer

- [Jay Alammar: The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/)

适合第一次理解 Q、K、V、Multi-Head Attention 和 Encoder-Decoder。不要把它作为唯一教材，读完后要回到原论文和代码。

### 2. Let's build GPT

- [Andrej Karpathy 视频与代码](https://github.com/karpathy/nanoGPT)

适合建立 decoder-only GPT 的直觉。推荐先阅读 `model.py`，再阅读训练循环和生成逻辑。

### 3. MIT Foundations of Computer Vision

- [Vision Transformer 章节](https://visionbook.mit.edu/transformers.html)

适合补充 ViT、patch token、视觉 Attention、位置编码和 CNN/Transformer 的差异。

### 4. PyTorch Attention 文档

- [Scaled Dot Product Attention](https://pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html)
- [PyTorch SDPA 教程](https://pytorch.org/tutorials/intermediate/scaled_dot_product_attention_tutorial.html)
- [Transformer API](https://pytorch.org/docs/stable/generated/torch.nn.Transformer.html)

学习目标不是只会调用 `MultiheadAttention`，而是理解：

- `(B, T, D)` 如何变成 `(B, H, T, Dh)`；
- causal mask 和 padding mask 的形状；
- SDPA 如何选择 FlashAttention 或其他后端；
- KV cache 为什么能降低增量生成成本。

每篇论文只记录五件事：

```text

训练目标是什么？
计算/显存代价是什么？
后续模型继承或改变了什么？
```

## 五、经典多模态模型资料

### 1. BLIP-2

- [论文](https://arxiv.org/abs/2301.12597)
- [Salesforce LAVIS](https://github.com/salesforce/LAVIS)

重点：Q-Former 如何使用少量 query 从冻结视觉编码器读取信息，并把结果接入 LLM。

### 2. Flamingo

- [论文](https://arxiv.org/abs/2204.14198)
- [DeepMind Perceiver IO](https://arxiv.org/abs/2107.14795)

重点：Perceiver Resampler、交错图文序列、gated cross-attention 和 few-shot multimodal learning。

### 3. LLaVA

- [论文 Visual Instruction Tuning](https://arxiv.org/abs/2304.08485)
- [官方代码](https://github.com/haotian-liu/LLaVA)
- [LLaVA-NeXT](https://github.com/LLaVA-VL/LLaVA-NeXT)

重点：CLIP Vision Tower、MLP Projector、`<image>` 占位符替换、视觉指令数据和两阶段训练。

### 4. Qwen-VL / Qwen2-VL / Qwen2.5-VL

- [Qwen-VL 论文](https://arxiv.org/abs/2308.12966)
- [Qwen2-VL 官方资料](https://qwen2.org/vl/)
- [Qwen2.5-VL 官方发布](https://qwen.ai/blog?id=qwen2.5-vl)
- [Qwen2.5-VL 代码](https://github.com/QwenLM/Qwen2.5-VL)

重点：

- Naive Dynamic Resolution；
- M-RoPE / 2D 与 3D 位置编码；
- Vision Transformer 与 Vision-Language Merger；
- 视频 patch；
- grounding、OCR 和结构化输出。

Qwen2-VL 是从经典连接器路线过渡到成熟视觉语言模型的最佳源码对象之一。

## 六、成熟开源多模态源码

按推荐顺序阅读：

| 模型 | 源码 | 重点 |
|---|---|---|
| LLaVA | [LLaVA](https://github.com/haotian-liu/LLaVA) | 最简单的视觉 token 注入 |
| Qwen2-VL | [Qwen2-VL](https://github.com/QwenLM/Qwen2-VL) | 动态分辨率、M-RoPE、视频 |
| Qwen2.5-VL | [Qwen2.5-VL](https://github.com/QwenLM/Qwen2.5-VL) | OCR、grounding、视觉 Agent |
| InternVL | [InternVL](https://github.com/OpenGVLab/InternVL) | 多尺度图像与高分辨率 |
| Idefics3 | [Idefics3](https://github.com/huggingface/transformers/tree/main/src/transformers/models/idefics3) | Hugging Face 原生多模态实现 |
| Llama 3.2 Vision | [Llama 3.2](https://github.com/meta-llama/llama-models) | Meta 官方视觉适配路线 |
| Gemma | [Gemma](https://github.com/google-deepmind/gemma) | Google 开源模型与配置 |

固定源码阅读顺序：

1. `config`：hidden size、层数、patch size、视觉 token 数；
2. `processor`：图片/视频如何预处理；
3. `vision tower`：输出 patch token 还是 pooled feature；
4. `connector`：Projector、Merger、Q-Former 或 Cross-Attention；
5. `forward`：视觉 token 如何进入文本序列；
6. `position_ids` 与 `attention_mask`；
7. `generate` 与 KV cache；
8. 训练数据和损失函数。

判断一篇新资料是否值得纳入笔记：

1. 是否有论文、官方技术报告或代码；
2. 是否明确区分模型结构和产品系统；
3. 是否给出张量、训练目标或计算复杂度；
4. 是否能通过源码、权重或实验复核；
5. 是否说明版本和发布日期。
