## 基本概念
当发生缺页错误且内存中没有空闲帧时，操作系统必须执行页面置换，将内存中的某个页面换出到后备存储（如磁盘），并将需要的页面调入。页面置换算法的目的是使缺页率降到最低。
为了评估算法，通常使用一个内存引用的页面序列，称为**引用串 (Reference String)**。
假设引用串为：`7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2, 1, 2, 0, 1, 7, 0, 1`，且系统分配了 3 个物理帧。

## 先进先出置换算法 (FIFO)
**原理**：总是淘汰最先进入内存的页面。可以将其理解为一个队列。
**示例流程**（3个物理帧）：
- 访问 7：调入 7，内存为 `[7, -, -]`（缺页）
- 访问 0：调入 0，内存为 `[7, 0, -]`（缺页）
- 访问 1：调入 1，内存为 `[7, 0, 1]`（缺页）
- 访问 2：替换最老的 7，内存为 `[2, 0, 1]`（缺页）
- 访问 0：命中，内存不变 `[2, 0, 1]`
- 访问 3：替换最老的 0，内存为 `[2, 3, 1]`（缺页）
- 访问 0：替换最老的 1，内存为 `[2, 3, 0]`（缺页）
- ...依次类推。

**Belady 异常**：对于 FIFO 算法，有时增加分配的物理帧数，反而会导致缺页率上升。这种现象被称为 Belady 异常。

## 最佳置换算法 (Optimal)
**原理**：替换在未来最长时间内不会被访问的页面。此算法保证了最低的缺页率，且不存在 Belady 异常。
**示例流程**（3个物理帧）：
- 访问 7, 0, 1：内存为 `[7, 0, 1]`（3次缺页）
- 访问 2：未来序列是 `0, 3, 0, 4, 2...`，7 最晚被访问，替换 7，内存为 `[2, 0, 1]`（缺页）
- 访问 0：命中，内存不变 `[2, 0, 1]`
- 访问 3：未来序列是 `0, 4, 2, 3...`，1 最晚被访问，替换 1，内存为 `[2, 0, 3]`（缺页）
- 访问 0：命中，内存不变 `[2, 0, 3]`
- 访问 4：未来序列是 `2, 3, 0...`，0、2、3 都会在未来较早被访问，这里 0 最晚（在 3 和 2 之后），替换 0，内存为 `[2, 4, 3]`（缺页）
- ...依次类推。

**局限性**：由于需要预知未来的引用串，最佳置换算法在实际系统中无法实现，主要用于作为理论基准来评估其他算法的性能。

## 最近最少使用置换算法 (LRU)
**原理**：选择在最近一段时间里最久没有被访问的页面进行替换。它是最佳算法向后看的近似，表现优异且无 Belady 异常。
**示例流程**（3个物理帧）：
- 访问 7, 0, 1：内存为 `[7, 0, 1]`（3次缺页）
- 访问 2：过去最久未用的是 7，替换 7，内存为 `[2, 0, 1]`（缺页）
- 访问 0：命中，更新 0 为最近使用，内存不变 `[2, 0, 1]`
- 访问 3：过去最久未用的是 1，替换 1，内存为 `[2, 0, 3]`（缺页）
- 访问 0：命中，更新 0 为最近使用，内存不变 `[2, 0, 3]`
- 访问 4：过去最久未用的是 2，替换 2，内存为 `[4, 0, 3]`（缺页）
- 访问 2：过去最久未用的是 3，替换 3，内存为 `[4, 0, 2]`（缺页）
- ...依次类推。

**硬件实现**：
1. **计数器**：为每个页表项添加时间使用字段，每次访问更新为系统时钟。替换时寻找时间最早的。
2. **栈**：维护一个页面号的栈，每次访问页面将其移至栈顶。替换时直接淘汰栈底页面。这两种方式都需要大量的硬件支持。

## 近似 LRU 算法
由于纯 LRU 硬件开销大，很多系统采用近似 LRU 算法。硬件为每个页面提供一个**引用位 (Reference Bit)**，初始为 0，访问时设为 1。
- **附加引用位算法**：定期记录引用位的历史。
- **二次机会算法 (Clock 算法)**：基于 FIFO，如果被选中的页面引用位为 1，则给予“二次机会”，将其引用位清零并移到队列末尾，继续检查下一个。
这些算法作为[[按需调页|按需调页]]系统的核心组件，保障了系统在内存紧张时仍能高效运行。
