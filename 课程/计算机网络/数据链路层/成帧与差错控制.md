## 数据链路层概述

数据链路层的主要任务是将易出错的物理链路转化为对网络层来说无差错的逻辑链路。它的核心功能包括成帧 (Framing)、差错控制 (Error Control) 和流量控制 (Flow Control)。在《计算机网络》第5版中，数据链路层通常被划分为逻辑链路控制 (LLC) 子层和[[介质访问控制子层/CSMA_CD与以太网|介质访问控制 (MAC) 子层]]。

## 成帧 (Framing)

物理层传输的是比特流，而数据链路层需要将比特流组合成有意义的块，即“帧”。成帧主要解决帧的定界问题。常用的成帧方法有：

- **字节计数法**：在帧的头部使用一个字段来标明帧内的字符数。一旦计数字段出错，将导致接收端失去同步，后续所有帧的定界都会失败，因此较少单独使用。
- **字节填充的标志字节法**：使用特定的标志字节（如 `0x7E`）作为帧的开始和结束。如果数据中出现了标志字节，则在其前面插入一个转义字节（如 `ESC`）。这种方法依赖于 8 位字节。
- **比特填充的标志比特法**：使用特定的比特模式（如 `01111110`）作为帧界界定符。发送方在数据中遇到连续的五个 `1` 时，自动插入一个 `0`；接收方遇到连续的五个 `1` 后的 `0` 则自动删除。这种方法允许传输任意长度的比特序列。
- **物理层编码违例法**：利用物理层编码中不会用到的信号形式（如曼彻斯特编码中不发生跳变的信号）来作为帧的边界。

## 差错控制 (Error Control)

数据在传输过程中可能会发生比特翻转（0 变 1，1 变 0）。差错控制旨在检测和纠正这些错误。

### 纠错码 (Error-Correcting Codes)
通过在数据中加入足够的冗余信息，使得接收方不仅能发现错误，还能推断出错误的位置并进行纠正。
- **海明码 (Hamming Code)**：利用海明距离的概念，能够纠正单比特错误。假设有 $m$ 个信息位和 $r$ 个校验位，需要满足 $m + r + 1 \leq 2^r$。
	- **算法步骤**：
		1. **确定校验位数量**：根据 $m + r + 1 \leq 2^r$ 求出最小的 $r$。
		2. **确定校验位位置**：校验位被放置在二进制序号为 $2^k$ 的位置上（即第 1, 2, 4, 8... 位），其余位置填充数据位。
		3. **计算校验位的值**：每个校验位负责校验特定位置的数据位。规则是：若数据位的位置编号的二进制表示中第 $k$ 位为 1，则该数据位由第 $2^k$ 个校验位负责校验。通过对负责的数据位进行异或（偶校验），求出每个校验位的值。
		4. **纠错原理**：接收端用同样的方法重新计算校验位，若发现错误，将出错的校验组对应的校验位编号相加，其和即为出错比特的绝对位置。将该位翻转即可纠正错误。
	- **海明码编码示例**：假设要发送的数据为 `1011001`（7位）。
		- 根据公式 $7 + r + 1 \leq 2^r$，解得最小的 $r = 4$。因此编码后的总长度为 11 位。
		- 校验位分别放在 P1, P2, P4, P8 的位置上。

### 检错码 (Error-Detecting Codes)
只在数据中加入少量冗余，使得接收方能发现错误，但无法纠正。通常结合重传机制使用。
- **奇偶校验 (Parity Check)**：添加一个校验位，使数据中 1 的个数为奇数或偶数。只能检测出奇数个比特的错误。
- **校验和 (Checksum)**：将数据划分为多段进行累加，将结果的反码作为校验和附加在数据后。
- **循环冗余校验 (CRC, Cyclic Redundancy Check)**：将数据视为一个多项式，通过生成多项式进行模 2 除法，余数即为帧检验序列 (FCS)。CRC 的检错能力极强，在硬件中极易实现，是数据链路层最常用的检错方法。
	- **算法步骤**：
		1. **选择生成多项式**：收发双方约定一个生成多项式 $G(x)$，假设其阶数为 $r$（即对应的二进制比特串长度为 $r+1$）。
		2. **数据移位**：将发送数据 $M(x)$ 的末尾追加 $r$ 个 0（相当于乘以 $2^r$）。
		3. **模 2 除法计算 FCS**：将追加 0 后的数据比特串对 $G(x)$ 的比特串进行**模 2 除法**（加减法均等同于异或操作，不产生进位或借位）。得到的 $r$ 位余数即为 FCS。
		4. **发送数据**：将原始数据 $M(x)$ 与 FCS 拼接后发送。
		5. **接收端校验**：接收端收到数据后，再次使用相同的 $G(x)$ 进行模 2 除法。如果余数为 0，则认为传输无差错；若余数不为 0，则帧被损坏，直接丢弃。
	- **CRC 校验示例**：
		- 假设发送数据 $M = 101001$，生成多项式 $G(x) = x^3 + x^2 + 1$，其对应的比特串为 `1101`（阶数 $r=3$）。
		- 步骤1：在数据末尾加 3 个 0，变为 `101001000`。
		- 步骤2：用 `101001000` 模 2 除以 `1101`。
			- `1010` $\oplus$ `1101` = `0111`
			- `1110` $\oplus$ `1101` = `0011`
			- `0111` $\oplus$ `1101` = `0010`
			- `0100` $\oplus$ `1101` = `0101`（省略中间若干次下落位计算，最终得到 3 位余数）
		- 假设经过模 2 除法后得到的余数为 `001`，则 FCS 为 `001`。最终发送的数据帧为 `101001001`。

当检测到帧出错时，数据链路层通常会要求发送方重新传输，这依赖于[[滑动窗口协议#自动重传请求 (ARQ)|自动重传请求]]机制。
