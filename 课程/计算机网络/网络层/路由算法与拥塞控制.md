## 路由算法概述

路由器的主要功能是根据转发表（路由表）将到达的数据报转发到正确的输出链路。路由算法决定了如何构建和更新这些转发表。

路由算法大致分为静态路由和动态路由两类。现代互联网主要依赖动态路由算法，它们能根据网络拓扑和流量的变化自动调整路由。

### 距离矢量路由 (Distance Vector Routing)
每个路由器维护一张表，表中列出了到达每个已知目的地的最短距离和下一跳。路由器定期与其相邻路由器交换自己的整张距离矢量表。
- **代表协议**：RIP (Routing Information Protocol)。
- **缺点**：存在“好消息传得快，坏消息传得慢”的计数到无穷大 (Count-to-Infinity) 问题。

### 链路状态路由 (Link State Routing)
每个路由器主动测试其所有相邻链路的状态（如延迟、带宽），并将这些链路状态信息广播（泛洪）给网络中的所有其他路由器。每个路由器最终都会获得整个网络的完整拓扑图，然后利用 Dijkstra 算法独立计算出到达所有节点的最短路径。
- **代表协议**：OSPF (Open Shortest Path First)。
- **优点**：收敛速度快，不易产生路由环路，适合大型网络。

## 层次化路由与 BGP

由于互联网规模极其庞大，要求所有路由器掌握所有目的地的路径是不现实的。因此，互联网采用了分层次的路由结构：
- **自治系统 (AS, Autonomous System)**：由单一机构管理的网络集合。
- **内部网关协议 (IGP)**：用于 AS 内部的路由，如 RIP、OSPF。
- **外部网关协议 (EGP)**：用于 AS 之间的路由。目前互联网标准的 EGP 是 BGP (Border Gateway Protocol)。BGP 是一种路径矢量协议，它不仅考虑距离，更注重不同 AS 之间的策略和商业关系。

## 拥塞控制算法

当网络中存在过多的数据包，导致路由器缓存溢出并丢弃数据包时，就发生了拥塞。网络层的拥塞控制旨在全局性地降低网络负载。

### 拥塞控制策略
1. **流量感知路由**：将流量从拥塞的路径转移到空闲的路径。
2. **准入控制 (Admission Control)**：在虚电路网络中，如果网络已经拥塞，则拒绝建立新的虚电路连接。
3. **流量调节 (Traffic Throttling)**：路由器在检测到拥塞迹象时，向源主机发送抑制报文（Choke Packet），要求其降低发送速率。
4. **负载丢弃 (Load Shedding)**：当拥塞不可避免时，路由器不得不丢弃数据包。丢弃策略可以是随机早期检测 (RED, Random Early Detection)，即在队列完全满之前，以一定概率随机丢弃数据包，以隐式地通知[[传输层/TCP协议与状态机#TCP 流量控制与拥塞控制|传输层的 TCP 协议]]减缓发送速度。
