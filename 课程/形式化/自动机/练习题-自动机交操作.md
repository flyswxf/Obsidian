这是针对两张状态转移图求交集的临时练手笔记，包含了对[[有限状态自动机|FSA]]交集与[[Buchi自动机|Büchi 自动机]]交集的详细推导过程。

## 题目描述

给定两个自动机 $A_1$ 和 $A_2$：
- $A_1 = (\{p_0, p_1, p_2\}, \{a, b\}, \delta_1, p_0, \{p_1\})$
  - 转移包含：$p_0 \xrightarrow{b} p_0$, $p_0 \xrightarrow{a} p_1$, $p_1 \xrightarrow{a} p_1$, $p_1 \xrightarrow{b} p_2$, $p_2 \xrightarrow{b} p_2$, $p_2 \xrightarrow{a} p_0$
- $A_2 = (\{q_0, q_1\}, \{a, b\}, \delta_2, q_0, \{q_1\})$
  - 转移包含：$q_0 \xrightarrow{a} q_0$, $q_0 \xrightarrow{b} q_1$, $q_1 \xrightarrow{b} q_1$, $q_1 \xrightarrow{a} q_0$

---

## 第一问：求有限自动机的交（15分）

根据[[自动机交操作#形式化定义|有限自动机交集构造法]]，乘积自动机状态集为笛卡尔积 $Q_1 \times Q_2$，初始状态为 $(p_0, q_0)$，接受状态必须同时属于 $F_1$ 和 $F_2$，即唯一接受状态为 $(p_1, q_1)$。

**可达状态转移计算**：
- 初始：$(p_0, q_0)$
  - 输入 $a$：$p_0 \xrightarrow{a} p_1, q_0 \xrightarrow{a} q_0 \implies (p_1, q_0)$
  - 输入 $b$：$p_0 \xrightarrow{b} p_0, q_0 \xrightarrow{b} q_1 \implies (p_0, q_1)$
- 从 $(p_1, q_0)$：
  - 输入 $a$：$p_1 \xrightarrow{a} p_1, q_0 \xrightarrow{a} q_0 \implies (p_1, q_0)$
  - 输入 $b$：$p_1 \xrightarrow{b} p_2, q_0 \xrightarrow{b} q_1 \implies (p_2, q_1)$
- 从 $(p_0, q_1)$：
  - 输入 $a$：$p_0 \xrightarrow{a} p_1, q_1 \xrightarrow{a} q_0 \implies (p_1, q_0)$
  - 输入 $b$：$p_0 \xrightarrow{b} p_0, q_1 \xrightarrow{b} q_1 \implies (p_0, q_1)$
- 从 $(p_2, q_1)$：
  - 输入 $a$：$p_2 \xrightarrow{a} p_0, q_1 \xrightarrow{a} q_0 \implies (p_0, q_0)$
  - 输入 $b$：$p_2 \xrightarrow{b} p_2, q_1 \xrightarrow{b} q_1 \implies (p_2, q_1)$

**结果与分析**：
可以观察到，在所有生成的可达状态集合 $\{(p_0, q_0), (p_1, q_0), (p_0, q_1), (p_2, q_1)\}$ 中，并不包含接受状态 $(p_1, q_1)$。
- 逻辑分析：在 $A_1$ 中，要进入接受状态 $p_1$，最后一次输入必须是 $a$。而在 $A_2$ 中，要进入接受状态 $q_1$，最后一次输入必须是 $b$。一个有限长度的字符串不可能同时以 $a$ 和 $b$ 结尾。
- **结论**：这两个有限自动机的交集语言为空集 $\emptyset$。

## 第二问：求无限自动机的交（5分）

在处理 $\omega$-字时，必须采用带有 Phase（1和2）标记的[[自动机交操作#Büchi 自动机的交操作|Büchi 交集算法]]，以确保两个自动机的接受状态都能被无限次交替访问。

状态形式为 $(p_i, q_j, k)$，其中 $k \in \{1, 2\}$ 为追踪标志。
- 初始状态：$s_1 = (p_0, q_0, 1)$
- 接受状态：$F = F_1 \times Q_2 \times \{1\} = \{(p_1, q_0, 1), (p_1, q_1, 1)\}$

**转移过程推导（包含状态切相）**：
1. **当前标志位 1（等待 $A_1$ 接受状态 $p_1$）**：
   - 从 $s_1(p_0, q_0, 1)$：由于 $p_0 \notin F_1$，标志位保持 1。
     - $\xrightarrow{a} (p_1, q_0, 1) = s_2$ （此状态即为接受状态！）
     - $\xrightarrow{b} (p_0, q_1, 1) = s_3$
   - 从 $s_3(p_0, q_1, 1)$：由于 $p_0 \notin F_1$，标志位保持 1。
     - $\xrightarrow{a} (p_1, q_0, 1) = s_2$
     - $\xrightarrow{b} (p_0, q_1, 1) = s_3$
   - 从 $s_2(p_1, q_0, 1)$：由于 $p_1 \in F_1$，标志位翻转至 **2**。
     - $\xrightarrow{a} (p_1, q_0, 2) = s_4$
     - $\xrightarrow{b} (p_2, q_1, 2) = s_5$
   - 从 $(p_2, q_1, 1) = s_6$（由相 2 翻转而来）：由于 $p_2 \notin F_1$，标志保持 1。
     - $\xrightarrow{a} (p_0, q_0, 1) = s_1$
     - $\xrightarrow{b} (p_2, q_1, 1) = s_6$

2. **当前标志位 2（等待 $A_2$ 接受状态 $q_1$）**：
   - 从 $s_4(p_1, q_0, 2)$：由于 $q_0 \notin F_2$，标志保持 2。
     - $\xrightarrow{a} (p_1, q_0, 2) = s_4$
     - $\xrightarrow{b} (p_2, q_1, 2) = s_5$
   - 从 $s_5(p_2, q_1, 2)$：由于 $q_1 \in F_2$，标志位翻转至 **1**。
     - $\xrightarrow{a} (p_0, q_0, 1) = s_1$
     - $\xrightarrow{b} (p_2, q_1, 1) = s_6$

**结果自动机图**：

一共得到了 6 个可达状态，最终的 Büchi 交集自动机如下所示，唯一的接受状态是 $(p_1, q_0, 1)$：

![[assets/practice_buchi_intersection.svg]]

只要无限长序列中包含无穷多个 $a$ 和 $b$（从而形成环路不断经过 $s_2$ 翻转到相 2，并在 $s_5$ 翻转回相 1），该输入就能被接收。
