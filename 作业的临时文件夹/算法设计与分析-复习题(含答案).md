## 0. 伪代码与算法基础（PPT L1 + 笔记）

### 0.1 概念题

1. 题目：给出“算法”的两个必要条件（按 PPT 的表述）。
   - 答案：
     - 指令必须足够精确，能机械实现。
     - 指令条数必须有限（有限步结束）。

2. 题目：区分“计算问题（problem）”“实例（instance）”“解（solution）”。
   - 答案：
     - problem：输入输出关系的规范化描述。
     - instance：某个具体输入（如排序的输入序列）。
     - solution：对该 instance 的输出，满足 problem 的规范。

3. 题目：写伪代码时，为什么赋值用 `←` 或 `:=`，而不是 `=`？
   - 答案：避免与“相等比较”混淆，使语义清晰且语言无关。

4. 题目：给出一种对算法正确性的常见证明结构。
   - 答案：循环不变式三段式（初始化、保持、终止）或数学归纳法（基例、归纳步）。

### 0.2 伪代码快速题

5. 题目：写伪代码 `FindMin(A)`，返回数组最小值（下标从 1）。
   - 答案：
     ```text
     FindMin(A):
       m <- A[1]
       for i <- 2 to A.length:
         if A[i] < m:
           m <- A[i]
       return m
     ```

6. 题目：写伪代码 `Swap(A[i], A[j])` 并说明它的抽象意义。
   - 答案：把“交换”当作原子操作即可，不展开临时变量细节也可；抽象意义是强调算法层面步骤而非语言语法。

## 1. 渐近记号与增长阶（CLRS Ch3 + 作业 1-1/1-2）

### 1.1 定义与关系

7. 题目：写出 $O(g(n))$ 的形式化定义。
   - 答案：存在常数 $c>0,n_0$，使得 $\forall n\ge n_0: 0\le f(n)\le c\,g(n)$。

8. 题目：证明 $f(n)=\Theta(g(n)) \iff f(n)=O(g(n))$ 且 $f(n)=\Omega(g(n))$。
   - 答案：
     - “$\Rightarrow$”：由 $\Theta$ 的夹逼定义直接得上下界。
     - “$\Leftarrow$”：取 $O$ 的常数为 $c_2$，$\Omega$ 的常数为 $c_1$，令统一阈值为两者阈值的最大值即可。

9. 题目：在渐近正前提下，给出 $f=o(g)$ 的极限判别。
   - 答案：$\lim_{n\to\infty} \frac{f(n)}{g(n)} = 0$。

10. 题目：判断正误：$f=O(g)\Rightarrow g=O(f)$。
   - 答案：错误。反例：$f(n)=1,g(n)=n$。

11. 题目：判断正误：对渐近正函数，总有 $f(n)+g(n)=\Theta(\min\{f(n),g(n)\})$。
   - 答案：错误；正确结论是 $f(n)+g(n)=\Theta(\max\{f(n),g(n)\})$。

12. 题目：判断正误：若 $f=O(g)$ 且 $f,g\ge 1$ 且 $\lg g(n)\ge 1$（充分大时），则 $\lg f = O(\lg g)$。
   - 答案：正确。用 $f\le c g \Rightarrow \lg f \le \lg c + \lg g \le (1+\lg c)\lg g$（当 $\lg g\ge 1$）。

13. 题目：判断正误：$f=O(g)\Rightarrow 2^{f}=O(2^{g})$。
   - 答案：错误。取 $f(n)=2n,g(n)=n$，则 $2^{2n}/2^{n}=2^n$ 无界。

### 1.2 增长阶排序（精选）

14. 题目：证明 $n^{1/\lg n}=2$（$\lg$ 为 2 底对数）。
   - 答案：$n^{1/\lg n}=(2^{\lg n})^{1/\lg n}=2$。

15. 题目：比较 $\lg^* n$ 与 $\ln\ln n$ 的增长速度（谁更大？）。
   - 答案：$\ln\ln n$ 更快；$\lg^* n$ 增长极慢（迭代对数）。

16. 题目：证明 $(\sqrt{2})^{\lg n}=\sqrt{n}$。
   - 答案：$(\sqrt{2})^{\lg n} = 2^{\frac{1}{2}\lg n} = \sqrt{2^{\lg n}}=\sqrt{n}$。

17. 题目：比较 $(\lg n)!$ 与 $n^3$ 的增长速度。
   - 答案：$(\lg n)!$ 更快。令 $x=\lg n$，比较 $x!$ 与 $2^{3x}$；阶乘支配指数 $a^x$（常数 $a$）。

## 2. 递归式与主定理（CLRS Ch4 + 作业 4-1/4.5-5）

### 2.1 主定理基础

18. 题目：主定理适用的递归式标准形式是什么？
   - 答案：$T(n)=aT(n/b)+f(n)$，其中 $a\ge 1,b>1,f(n)$ 渐近非负。

19. 题目：对 $T(n)=2T(n/2)+\Theta(n)$ 用主定理求解。
   - 答案：$n^{\log_b a}=n$，$f(n)=\Theta(n)$ 属 Case 2（$k=0$），故 $T(n)=\Theta(n\lg n)$。

20. 题目：对 $T(n)=7T(n/2)+\Theta(n^2)$ 用主定理求解。
   - 答案：$n^{\log_2 7}\approx n^{2.807}$，$n^2$ 多项式更小，Case 1，$T(n)=\Theta(n^{\log_2 7})$。

21. 题目：对 $T(n)=4T(n/2)+n^3$ 用主定理求解，并验证正则条件。
   - 答案：$n^{\log_2 4}=n^2$，$f(n)=n^3=\Omega(n^{2+1})$；且 $4f(n/2)=4(n/2)^3=n^3/2\le c n^3$（取 $c=3/4$），故 Case 3，$T(n)=\Theta(n^3)$。

22. 题目：解释主定理 Case 3 的“正则条件”起到的作用。
   - 答案：保证递归树每层的 $f(n/b^i)$ 按几何级数衰减，根层主导不被破坏。

23. 题目：给出一个满足 Case 3 的比较例子：$a=2,b=2,f(n)=n^2$，写出 $c$。
   - 答案：$2f(n/2)=2(n/2)^2=n^2/2 \le c n^2$，取 $c=1/2$。

### 2.2 主定理不适用与替代法

24. 题目：主定理为什么不直接适用于 $T(n)=4T(n/2)+\frac{n^2}{\lg n}$？
   - 答案：$n^{\log_2 4}=n^2$，但 $f(n)=n^2/\lg n$ 既不是 $O(n^{2-\varepsilon})$，也不是 $\Theta(n^2(\lg n)^k)$（$k\ge 0$），也不是 $\Omega(n^{2+\varepsilon})$。

25. 题目：用递归树求 $T(n)=4T(n/2)+\frac{n^2}{\lg n}$ 的渐近解。
   - 答案：第 $j$ 层总非递归代价为 $\frac{n^2}{\lg n-j}$，求和为 $n^2\sum_{i=1}^{\lg n}\frac{1}{i}=\Theta(n^2\lg\lg n)$。

26. 题目：求解 $T(n)=T(n-2)+n^2$。
   - 答案：展开得到平方和，$T(n)=\Theta\!\left(\sum_{k\le n}k^2\right)=\Theta(n^3)$。

27. 题目：作业 4.5-5 的核心结论是什么？（只写结论与关键理由）
   - 答案：该例子满足 Case 3 的增长比较，但不满足正则条件；关键在于 $\sin(\ln n)$ 使比例 $\frac{a f(n/b)}{f(n)}$ 无法被某个 $c<1$ 上界住。

## 3. 比较排序与下界（CLRS Ch8/Ch9 + 作业 6/8/9）

### 3.1 决策树模型

28. 题目：用决策树证明任何比较排序最坏时间下界为 $\Omega(n\lg n)$ 的核心不等式是什么？
   - 答案：$n!\le 2^h \Rightarrow h\ge \lg(n!)=\Theta(n\lg n)$。

29. 题目：为什么需要 $n!$ 个叶子？
   - 答案：比较排序必须区分所有输入排列；不同排列必须落在不同叶子才能输出正确排序结果。

30. 题目：用 Stirling 近似给出 $\lg(n!)$ 的主项。
   - 答案：$\lg(n!)=n\lg n - n\lg e + \Theta(\lg n)$。

31. 题目（作业 8.1-3 风格）：若某比较排序在至少 $\alpha(n)$ 比例输入上比较次数 $\le c n$，写出必须满足的不等式。
   - 答案：$\alpha(n)\,n!\le 2^{cn}$。

### 3.2 归并排序

32. 题目：写出 MergeSort 的递归式，并给出解。
   - 答案：$T(n)=2T(n/2)+\Theta(n)=\Theta(n\lg n)$。

33. 题目：归并排序稳定的原因是什么？
   - 答案：合并时遇到相等键值，优先取左侧元素即可保持相对次序。

### 3.3 快速排序与随机化

34. 题目：快速排序最坏 $O(n^2)$ 的输入模式是什么？
   - 答案：每次分区都极端不平衡（pivot 总在端点，如总选最小或最大）。

35. 题目（作业 7.3-2 风格）：RANDOMIZED-QUICKSORT 在最好/最坏情况下调用随机数生成器的次数量级。
   - 答案：都是 $\Theta(n)$（每个非平凡子数组做一次随机分区；形成满二叉树时内部节点 $n-1$）。

36. 题目：解释“随机化”为什么能把期望时间变为 $O(n\lg n)$。
   - 答案：随机 pivot 使分区平衡的期望良好，期望递归深度为 $O(\lg n)$，每层总代价 $O(n)$。

37. 题目（作业 7.4-5 风格）：IntroSort 思想：当子数组规模 $\le k$ 时改用插入排序。写出整体时间的一个合理模型并说明如何选 $k$。
   - 答案：可写成 $T(n,k)\approx a\,n\log(n/k)+b\,n\,k$；$k$ 取小常数并用实验微调。

### 3.4 堆排序

38. 题目：0 基数组表示堆时，父/左/右孩子下标公式是什么？
   - 答案：$parent(i)=\lfloor(i-1)/2\rfloor$，$left(i)=2i+1$，$right(i)=2i+2$。

39. 题目：为什么 Build-Heap 是 $O(n)$ 而不是 $O(n\lg n)$？
   - 答案：不同高度节点下滤代价不同，按高度求和：$\sum_h \frac{n}{2^{h+1}}\Theta(h)=\Theta(n)$。

40. 题目：堆排序是否稳定？为什么？
   - 答案：不稳定；交换堆顶与末尾会改变相等元素相对次序。

### 3.5 非比较排序

41. 题目：计数排序的时间与空间复杂度分别是多少？
   - 答案：时间 $\Theta(n+k)$，空间 $\Theta(n+k)$（$k$ 为键域大小）。

42. 题目：计数排序稳定性的关键步骤是什么？
   - 答案：对输入从右到左扫描，并用前缀和位置递减放入输出数组。

43. 题目：基数排序为什么必须使用稳定的子排序？
   - 答案：稳定性保证高位排序时不破坏已建立的低位有序性（归纳证明）。

44. 题目（作业 8.3-4 风格）：对 $n$ 个范围 $[0,n^3-1]$ 的整数排序，如何在 $O(n)$ 时间完成？
   - 答案：用基数排序，按 $r=\lg n$ 位分 3 趟，单趟 $\Theta(n+2^r)=\Theta(n)$，总 $\Theta(3n)$。

45. 题目：桶排序平均线性成立的关键假设是什么？最坏情况为何是 $\Theta(n^2)$？
   - 答案：元素近似均匀独立落桶；最坏所有元素落入同一桶，桶内排序退化到 $\Theta(n^2)$。

46. 题目（作业 8.4-2 风格）：如何把桶排序最坏时间改到 $O(n\lg n)$ 且保持平均线性？
   - 答案：桶内用 $O(m\lg m)$ 最坏排序（如归并），则 $\sum m_i\lg m_i\le n\lg n$；平均仍可用 $\mathbf{E}[m_i\lg m_i]\le \mathbf{E}[m_i^2]=O(1)$ 推得 $\Theta(n)$。

## 4. 选择与随机化（CLRS Ch9 + 笔记 RandomSelect）

47. 题目：Rand-Select 的期望时间为什么是 $\Theta(n)$？
   - 答案：期望满足 $T(n)=T(U)+\Theta(n)$ 且 $\mathbf{E}[U]\le cn$（常数 $c<1$），由期望递归深度控制得线性。

48. 题目：Rand-Select 最坏为什么是 $O(n^2)$？
   - 答案：每次 pivot 都是最小/最大导致递归规模 $n-1$，递推 $T(n)=T(n-1)+\Theta(n)=\Theta(n^2)$。

49. 题目：Median-of-Medians（BFPRT）最坏线性时间的关键不等式是什么？
   - 答案：每次至少丢弃常数比例元素，可写 $T(n)\le T(n/5)+T(7n/10)+\Theta(n)$（或类似），代换法得 $\Theta(n)$。

50. 题目：解释为什么分组大小常取 5 而不是 3。
   - 答案：分组过小无法保证足够多元素被丢弃，递推中系数和可能 $\ge 1$，无法压到线性。

## 5. 分治典型题（CLRS Ch4）

### 5.1 最大子数组

51. 题目：最大子数组分治算法的三种候选情况是什么？
   - 答案：完全在左、完全在右、跨越中点（左最佳后缀 + 右最佳前缀）。

52. 题目：写出跨越中点最大子数组的线性求法（思路级）。
   - 答案：从 mid 向左累加取最大后缀；从 mid+1 向右累加取最大前缀；两者相加。

53. 题目：最大子数组分治复杂度为何是 $\Theta(n\lg n)$？
   - 答案：递推 $T(n)=2T(n/2)+\Theta(n)$，主定理 Case 2。

54. 题目（作业 4.1-5 风格）：给出线性时间的最大子数组算法（Kadane）递推含义。
   - 答案：维护 $bestEnd[j]=\max(A[j],bestEnd[j-1]+A[j])$，全局最大为 $\max_j bestEnd[j]$。

### 5.2 逆序对

55. 题目：证明插入排序运行时间是 $\Theta(I)$，其中 $I$ 为逆序对数量。
   - 答案：每次把当前元素向左移动的步数等于与它形成逆序对的较大元素数量；总移动等于总逆序对。

56. 题目：如何在归并排序合并阶段统计跨左右子数组的逆序对？
   - 答案：合并时若右元素 $R[j]<L[i]$，则产生 $|L|-i+1$ 个逆序对。

### 5.3 两数和判定

57. 题目：给出“两数和判定”在排序后用双指针的循环不变式。
   - 答案：每轮后区间 $[i,j]$ 保留所有仍可能组成 $x$ 的候选对；若 $S[i]+S[j]<x$ 则 $i$ 左侧都不可能；若 $>x$ 则 $j$ 右侧都不可能。

58. 题目：两数和判定总时间复杂度是多少？
   - 答案：排序 $O(n\lg n)$ + 扫描 $O(n)$，合计 $O(n\lg n)$。

## 6. 图：基础、存储、遍历（CLRS Ch22 + 笔记）

### 6.1 基础与表示

59. 题目：邻接矩阵与邻接表的空间复杂度分别是多少？
   - 答案：邻接矩阵 $O(V^2)$；邻接表 $\Theta(V+E)$。

60. 题目：无向图的握手引理是什么？
   - 答案：$\sum_{v\in V}\deg(v)=2|E|$。

61. 题目：对 4 个顶点无向图（无自环），邻接矩阵最少需要存多少 bit？
   - 答案：只存上三角且不含对角线，$V(V-1)/2=6$ bit。

### 6.2 BFS

62. 题目：BFS 用什么数据结构？在无权图中得到什么性质？
   - 答案：队列；得到从源点出发的最短路（按边数）。

63. 题目：BFS 的时间复杂度在邻接表表示下是多少？
   - 答案：$O(V+E)$。

64. 题目（作业 22.2-6 风格）：构造一个图，使得某个“最短路径树”无法由 BFS 生成，并说明原因。
   - 答案：同层顶点对下一层顶点的父指针分配会被 BFS 的先入队顶点“抢占”，导致某些最短路径树结构不可实现（见作业中的 $s,a,b,c,d$ 例子）。

### 6.3 DFS

65. 题目：DFS 的三色标记各代表什么状态？
   - 答案：白未发现；灰已发现未完成（在递归栈）；黑已完成。

66. 题目：括号定理（Parenthesis Theorem）的结论是什么？
   - 答案：任意两顶点区间 $[d,f]$ 要么嵌套要么不相交；$v$ 为 $u$ 后代当且仅当 $u.d<v.d<v.f<u.f$。

67. 题目：白色路径定理的结论是什么？
   - 答案：$v$ 是 $u$ 后代当且仅当在 $u.d$ 时刻存在一条从 $u$ 到 $v$ 的全白路径。

68. 题目：有向图 DFS 的边分类有哪些？如何用颜色/时间识别“后向边”？
   - 答案：树边、后向边、前向边、横向边；遇到灰色顶点即后向边（指向祖先，说明有环）。

69. 题目：无向图 DFS 为什么不会产生前向边/横向边？
   - 答案：无向边被双向探索，非树边只可能连向祖先（后向边），不会形成有向图中的前向/横向类型。

70. 题目（作业 22.3-9 风格）：给出一个反例否定猜想“若有路径 $u\leadsto v$ 则必有 $v.d\le u.f$”。
   - 答案：用作业中的 3 点有向图即可：边 $(1,2),(1,3),(2,1)$；DFS 得 $2.f<3.d$。

### 6.4 Universal Sink

71. 题目：通用汇点（universal sink）的定义是什么？
   - 答案：出度为 0，入度为 $V-1$。

72. 题目：给出在邻接矩阵模型下 $O(V)$ 找通用汇点的算法要点。
   - 答案：用候选指针 $i$ 扫一遍列：若 $A[i][j]=1$ 则 $i=j$；扫完验证第 $i$ 行全 0 且第 $i$ 列（除对角）全 1。

## 7. 最小生成树（CLRS Ch23 + 作业 23.*）

73. 题目：定义“切割（cut）”与“轻边（light edge）”。
   - 答案：切割是 $(S,V-S)$；横跨切割且权重最小的边为轻边（可能不唯一）。

74. 题目：切割性质（cut property）的结论是什么？
   - 答案：对任意切割，其轻边必属于某棵 MST。

75. 题目（作业 23.1-3）：证明 MST 中任意边 $(u,v)$ 是其移除产生切割的轻边。
   - 答案：反证；若存在更轻横跨边替换，则得到更小权生成树，矛盾。

76. 题目（作业 23.1-4）：说明“把所有可能成为某切割轻边的边收集起来”不一定得到 MST。
   - 答案：等权三角形图中三条边都可能是某切割的轻边，但三条边构成环，不是树。

77. 题目：Kruskal 的核心数据结构是什么？总复杂度主要由什么决定？
   - 答案：并查集；主要由边排序 $O(E\lg E)$ 决定（并查集摊还 $O(E\alpha(V))$）。

78. 题目（作业 23.2-4）：若边权是 $1..|V|$ 的整数，如何把 Kruskal 排序阶段降到 $O(E+V)$？
   - 答案：用计数排序（键域 $k=|V|$）。

79. 题目：Prim 用二叉堆实现的复杂度是多少？斐波那契堆实现是多少？
   - 答案：二叉堆 $O(E\lg V)$；斐波那契堆 $O(E+V\lg V)$。

80. 题目：Prim 为什么是“加点”的贪心？Kruskal 为什么是“加边”的贪心？
   - 答案：Prim 维护已入树顶点集合 $S$，每次选跨割最轻边把新顶点并入；Kruskal 维护森林，每次选最轻且不成环的边合并分量。

## 8. 最短路径（CLRS Ch24 + 作业 24.*）

### 8.1 松弛与性质

81. 题目：写出 `RELAX(u,v,w)` 的伪代码与含义。
   - 答案：若 $v.d>u.d+w(u,v)$ 则更新 $v.d,u.\pi$；含义是用通过 $u$ 的路径改进 $v$ 的最短路估计。

82. 题目：说明最短路径的最优子结构性质。
   - 答案：最短路径上的任意子路径仍是对应端点间的最短路径，否则可替换得到更短整体路径，矛盾。

83. 题目：写出三角不等式在最短路中的形式。
   - 答案：$\delta(s,v)\le \delta(s,u)+w(u,v)$（对任意边 $(u,v)$）。

### 8.2 Dijkstra 与 Bellman-Ford

84. 题目：Dijkstra 的适用条件是什么？为什么不能有负边？
   - 答案：边权非负；负边会破坏贪心“已出队顶点距离已最优”的性质。

85. 题目：Bellman-Ford 的时间复杂度是多少？它能检测什么？
   - 答案：$O(VE)$；能检测从源点可达的负权环。

86. 题目：解释 Bellman-Ford “最多 $V-1$ 条边” 的核心原因。
   - 答案：简单路径最多含 $V-1$ 条边；若存在更长则必含环，若无负环可去环不增代价。

87. 题目（作业 24.1-4）：如何把受负环影响的所有顶点距离设为 $-\infty$？给出思路级步骤。
   - 答案：标准 BF 后再扫一遍边，凡仍可松弛的顶点入队并标为 $-\infty$，再在图上从这些点做 BFS/DFS，把所有可达点也标为 $-\infty$。

88. 题目（作业 24.3-4）：如何在 $O(V+E)$ 时间验证一组 $(d,\pi)$ 是否是一棵合法的最短路径树输出？
   - 答案：检查源点；对每顶点验证 $d$ 与 $\pi$ 边一致性；对每条边检查松弛不等式 $v.d\le u.d+w(u,v)$；必要时检查 $\pi$ 无环。

89. 题目（作业 24.3-6）：最大化路径可靠性乘积 $\prod r(e)$ 如何转为最短路？
   - 答案：取权 $w(e)=-\log r(e)\ge 0$，最大化乘积等价于最小化 $\sum w(e)$，用 Dijkstra。

## 9. 最大流最小割（CLRS Ch26 + 作业 26.* + 笔记）

### 9.1 定义与定理

90. 题目：写出流的容量限制与流量守恒约束。
   - 答案：
     - 容量：$0\le f(u,v)\le c(u,v)$。
     - 守恒：对 $u\notin\{s,t\}$，$\sum_v f(v,u)=\sum_v f(u,v)$。

91. 题目：残量网络 $G_f$ 中，正向边与反向边的残量容量分别是什么？
   - 答案：正向 $c_f(u,v)=c(u,v)-f(u,v)$；反向 $c_f(v,u)=f(u,v)$（当 $f(u,v)>0$）。

92. 题目：最大流最小割定理的内容是什么？
   - 答案：最大流值等于最小割容量：$|f_{\max}|=C_{\min}$。

### 9.2 算法题

93. 题目：Ford-Fulkerson 方法的基本循环是什么？
   - 答案：在残量网络中找增广路，沿路按瓶颈残量增广；直到不存在增广路。

94. 题目：Edmonds-Karp 的关键改动是什么？复杂度是多少？
   - 答案：用 BFS 找最短边数增广路；复杂度 $O(VE^2)$。

95. 题目：Dinic 的两阶段结构是什么？（只写关键点）
   - 答案：BFS 建层次图；在层次图上多次 DFS 找阻塞流；重复直到 $t$ 不可达。

96. 题目（作业 26.1-7）：如何把“点容量”转为“边容量”？
   - 答案：每个点 $v$ 拆为 $v_{in},v_{out}$，加边 $(v_{in},v_{out})$ 容量为点容量；原边 $(u,v)$ 变为 $(u_{out},v_{in})$。

97. 题目（作业 26.2-4）：解释“cancel flow”在残量网络中的含义。
   - 答案：通过反向边增广等价于撤销先前在某条边上的部分流量，从而重新分配以增加总流。

## 10. 动态规划（CLRS Ch15 + 作业 15.*）

### 10.1 钢条切割（Rod Cutting）

98. 题目（作业 15.1-3）：若每次切割需支付成本 $c$，写出递推式 $r_n$。
   - 答案：$r_0=0$，$r_n=\max\left(p_n,\max_{1\le i<n}(p_i+r_{n-i}-c)\right)$。

99. 题目：给出自底向上的 DP 伪代码思路级结构（不要求细节）。
   - 答案：for $j=1..n$，令 $q=p[j]$，再枚举第一段 $i=1..j-1$ 用 $p[i]+r[j-i]-c$ 更新，最后 $r[j]=q$。

100. 题目：上述算法时间复杂度是多少？
   - 答案：外层 $n$，内层均摊 $O(n)$，总 $\Theta(n^2)$。

### 10.2 矩阵链乘法

101. 题目：矩阵链乘法的 DP 状态 $m[i,j]$ 表示什么？
   - 答案：计算 $A_i\cdots A_j$ 的最小标量乘法次数。

102. 题目：写出矩阵链乘法的转移式。
   - 答案：$m[i,j]=\min_{i\le k<j}\{m[i,k]+m[k+1,j]+p_{i-1}p_k p_j\}$。

103. 题目（作业 15.2-2）：如何用 $s[i,j]$ 递归输出最优括号化（只写思路伪代码级）。
   - 答案：若 $i=j$ 返回 $A_i$；令 $k=s[i,j]$，递归构造 $(i,k)$ 与 $(k+1,j)$ 后再相乘。

104. 题目（作业 15.2-4）：矩阵链乘法子问题图顶点数与边数分别是多少？
   - 答案：顶点数 $\frac{n(n+1)}{2}$；边数 $\frac{n^3-n}{3}$。

## 11. 综合题（偏考试风格）

105. 题目：给出一个递归式，主定理可用但容易错判 Case 2 的 $k$，并给出正确结论。
   - 答案：例如 $T(n)=2T(n/2)+n\lg n$，此时 $f(n)=\Theta(n^{\log_2 2}(\lg n)^1)$，Case 2（$k=1$），结论 $T(n)=\Theta(n(\lg n)^2)$。

106. 题目：对比“比较排序下界 $\Omega(n\lg n)$”与“计数排序 $\Theta(n+k)$”并解释矛盾在哪里。
   - 答案：下界只适用于基于比较的排序；计数排序不比较元素大小，利用键域结构突破模型假设。

107. 题目：给出一个包含负边但无负环的图，说明 Dijkstra 可能失败的具体方式。
   - 答案：构造使得某顶点先被确定为“最短”，但之后通过负边得到更短路径；Dijkstra 不会再更新已出队顶点导致错误。

108. 题目：对同一个无向连通图，说明 MST 不一定唯一的条件。
   - 答案：存在相同权重的可替换边（例如某个环上有等权边），导致多棵权重相同的生成树。

109. 题目：说明“最大流值等于最小割容量”如何用来做正确性证书（certificate）。
   - 答案：给出一组流 $f$ 与一个割 $(S,T)$，若 $|f|=C(S,T)$，则二者分别是最大流与最小割（由弱对偶与等号成立）。

110. 题目：给出一个同时涉及排序与图的综合题：在带权边集按权排序后，用 Kruskal 构造 MST。写出总复杂度（按 $V,E$）。
   - 答案：$O(E\lg E + E\alpha(V))=O(E\lg V)$。

## 附录 B：自然演绎（来自临时文件夹 homework.md）

114. 题目：证明：$\forall x(\exists y\,P(x,y)\to Q(x)) \vdash \forall x(\forall y\,P(x,y)\to Q(x))$，写出证明骨架（只写主要规则序列）。
   - 答案：取新参数 $x_0$，由 $\forall$ 消去得到 $\exists y P(x_0,y)\to Q(x_0)$；假设 $\forall y P(x_0,y)$，用 $\forall$ 消去得 $P(x_0,y_0)$，再 $\exists$ 引入得 $\exists y P(x_0,y)$，用 $\to$ 消去得 $Q(x_0)$，再 $\to$ 引入，最后对 $x_0$ 做 $\forall$ 引入。

115. 题目：解释在全称引入（$\forall$-introduction）中“新参数”侧条件的意义。
   - 答案：保证证明不依赖于该参数的特殊性质，从而可推广到任意个体。
