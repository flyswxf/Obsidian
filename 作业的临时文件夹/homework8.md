## 22.1-6
![[Pasted image 20251214113917.png]]

算法步骤如下：

1. **寻找候选者**:
   维护一个候选者 $i$。最初令 $i=1$。
   遍历 $j = 2$ 到 $|V|$：
   - 如果 $A[i][j] == 1$：说明 $i$ 有一条出边指向 $j$，因此 $i$ 不可能是universal sink（出度必须为0）。所以将 $i$ 更新为 $j$ 作为新的潜在候选者。
   - 如果 $A[i][j] == 0$：说明 $i$ 没有出边指向 $j$，因此 $j$ 不可能是universal sink（必须与所有其他节点的连接）。保持 $i$ 不变，继续检查下一个 $j$。
   循环结束后，只有 $i$ 可能是通用汇点。

2. **验证候选者**:
   验证 $i$ 是否真的是通用汇点。这需要检查：
   - $i$ 的行全为 0（出度为 0）。
   - $i$ 的列（除了 $A[i][i]$）全为 1（入度为 $|V|-1$）。

**完整算法代码**:

```cpp
bool UniversalSink(const vector<vector<int>>& A) {
    int n = A.size();
    int i = 0;
    for (int j = 1; j < n; ++j) {
        if (A[i][j] == 1) {
            i = j;
        }
    }
    for (int j = 0; j < n; ++j) {
        if (A[i][j] == 1) return false;
        if (i != j && A[j][i] == 0) return false;
    }
    return true;
}
```

**时间复杂度**:
步骤 1 进行 $|V|-1$ 次矩阵查询，时间为 $O(V)$。步骤 2 进行 $2|V|$ 次矩阵查询，时间为 $O(V)$。
因此总时间复杂度为 $O(V)$。

## 22.2-6
![[Pasted image 20251214125827.png]]
考虑有向图 $G=(V, E)$ 如下：
- 顶点: $V = \{s, a, b, c, d\}$
- 边: $E = \{(s, a), (s, b), (a, c), (a, d), (b, c), (b, d)\}$
- $s$出发的最短路径: $E_{\pi} = \{(s, a), (s, b), (a, c), (b, d)\}$

**验证 $E_{\pi}$ 是$s$出发的最短路径**:
- $s \to a$: 路径 $s \to a$，长度 1（最短）。
- $s \to b$: 路径 $s \to b$，长度 1（最短）。
- $s \to c$: 路径 $s \to a \to c$，长度 2（最短，另一条 $s \to b \to c$ 长度也为 2）。
- $s \to d$: 路径 $s \to b \to d$，长度 2（最短，另一条 $s \to a \to d$ 长度也为 2）。
因此，$E_{\pi}$ 中包含的路径均为 $G$ 中的最短路径。

**证明 BFS 无法生成 $E_{\pi}$**:
BFS 从 $s$ 开始，第一层节点为 $\{a, b\}$。
无论邻接表中 $a$ 和 $b$ 的顺序如何，BFS 只有两种情况：

1.  **先访问 $a$** (即 $Adj[s] = [a, b]$):
    - 队列初始为 $[a, b]$。
    - 弹出 $a$，访问 $a$ 的所有未访问邻居 $\{c, d\}$。
    - 边 $(a, c)$ 和 $(a, d)$ 被加入树中。
    - 此时 $d$ 的父节点变成了 $a$。
    - 这与 $E_{\pi}$ 中的 $(b, d)$ 矛盾。

2.  **先访问 $b$** (即 $Adj[s] = [b, a]$):
    - 队列初始为 $[b, a]$。
    - 弹出 $b$，访问 $b$ 的所有未访问邻居 $\{c, d\}$。
    - 边 $(b, c)$ 和 $(b, d)$ 被加入树中。
    - 此时 $c$ 的父节点变成了 $b$。
    - 这与 $E_{\pi}$ 中的 $(a, c)$ 矛盾。

因此，无论邻接表顺序如何，BFS 都无法生成 $E_{\pi}$，因为它总是倾向于让同一层中先访问的节点尽可能多地抢占下一层的子节点，而无法将子节点让出给到同一层的其他节点

## 22.3-9
![[Pasted image 20251214142530.png]]

考虑有向图 $G=(V, E)$: 
- 顶点: $V = \{1, 2, 3\}$
- 边: $E = \{(1, 2), (1, 3), (2, 1)\}$

假设 DFS 从顶点 1 开始搜索，且在顶点 1 的邻接表中，2 排在 3 之前。
1.  在时刻 1，发现顶点 1 ($1.d = 1$)。
2.  在时刻 2，从 1 发现顶点 2 ($2.d = 2$)。
3.  顶点 2 的唯一邻居是 1，但 1 已经被发现（且未完成），所以边 $(2, 1)$ 是后向边。2 没有其他邻居。
4.  在时刻 3，顶点 2 完成 ($2.f = 3$)。
5.  DFS 回溯到顶点 1。
6.  在时刻 4，从 1 发现顶点 3 ($3.d = 4$)。
7.  在时刻 5，顶点 3 完成 ($3.f = 5$)。
8.  在时刻 6，顶点 1 完成 ($1.f = 6$)。

根据题目中猜想的描述, 在该图中存在从 $u=2$ 到 $v=3$ 的路径 $2 \to 1 \to 3$, 则有$v.d \le u.f$ (即 $3.d \le 2.f$)。但是实际结果为$3.d = 4$， $2.f = 3$, 即 $v.d > u.f$。因此，猜想不成立。
