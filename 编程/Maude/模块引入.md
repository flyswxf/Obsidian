## 常用模块

| 模块    | 是否默认加入所有模块       | 说明                                                                    |
| ------- | -------------------------- | ----------------------------------------------------------------------- |
| `TRUTH` | 是（自动加入其内置操作符） | 提供 `if_then_else_fi`、`_==_`、`_=/=_`，三者自动、多态、在所有模块可用 |
| `BOOL`  | 是（自动 including）       | 布尔运算 `_and_`、`_or_`、`xor`、`not` 等，默认自动包含到每个模块       |
| `NAT`   | 否                         | 需显式导入（自然数）                                                    |
| `INT`   | 否                         | 需显式导入（整数）                                                      |

## 导入方式
`protecting MODULE .`/`pr MODULE .`
  - 语义承诺：保守扩展，不改变被导入理论的性质（运行期不强制检查）。
  - 适用：明确希望保证语义不被破坏时。
`including MODULE .`/`inc MODULE .`
  - 语义：普通包含，不作“保护”承诺（运行期效果与 protecting 等价）。
  - 适用：不确定是否满足保护条件时，优先使用以避免虚假声明。

**示例**
```python
mod USE-NUM is
  protecting NAT .      -- 或 pr NAT .
  including INT .       -- 显式包含另一个预定义模块
endm
```
