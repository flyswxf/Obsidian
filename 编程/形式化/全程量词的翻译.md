# Rule U.G
![[Pasted image 20250325215247.png]]
- Rule U.G说明在论证时, **全程量词**可以直接消去, 这是因为在证明过程中, 要证明自由变量的条件成立, 已经包含了**对任意取值都成立**的隐含条件
- 需要保证变量名无冲突.
	- 若条件中有P(x), 即**X这个变量名已经使用过**, 且需要满足P. 此时可以将全称量词翻译为**新的变量名**, 如H1(Y), 以区分
