### Assignment 7：验证 Hoare 三元组（Sort 的部分正确性）

要验证
$$\{\,P\,\}\ \texttt{Sort}\ \{\,Q\,\}$$
其中
$$P \equiv (n>0)\ \land\ \forall k\,(0\le k<n \to a[k]\in \mathbb N)$$
$$Q \equiv \forall i,j\,(0\le i\le j<n \to a[i]\le a[j])$$

程序（冒泡排序）为：
```c
i = 0;
while (i < n-1) {
  j = 0;
  while (j < n-i-1) {
    if (a[j] > a[j+1]) {
      temp = a[j];
      a[j] = a[j+1];
      a[j+1] = temp;
    }
    j = j + 1;
  }
  i = i + 1;
}
```

#### 外层循环不变式

定义外层循环不变式 $I(i)$：
$$I(i)\equiv (0\le i\le n-1)\ \land\ S(i)\ \land\ R(i)\ \land\ N(a)$$
其中
$$S(i)\equiv \forall p,q\,(n-i\le p\le q<n\to a[p]\le a[q])$$
表示后缀 $a[n-i..n-1]$ 已经非降序排好；
$$R(i)\equiv \forall p,q\,(0\le p<n-i\land n-i\le q<n\to a[p]\le a[q])$$
表示前缀任一元素都不大于该后缀任一元素；
$$N(a)\equiv \forall k\,(0\le k<n\to a[k]\in\mathbb N)$$
表示数组元素仍在 $\mathbb N$ 中（交换不会破坏该性质）。

**初始化**：执行 `i = 0` 后，$0\le i\le n-1$ 成立（由 $n>0$ 得 $n-1\ge 0$）。此时后缀区间 $[n..n-1]$ 为空，$S(0)$ 与 $R(0)$ 都真值空泛成立；$N(a)$ 由前置条件 $P$ 给出。因此 $I(0)$ 成立。

**保持性**：假设某次外层循环开始时 $I(i)$ 成立且条件 $i<n-1$ 为真。需证明执行一轮内层循环并做 `i=i+1` 后得到 $I(i+1)$。
关键是证明：内层循环结束时，位置 $n-i-1$ 上是前缀 $a[0..n-i-1]$ 的最大值，从而它可以作为“新增的已排好后缀元素”。

#### 内层循环不变式（固定外层 i）

令 $m=n-i-1$（内层循环的右端点）。定义内层循环不变式 $J(j)$：
$$J(j)\equiv (0\le j\le m)\ \land\ a[j]=\max(a[0..j])\ \land\ S(i)\ \land\ R(i)\ \land\ N(a)$$

**初始化**：`j=0` 后，$a[0]=\max(a[0..0])$ 显然成立；其余部分由外层不变式 $I(i)$ 继承。因此 $J(0)$ 成立。

**保持性**：假设 $J(j)$ 成立且 $j<m$。循环体比较 $a[j]$ 与 $a[j+1]$：
- 若 $a[j]\le a[j+1]$，不交换，则 $a[j+1]\ge a[j]=\max(a[0..j])$，所以 $a[j+1]=\max(a[0..j+1])$；
- 若 $a[j]>a[j+1]$，交换后 $a[j+1]$ 变为原来的 $a[j]$，而原来的 $a[j]$ 又等于 $\max(a[0..j])$，因此交换后仍有 $a[j+1]=\max(a[0..j+1])$。

同时该交换仅发生在下标 $\le m$ 的前缀范围内，不影响已排好后缀 $a[n-i..n-1]$ 的有序性与前后缀大小关系；并且交换不改变元素属于 $\mathbb N$ 的事实。因此执行 `j=j+1` 后得到 $J(j+1)$。

**终止**：当内层循环结束时 $j=m$，由 $J(m)$ 得
$$a[m]=\max(a[0..m])=\max(a[0..n-i-1]).$$
即位置 $n-i-1$ 上是尚未放入后缀部分的最大元素。

#### 回到外层保持性

内层结束后执行 `i=i+1`，新的后缀起点从 $n-i$ 变为 $n-(i+1)=n-i-1=m$。由上面的结论，$a[m]$ 是前缀最大值，所以对任意 $p<m$ 有 $a[p]\le a[m]$；而旧后缀 $a[n-i..n-1]$ 已满足 $S(i)$ 且所有前缀元素都不大于旧后缀元素（$R(i)$）。因此把 $a[m]$ 接到旧后缀左边后，新的后缀 $a[n-(i+1)..n-1]$ 仍然整体非降序，且新的前缀 $a[0..n-(i+1)-1]$ 仍不大于新的后缀任一元素，于是 $S(i+1)$ 与 $R(i+1)$ 成立；$N(a)$ 仍保持成立；并且 $0\le i+1\le n-1$ 也成立。因此 $I(i+1)$ 得证。

**终止推出后置条件**：外层循环退出时 $\neg(i<n-1)$，即 $i\ge n-1$。又由不变式 $0\le i\le n-1$，可知必有 $i=n-1$。
代入 $I(n-1)$：
- $S(n-1)$ 给出后缀 $a[1..n-1]$ 非降序；
- $R(n-1)$ 给出 $a[0]\le a[q]$ 对所有 $1\le q<n$ 成立。

于是对任意 $0\le i\le j<n$：
- 若 $i=0$，由 $R(n-1)$ 得 $a[0]\le a[j]$；
- 若 $i\ge 1$，由 $S(n-1)$ 得 $a[i]\le a[j]$。

因此 $Q$ 成立，从而 $\{P\}\ \texttt{Sort}\ \{Q\}$ 的**部分正确性**得到验证（不要求证明一定终止）。
