# 谓词（Predicate）

- 定义：关于对象性质或关系的陈述式，随参数取值返回真/假。
- 记号：一元谓词 `P(x)`，二元谓词 `R(x,y)`，n 元谓词 `R(x1,…,xn)`。
- 论域：变量取值的范围，必须先约定。

> [!example] 示例
> - S(x)：x 是学生
> - T(x,y)：y 是 x 的老师
> - Even(n)：n 是偶数

> [!note] 命题 vs. 谓词
> - 给定具体参数后，谓词实例化为命题：如 `S(小明)`。
> - 含自由变量的谓词本身不是命题；需用量词绑定，见 [[全称量词]]。

> [!tip] 变量的自由与约束
> - 自由变量：未被量词绑定的变量。
> - 约束变量：被量词绑定的变量。例：`∀x S(x)` 中的 `x` 是约束变量。

> [!warning] 常见误区
> - 论域未声明或变化导致歧义。建议在首处写明：如“设论域为所有学生”。
> - 把 `∀x S(x)` 误读为存在一个特定 x；应读作“对于所有 x”。

与量词配合的常见形式：
```
∀x∈D. P(x)         对所有 x 属于 D，P(x) 成立
∃x∈D. P(x)         存在某个 x 属于 D，使 P(x) 成立
```

更多量词用法见 [[全称量词]]。
