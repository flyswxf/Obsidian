# 命题（Proposition）

- 定义：仅取真/假（T/F）的可判定陈述句，不含自由变量。
- 示例：
  - P：明天会下雨。
  - Q：2 是偶数。

> [!note] 逻辑连接词
> 常用：¬（否定）、∧（且）、∨（或）、→（蕴涵）、↔（等价）。
> 书写示例：`P ∧ ¬Q`，`P → Q`。

> [!example] 真值直觉
> - ¬P 为真当且仅当 P 为假。
> - P ∧ Q 为真当且仅当 P、Q 都真。
> - P ∨ Q 为真当且仅当至少一真。
> - P → Q 等价于 ¬P ∨ Q。
> - P ↔ Q 等价于 (P → Q) ∧ (Q → P)。

> [!tip] 常用等价
> - 德摩根：¬(P ∧ Q) ≡ ¬P ∨ ¬Q；¬(P ∨ Q) ≡ ¬P ∧ ¬Q
> - 逆否：P → Q ≡ ¬Q → ¬P
> - 吸收：P ∨ (P ∧ Q) ≡ P；P ∧ (P ∨ Q) ≡ P

> [!warning] 常见误区
> - 把“P → Q”理解为因果；它是逻辑关系，不必有因果。
> - 将含自由变量的陈述当作命题；应先实例化或量化，见 [[谓词]]、[[全称量词]]。

优先级（从高到低）：¬ > ∧ > ∨ > → > ↔。必要时使用括号以避免歧义。

简短真值表示：
```
P → Q  ≡  ¬P ∨ Q
P ↔ Q  ≡  (P → Q) ∧ (Q → P)
```

LaTeX 记法（Obsidian 支持）：`$\neg, \land, \lor, \to, \leftrightarrow$`
