## A. 均衡数

### 题目摘要

给定常数 `2026202620262026`，把“二进制中 `1` 和 `0` 数量相同”的正整数称为均衡数。求与该常数距离最近的均衡数；若有多个，取较小者。

### 核心思路

设原数二进制长度为 $51$。均衡数二进制长度必须是偶数，因此只需考虑：

- 长度为 $50$ 的最大均衡数：前 $25$ 位为 `1`，后 $25$ 位为 `0`
- 长度为 $52$ 的最小均衡数：首位 `1`，再接 $26$ 个 `0`，最后接 $25$ 个 `1`

比较两者与原数的距离即可。

### 答案

`2251799847239679`

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 2251799847239679LL << '\n';
    return 0;
}
```

## B. 量子 2048

### 题目摘要

求一个 $2048 \times 2048$ 的 `0/1` 矩阵个数，要求：

- 每一行 `1` 的个数为奇数
- 每一列 `1` 的个数为奇数
- 任意 $2 \times 2$ 子矩阵中 `1` 的个数为奇数

结果对 `998244353` 取模。

### 核心思路

把矩阵元素视为模 $2$ 意义下的值。

任意 $2 \times 2$ 子矩阵和为奇数，说明内部元素一旦给定第一行和第一列，其余位置都被唯一确定。  
因此自由变量个数先是：

$$
2048 + 2048 - 1 = 4095
$$

再结合“所有行奇”“所有列奇”，最终只留下两个独立约束，因此可行方案数为：

$$
2^{4095-2} = 2^{4093}
$$

计算：

$$
2^{4093} \bmod 998244353 = 618395416
$$

### 答案

`618395416`

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long qpow(long long a, long long b, long long mod) {
    long long res = 1 % mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

int main() {
    const long long MOD = 998244353;
    cout << qpow(2, 4093, MOD) << '\n';
    return 0;
}
```

## C. 拦截程序

### 题目摘要

数据包当前位置有两种可能：$P_A = V \times T$，$P_B = L - V \times T$。  
选择整数坐标 $P$ 部署拦截程序，使得：

$$
\max(|P-P_A|, |P-P_B|)
$$

最小。

### 核心思路

最优点就是两点中点附近的整数点。  
答案等于两点距离的一半向上取整：

$$
\left\lceil \frac{|P_A - P_B|}{2} \right\rceil
$$

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int C;
    cin >> C;
    while (C--) {
        long long L, V, T;
        cin >> L >> V >> T;
        long long pa = V * T;
        long long pb = L - V * T;
        cout << (llabs(pa - pb) + 1) / 2 << '\n';
    }
    return 0;
}
```

## D. 切割木材

### 题目摘要

有 $N$ 根木材，长度分别为 $A_i$。最多切 $K$ 刀。  
求最小可行挡板间距 $L$，使切割后所有木段长度都不超过 $L$。

### 核心思路

答案具有单调性，二分最小可行 $L$。

对于一根长度为 $x$ 的木材，若要求每段都不超过 $L$，最少需要切：

$$
\left\lceil \frac{x}{L} \right\rceil - 1
$$

也可写成：

$$
\frac{x-1}{L}
$$

对所有木材求和，若总切刀数不超过 $K$，则当前 $L$ 可行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    long long r = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        r = max(r, a[i]);
    }

    auto check = [&](long long lim) {
        long long need = 0;
        for (long long x : a) {
            need += (x - 1) / lim;
            if (need > k) return false;
        }
        return need <= k;
    };

    long long l = 1;
    while (l < r) {
        long long mid = (l + r) >> 1;
        if (check(mid)) r = mid;
        else l = mid + 1;
    }
    cout << l << '\n';
    return 0;
}
```

## E. 读取指令

### 题目摘要

有 $N$ 个连续扇区，第 $i$ 个扇区数据量为 $C \times i$。  
每次可读取一个连续区间，且各扇区最多读一次。  
要求恰好读取 $W$ 字节，求最少读取次数；无解输出 `-1`。

### 核心思路

先把公共因子 $C$ 除掉。令：

$$
K = \frac{W}{C}
$$

若 $W \bmod C \ne 0$，显然无解。  
若 $K = 0$，答案是 `0`。  
若：

$$
1+2+\cdots+N < K
$$

也无解。

关键结论：有解时答案一定不超过 `2`。

因此只需判断能否用 `1` 个区间完成；若不能，则答案一定是 `2`。

设区间长度为 `len`，左端点为 `l`，则区间和为：

$$
K = len \cdot l + \frac{len(len-1)}{2}
$$

枚举 `len`，检查是否能得到合法整数 `l` 即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        long long n, c, w;
        cin >> n >> c >> w;

        if (w == 0) {
            cout << 0 << '\n';
            continue;
        }
        if (w % c != 0) {
            cout << -1 << '\n';
            continue;
        }

        long long k = w / c;
        if (k > n * (n + 1) / 2) {
            cout << -1 << '\n';
            continue;
        }

        bool one = false;
        for (long long len = 1; len <= n; len++) {
            long long base = len * (len - 1) / 2;
            if (base >= k) break;
            long long rem = k - base;
            if (rem % len != 0) continue;
            long long l = rem / len;
            if (1 <= l && l + len - 1 <= n) {
                one = true;
                break;
            }
        }

        cout << (one ? 1 : 2) << '\n';
    }
    return 0;
}
```

## F. 外卖配送

### 题目摘要

有 $N$ 个订单，必须按顺序分成若干批配送。  
每批可独立选择一种交通工具，第 $i$ 种工具处理长度为 $L$ 的一批时耗时：

$$
L \times A_i + \frac{L(L-1)}{2} \times B_i
$$

从第二批开始，每新开一批额外加固定代价 $X$。求最小总耗时。

### 核心思路

先预处理：

$$
cost[L] = \min_i \left( L A_i + \frac{L(L-1)}{2} B_i \right)
$$

再做线性 DP：

$$
dp[i] = \text{送完前 } i \text{ 单的最小代价}
$$

转移：

$$
dp[i] = \min_{0 \le j < i} \{ dp[j] + cost[i-j] + [j>0]\times X \}
$$

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    long long x;
    cin >> n >> m >> x;

    const long long INF = (1LL << 62);
    vector<long long> cost(n + 1, INF), dp(n + 1, INF);

    for (int i = 0; i < m; i++) {
        long long a, b;
        cin >> a >> b;
        for (int len = 1; len <= n; len++) {
            long long cur = 1LL * len * a + 1LL * len * (len - 1) / 2 * b;
            cost[len] = min(cost[len], cur);
        }
    }

    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = cost[i];
        for (int j = 1; j < i; j++) {
            dp[i] = min(dp[i], dp[j] + x + cost[i - j]);
        }
    }

    cout << dp[n] << '\n';
    return 0;
}
```

## G. 综合应变指标

### 题目摘要

把序列分成 `4` 个连续非空子段，最大化四段区间和绝对值之和。

### 核心思路

设前缀和为 $s[i]$。  
定义：

$$
dp[t][i] = \text{前 } i \text{ 个数分成 } t \text{ 段时的最大值}
$$

转移：

$$
dp[t][i] = \max_{t-1 \le j < i}\{dp[t-1][j] + |s[i]-s[j]|\}
$$

拆绝对值：

$$
dp[t][i] =
\max \Big(
s[i] + \max(dp[t-1][j]-s[j]),
-s[i] + \max(dp[t-1][j]+s[j])
\Big)
$$

这样每层只需线性扫一遍，总复杂度 $O(4N)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n + 1), s(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s[i] = s[i - 1] + a[i];
    }

    const long long NEG = -(1LL << 60);
    vector<long long> prev(n + 1, NEG), cur(n + 1, NEG);

    for (int i = 1; i <= n; i++) {
        prev[i] = llabs(s[i]); // 1 段
    }

    for (int part = 2; part <= 4; part++) {
        fill(cur.begin(), cur.end(), NEG);
        long long best1 = NEG, best2 = NEG;
        for (int i = part; i <= n; i++) {
            int j = i - 1;
            best1 = max(best1, prev[j] - s[j]);
            best2 = max(best2, prev[j] + s[j]);
            cur[i] = max(s[i] + best1, -s[i] + best2);
        }
        prev.swap(cur);
    }

    cout << prev[n] << '\n';
    return 0;
}
```

## H. 基因研究

### 题目摘要

长度为 $n$ 的随机基因串，每个位置独立，且 `A/T/G/C` 的概率已给出（模 `998244353`）。  
给定长度为 $m$ 的模式串 $s$。求随机串中“至少出现一次 $s$”的概率，结果按模意义输出。

### 核心思路

这是“模式串出现概率”问题。  
核心是把“当前后缀与模式串前缀匹配了多长”作为状态，用 `KMP 自动机` 转移。

定义：

$$
dp[i][j] = \text{考虑前 } i \text{ 位，当前最长匹配前缀长度为 } j \text{ 的概率}
$$

其中：

- 状态 `0..m-1` 表示尚未完整匹配
- 状态 `m` 设为吸收态，表示已经至少出现一次模式串

每读入一个字符，就按 KMP 自动机从旧状态跳到新状态，并乘上该位置字符概率。

复杂度：

$$
O(nm|\Sigma|) = O(4nm)
$$

适合本题范围。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

static const long long MOD = 998244353;

int id(char c) {
    if (c == 'A') return 0;
    if (c == 'T') return 1;
    if (c == 'G') return 2;
    return 3; // C
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    string pat;
    cin >> pat;

    vector<array<long long, 4>> prob(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> prob[i][0] >> prob[i][1] >> prob[i][2] >> prob[i][3];
    }

    // KMP 前缀函数
    vector<int> pi(m, 0);
    for (int i = 1; i < m; i++) {
        int j = pi[i - 1];
        while (j > 0 && pat[i] != pat[j]) j = pi[j - 1];
        if (pat[i] == pat[j]) j++;
        pi[i] = j;
    }

    // nxt[state][c]：当前匹配到 state 位，再加入字符 c 后的新状态
    vector<array<int, 4>> nxt(m + 1);
    const string alpha = "ATGC";
    for (int st = 0; st < m; st++) {
        for (int c = 0; c < 4; c++) {
            int j = st;
            while (j > 0 && pat[j] != alpha[c]) j = pi[j - 1];
            if (pat[j] == alpha[c]) j++;
            nxt[st][c] = j;
        }
    }
    for (int c = 0; c < 4; c++) nxt[m][c] = m; // 吸收态

    vector<long long> dp(m + 1, 0), ndp(m + 1, 0);
    dp[0] = 1;

    for (int i = 1; i <= n; i++) {
        fill(ndp.begin(), ndp.end(), 0);
        for (int st = 0; st <= m; st++) {
            if (dp[st] == 0) continue;
            for (int c = 0; c < 4; c++) {
                int to = (st == m ? m : nxt[st][c]);
                if (to == m) to = m;
                ndp[to] = (ndp[to] + dp[st] * prob[i][c]) % MOD;
            }
        }
        dp.swap(ndp);
    }

    cout << dp[m] % MOD << '\n';
    return 0;
}
```

## 小结

这套 A 组的整体结构很典型：

- A、B：结论型填空
- C、D：模拟 / 二分
- E：数论结论 + 枚举
- F、G：动态规划
- H：字符串自动机 + 概率 DP

1. 先把 `D 切割木材`、`F 外卖配送`、`G 综合应变指标` 单独各刷一遍
2. 再专项补 `KMP 自动机 / AC 自动机`
3. 最后回看 `B` 和 `E` 这类结论题，训练赛场推导速度
