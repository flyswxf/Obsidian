### 知识点1：最长递增子序列（LIS）

（已有笔记[最长递增子序列（LIS）.md](file:///d:/Obsidian/编程/算法/动态规划/最长递增子序列（LIS）.md)，此处补充扩展应用）

#### 蓝桥杯真题应用：最长公共子序列（LCS）转LIS
**题目**：两个数组，求最长公共子序列。当其中一个数组元素互不相同，可O(n log n)解决。

**输入样例**：
```
5
1 2 3 4 5
2 4 3 5 1
```
**输出样例**：
```
3  // 如 2 3 5
```

**思考推导**：
1. **切入点**：将a中元素映射为位置，对b中每个元素查对应位置，求位置序列的LIS即为LCS。
2. **边界条件**：b中元素不在a中则跳过。
3. **易错点**：仅当a元素互不相同才能使用，否则需要普通O(nm)DP。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <unordered_map>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    vector<int> a(n), b(n);
    unordered_map<int, int> pos;
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
        pos[a[i]] = i; // 记录 a[i] 在 a 中的位置
    }
    vector<int> seq;
    for (int i = 0; i < n; i++) {
        scanf("%d", &b[i]);
        // b[i] 如果也出现在 a 中，就把它转成“在 a 里的位置”
        if (pos.count(b[i])) seq.push_back(pos[b[i]]);
    }

    // 问题已经转成：求位置序列 seq 的最长严格递增子序列
    vector<int> tails;
    for (int x : seq) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x); // 可以接在当前最长 LIS 后面
        } else {
            *it = x; // 用更小的结尾替换，方便后面接更长序列
        }
    }
    printf("%d\n", tails.size());
    return 0;
}
```

### 知识点2：数字三角形/最小路径和

#### 核心原理
从底部向上DP或从顶部向下DP，每格取上方/左上方最小值。

#### C++ 实现
```cpp
// 数字三角形：从顶到底，路径数字和最大
int triangleDP(vector<vector<int>>& tri) {
    int n = tri.size();
    for (int i = n-2; i >= 0; i--)
        for (int j = 0; j <= i; j++)
            tri[i][j] += max(tri[i+1][j], tri[i+1][j+1]);
    return tri[0][0];
}
```

## 二、区间DP

### 知识点1：区间DP通用框架

#### 核心原理
状态表示为区间[l,r]，按区间长度从小到大枚举，大区间由小区间合并得到。

**状态转移通式**：
$$dp[l][r] = \min_{k=l}^{r-1}(dp[l][k] + dp[k+1][r]) + cost(l,r)$$

#### 实现思路
1. 枚举区间长度len从2到n（len=1为边界）
2. 枚举左端点l，右端点r=l+len-1
3. 枚举分割点k，合并左右区间

#### C++ 标准实现框架
```cpp
for (int len = 2; len <= n; len++) {       // 区间长度
    for (int l = 1; l + len - 1 <= n; l++) { // 左端点
        int r = l + len - 1;               // 右端点
        dp[l][r] = INF;
        for (int k = l; k < r; k++) {      // 分割点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost);
        }
    }
}
```

#### 蓝桥杯真题应用：石子合并
**题目**：n堆石子排成一排，每次合并相邻两堆，代价为两堆之和。求合并成一堆的最小代价。（$n \le 300$）

**输入样例**：
```
4
1 3 5 2
```
**输出样例**：
```
22
```

**思考推导**：
1. **切入点**：最后一次合并一定是左边连续一段和右边连续一段，典型区间DP。
2. **边界条件**：dp[i][i]=0，单堆无需合并。用前缀和快速算区间和。
3. **易错点**：初始化dp[l][r]为INF，且顺序必须按长度枚举。

**模拟过程**：石子[1,3,5,2]，前缀和s=[0,1,4,9,11]
- len=2: dp[1][2]=4, dp[2][3]=8, dp[3][4]=7
- len=3: dp[1][3]=min(dp[1][1]+dp[2][3]+s[3]-s[0]=0+8+9=17, dp[1][2]+dp[3][3]+s[3]-s[0]=4+0+9=13) → 13
- len=4: dp[1][4]=min(k=1:0+dp[2][4]+11, k=2:4+dp[3][4]+11, k=3:13+0+11)
  - dp[2][4]=min(dp[2][2]+dp[3][4]+7=0+7+7=14, dp[2][3]+dp[4][4]+7=8+0+7=15)=14
  - k=1: 0+14+11=25; k=2: 4+7+11=22; k=3: 13+0+11=24 → 取22

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(n+1), s(n+1, 0);
    vector<vector<int>> dp(n+1, vector<int>(n+1, 1e9));
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        s[i] = s[i-1] + a[i];
        dp[i][i] = 0;
    }
    for (int len = 2; len <= n; len++) {
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            for (int k = l; k < r; k++) {
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + s[r] - s[l-1]);
            }
        }
    }
    printf("%d\n", dp[1][n]);
    return 0;
}
```

## 三、背包问题

### 知识点1：01背包

#### 核心原理
n件物品，每件选或不选，体积v[i]，价值w[i]，背包容量V，求最大价值。

**状态**：$dp[i][j]$ = 前i件物品，容量j时最大价值。

**转移**：
$$dp[j] = \max(dp[j], dp[j-v[i]] + w[i])$$

**空间优化**：一维数组，**倒序枚举容量**，保证每件物品只选一次。

#### C++ 标准实现
```cpp
int knapsack01(int n, int V, vector<int>& v, vector<int>& w) {
    vector<int> dp(V + 1, 0);
    for (int i = 0; i < n; i++)
        for (int j = V; j >= v[i]; j--)
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
    return dp[V];
}
```

### 知识点2：完全背包

#### 核心原理
每种物品可选无限件。一维数组，**正序枚举容量**。

```cpp
int knapsackComplete(int n, int V, vector<int>& v, vector<int>& w) {
    vector<int> dp(V + 1, 0);
    for (int i = 0; i < n; i++)
        for (int j = v[i]; j <= V; j++)
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
    return dp[V];
}
```

### 知识点3：多重背包

#### 核心原理
第i种物品最多选s[i]件。优化方法：**二进制拆分**，将s[i]拆分为$2^0, 2^1, ...$的组合，转为01背包。

#### C++ 实现（二进制优化）
```cpp
int knapsackMultiple(int n, int V, vector<int>& v, vector<int>& w, vector<int>& s) {
    vector<int> dp(V + 1, 0);
    for (int i = 0; i < n; i++) {
        int cnt = s[i];
        for (int k = 1; cnt > 0; k <<= 1) {
            int t = min(k, cnt);
            int vi = v[i] * t, wi = w[i] * t;
            for (int j = V; j >= vi; j--)
                dp[j] = max(dp[j], dp[j - vi] + wi);
            cnt -= t;
        }
    }
    return dp[V];
}
```

#### 蓝桥杯真题应用：买书
**题目**：4本书价格分别为10,20,50,100，每本数量不限。花N元有多少种买法？

**输入样例**：`20`
**输出样例**：`2` （10×2 或 20×1）

**思考推导**：
1. **切入点**：完全背包求方案数，dp[j]表示花j元的方案数。
2. **边界条件**：dp[0]=1（不花钱有一种方案）。
3. **易错点**：求方案数累加而非max，且是完全背包（正序）。

```cpp
int main() {
    int N; scanf("%d", &N);
    vector<int> books = {10, 20, 50, 100};
    vector<int> dp(N+1, 0);
    dp[0] = 1;
    for (int v : books)
        for (int j = v; j <= N; j++)
            dp[j] += dp[j - v];
    printf("%d\n", dp[N]);
    return 0;
}
```

## 四、树形DP

### 知识点1：没有上司的舞会（经典树DP）

#### 核心原理
树结构上的DP，通常以子树为状态，先递归处理子节点，回溯时计算父节点。

**经典模型**：选父则不能选子节点（最大独立集）。

**状态**：
- $dp[u][0]$：不选u节点，以u为根子树的最大价值
- $dp[u][1]$：选u节点，以u为根子树的最大价值

**转移**：
$$dp[u][1] = w[u] + \sum dp[v][0]$$
$$dp[u][0] = \sum \max(dp[v][0], dp[v][1])$$

#### C++ 实现
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<vector<int>> g;
vector<int> happy;
vector<vector<int>> dp;

void dfs(int u, int fa) {
    dp[u][1] = happy[u];
    dp[u][0] = 0;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        dp[u][1] += dp[v][0];
        dp[u][0] += max(dp[v][0], dp[v][1]);
    }
}

int main() {
    int n; scanf("%d", &n);
    happy.resize(n+1); g.resize(n+1);
    dp.assign(n+1, vector<int>(2));
    for (int i = 1; i <= n; i++) scanf("%d", &happy[i]);
    vector<bool> isRoot(n+1, true);
    for (int i = 0; i < n-1; i++) {
        int u, v; scanf("%d%d", &v, &u);
        g[u].push_back(v); isRoot[v] = false;
    }
    int root = 1;
    for (int i = 1; i <= n; i++) if (isRoot[i]) root = i;
    dfs(root, -1);
    printf("%d\n", max(dp[root][0], dp[root][1]));
    return 0;
}
```

#### 蓝桥杯真题应用：树的中心（二次扫描/换根DP思想）
**题目**：求树中到最远节点距离最小的节点。
**思考推导**：两次DFS，第一次求子树内最远距离，第二次求换根后经过父节点的最远距离。

## 五、状态压缩DP

### 知识点1：位运算表示集合状态

#### 核心原理
用整数的二进制位表示集合，1表示选，0表示不选。适合N≤20的小集合问题。

#### 实现思路
1. 枚举状态S（0到2^N-1）
2. 利用位运算转移

#### 常用位运算
```
取第k位: S >> k & 1
设置第k位: S | (1 << k)
清空第k位: S & ~(1 << k)
lowbit: S & -S
枚举子集: for (int sub = S; sub; sub = (sub-1)&S)
```

#### 蓝桥杯真题应用：最短Hamilton路径（旅行商简化版）
**题目**：n个点的完全图，从0出发经过所有点恰好一次的最短路径（$n \le 20$）

**输入样例**：
```
4
0 1 2 3
1 0 4 5
2 4 0 1
3 5 1 0
```
**输出样例**：
```
6  // 0→1→2→3, 长度1+4+1=6
```

**思考推导**：
1. **切入点**：n=20，$2^{20} \approx 10^6$可以承受。
2. **状态定义**：`dp[S][j]`=经过集合S中的点，最后停在j点的最短路。
3. **转移**：枚举j的前驱k，`dp[S][j] = min(dp[S][j], dp[S-(1<<j)][k] + w[k][j])`
4. **边界条件**：`dp[1<<0][0] = 0`。
5. **易错点**：枚举顺序必须按集合大小递增。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    vector<vector<int>> w(n, vector<int>(n));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            scanf("%d", &w[i][j]);
    vector<vector<int>> dp(1<<n, vector<int>(n, 1e9));
    dp[1][0] = 0;
    for (int S = 1; S < (1<<n); S++) {
        if (!(S & 1)) continue; // 必须包含起点0
        for (int j = 0; j < n; j++) {
            if (!(S >> j & 1)) continue;
            int prev = S - (1 << j);
            for (int k = 0; k < n; k++) {
                if (prev >> k & 1)
                    dp[S][j] = min(dp[S][j], dp[prev][k] + w[k][j]);
            }
        }
    }
    int ans = 1e9;
    for (int j = 0; j < n; j++) ans = min(ans, dp[(1<<n)-1][j]);
    printf("%d\n", ans);
    return 0;
}
```

## 六、数位DP

### 知识点1：数位DP通法

#### 核心原理
统计[1,N]区间内满足某种数位性质的数的个数。

**状态**：`dfs(pos, state, lead, tight)`
- pos：当前处理到第几位
- state：数字状态（如前一位数、奇偶性等）
- lead：是否有前导零
- tight：上一位是否卡上限（决定当前位可选0-9还是0-digit[pos]）

**记忆化**：将参数组合存入memo，避免重复计算。

#### C++ 标准实现框架
```cpp
#include <cstring>
#include <vector>
using namespace std;

vector<int> digits;
int memo[20][11];

// last 取值 0~9 表示上一位数字
// last = 10 表示前面还没有放入有效数字
int dfs(int pos, int last, bool lead, bool tight) {
    if (pos == -1) return 1;

    // 只有“不受上界限制”且“已经出现有效数字”时才记忆化
    if (!tight && !lead && memo[pos][last] != -1) {
        return memo[pos][last];
    }

    int up = tight ? digits[pos] : 9;
    int res = 0;

    for (int d = 0; d <= up; d++) {
        if (d == 4) continue;

        // 只有前面已经出现有效数字时，last 才真的有意义
        if (!lead && last == 6 && d == 2) continue;

        bool nextLead = lead && (d == 0);
        int nextLast = nextLead ? 10 : d;
        res += dfs(pos - 1, nextLast, nextLead, tight && (d == up));
    }

    if (!tight && !lead) {
        memo[pos][last] = res;
    }
    return res;
}

int solve(int n) {
    digits.clear();
    if (n == 0) digits.push_back(0);
    while (n) {
        digits.push_back(n % 10);
        n /= 10;
    }

    memset(memo, -1, sizeof memo);
    return dfs((int)digits.size() - 1, 10, true, true);
}
```

#### 蓝桥杯真题应用：含特定数字的计数
**题目**：[L,R]区间内，数字中出现4或62的数的个数 = (R不合法数) - (L-1不合法数)
**思考推导**：补集思想，求合法数（不含4、不含连续62），总数减合法数即答案。
