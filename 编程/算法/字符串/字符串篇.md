#### 蓝桥杯真题应用：循环节（周期）问题
**题目**：求字符串最小循环节，输出每个前缀的最小循环次数。

**输入样例**：
```
aaa
```
**输出样例**：
```
3  // 长度3最小循环节长度1，循环3次
```

**思考推导**：
1. **切入点**：利用KMP的next数组，最小循环节长度 = len - next[len-1]。
2. **边界条件**：len % (len - next[len-1]) == 0 时，才是完整循环节。
3. **易错点**：注意索引，next数组长度为字符串长度。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<int> getNext(const string& p) {
    int m = p.size();
    vector<int> nxt(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = nxt[j-1];
        if (p[i] == p[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}

void solveCycle(const string& s) {
    int n = s.size();
    vector<int> nxt = getNext(s);
    for (int i = 0; i < n; i++) {
        int len = i + 1;
        int cycle = len - nxt[i];
        if (len % cycle == 0 && cycle < len) {
            printf("%d %d\n", len, len / cycle);
        }
    }
}
```

## 二、字典树（Trie / 前缀树）

### 知识点1：Trie树存储与查询

#### 核心原理
以字符为边的多叉树，根到节点的路径构成字符串。用于**字符串统计、前缀查询、最大异或对**等。

每个节点有26个子节点（或更多），外加cnt标记以该节点结尾的字符串数量。

#### 实现思路
1. 插入：从根出发，沿字符路径走，没有则新建节点，结尾cnt+1
2. 查询：沿字符路径走，走到空返回false，结尾cnt>0则存在
3. 前缀查询：同上，走到非空即存在前缀

#### C++ 数组模拟实现（竞赛常用）
```cpp
const int MAXN = 100010 * 32; // 按字符总数估计
int trie[MAXN][26], cnt[MAXN], idx;

void trieInit() {
    idx = 1;
    memset(trie, 0, sizeof trie);
    memset(cnt, 0, sizeof cnt);
}

void trieInsert(const string& s) {
    int p = 0;
    for (char c : s) {
        int x = c - 'a';
        if (!trie[p][x]) trie[p][x] = idx++;
        p = trie[p][x];
    }
    cnt[p]++;
}

int trieQuery(const string& s) {
    int p = 0;
    for (char c : s) {
        int x = c - 'a';
        if (!trie[p][x]) return 0;
        p = trie[p][x];
    }
    return cnt[p];
}

// 统计以s为前缀的字符串数（需要额外存子树cnt或遍历累加）
```

#### 蓝桥杯真题应用：最大异或对
**题目**：n个数中选两个数a,b，使a⊕b最大（$n \le 10^5$，数≤$2^{31}$）

**输入样例**：
```
5
3 10 5 25 2 8
```
**输出样例**：
```
28 // 5⊕25 = 28
```

**思考推导**：
1. **切入点**：二进制从高到低逐位贪心，用Trie存已插入数字的二进制位（0/1构成二叉Trie）。
2. **边界条件**：从最高位30位到0位，优先走与当前位相反的路径。
3. **易错点**：数字不足31位时高位补0；异或最大值是贪心尽量让高位为1。

**模拟过程**：数3(00011),10(01010),5(00101),25(11001),2(00010),8(01000)
- 插入前4个数后，查询5(00101)：
  - 最高位开始，尽量走和当前位相反的分支
  - 5 的高位是 0，Trie 中存在 25 的高位 1，所以优先走 1
  - 后面各位继续重复这个贪心过程
  - 最终会匹配到 25，得到 `5⊕25=28`
- 这个例子说明：Trie 查询函数返回的是“当前数能得到的最大异或值”，不是“匹配到的那个数本身”

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100010 * 31;
int trie[MAXN][2], idx;

void trieInsertNum(int x) {
    int p = 0;
    for (int i = 30; i >= 0; i--) {
        int b = x >> i & 1;
        if (!trie[p][b]) trie[p][b] = ++idx;
        p = trie[p][b];
    }
}

int trieQueryMaxXor(int x) {
    int p = 0, res = 0;
    for (int i = 30; i >= 0; i--) {
        int b = x >> i & 1;
        if (trie[p][1-b]) { // 优先走相反位
            res |= (1 << i);
            p = trie[p][1-b];
        } else {
            p = trie[p][b];
        }
    }
    return res;
}

int main() {
    int n; scanf("%d", &n);
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int x; scanf("%d", &x);
        if (i > 0) ans = max(ans, trieQueryMaxXor(x));
        trieInsertNum(x);
    }
    printf("%d\n", ans);
    return 0;
}
```

## 三、字符串哈希（滚动哈希）

### 知识点1：前缀哈希+进制base

#### 核心原理
将字符串视为P进制数，模Q。预处理前缀哈希和P的幂，O(1)求任意子串哈希值。用于字符串匹配、回文判断等。

**常用取值**：P=131或13331，Q=$2^{64}$（用unsigned long long自然溢出取模，简便高效）。

#### 核心公式
设字符串下标从1开始：
$$hash[i] = hash[i-1] \times P + s[i]$$
$$P\_pow[i] = P\_pow[i-1] \times P$$
子串s[l..r]的哈希：
$$hash(l,r) = hash[r] - hash[l-1] \times P\_pow[r-l+1]$$

#### C++ 标准实现（自然溢出）
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

typedef unsigned long long ULL;
const ULL P = 131;

struct StringHash {
    vector<ULL> h, p;
    int n;
    
    StringHash(const string& s) {
        n = s.size();
        h.resize(n+1, 0); p.resize(n+1, 1);
        for (int i = 1; i <= n; i++) {
            h[i] = h[i-1] * P + s[i-1]; // s[i-1]是原字符串0-based
            p[i] = p[i-1] * P;
        }
    }
    
    ULL get(int l, int r) { // 1-based [l, r]
        return h[r] - h[l-1] * p[r-l+1];
    }
};
```

#### 蓝桥杯真题应用：最长重复子串
**题目**：求字符串中最长出现至少两次的子串长度（不可重叠或可重叠）

**思考推导**：
1. **切入点**：二分答案长度L，检查是否有两个不同位置的长度L子串哈希值相同。
2. **边界条件**：不可重叠时位置差≥L，可重叠时直接排序找相同。
3. **易错点**：哈希冲突概率极低可用双哈希（两种P/Q）进一步降低。

```cpp
bool check(StringHash& sh, int L, int n, bool overlap=false) {
    vector<pair<ULL,int>> hashes;
    for (int i = 1; i + L - 1 <= n; i++) {
        hashes.push_back({sh.get(i, i+L-1), i});
    }
    sort(hashes.begin(), hashes.end());
    for (int i = 1; i < hashes.size(); i++) {
        if (hashes[i].first == hashes[i-1].first) {
            if (overlap) return true;
            if (abs(hashes[i].second - hashes[i-1].second) >= L) return true;
        }
    }
    return false;
}
```

## 四、Manacher算法（马拉车）

### 知识点1：最长回文子串（O(n)）

#### 核心原理
在字符间插入特殊分隔符（如#），将奇偶长度回文统一为奇数长度。利用已找到的回文对称性加速扩展，避免重复比较。

维护：
- p[i]：以i为中心的最长回文半径（含中心）
- mx, id：当前最右回文的右边界和中心

**时间复杂度**：严格O(n)

#### C++ 标准实现
```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

string manacherInit(const string& s) {
    string t = "^#";
    for (char c : s) { t += c; t += '#'; }
    t += '$';
    return t;
}

string longestPalindrome(const string& s) {
    string t = manacherInit(s);
    int n = t.size();
    vector<int> p(n, 0);
    int mx = 0, id = 0;
    int maxLen = 0, start = 0;
    
    for (int i = 1; i < n-1; i++) {
        if (i < mx) {
            // 镜像点：2*id-i
            p[i] = min(p[2*id - i], mx - i);
        } else {
            p[i] = 1;
        }
        // 暴力扩展
        while (t[i + p[i]] == t[i - p[i]]) p[i]++;
        // 更新mx和id
        if (i + p[i] > mx) {
            mx = i + p[i];
            id = i;
        }
        // 更新答案（回文在原串中长度=p[i]-1）
        if (p[i] - 1 > maxLen) {
            maxLen = p[i] - 1;
            // 原串起点：(i - p[i]) / 2
            start = (i - p[i]) / 2;
        }
    }
    return s.substr(start, maxLen);
}
```

#### 蓝桥杯真题应用：回文子串统计
**题目**：统计字符串中回文子串的总个数

**思考推导**：
1. **切入点**：Manacher求出每个中心的p[i]，p[i]-1就是该中心在原串中的最长回文半径（向上取整）。
2. **边界条件**：对每个p[i]，贡献 = (p[i])/2（即ceil((p[i]-1)/2)）。
3. **易错点**：插入#后p[i]=实际回文在t中的半径，对应原串中回文长度=p[i]-1，子串数=(p[i])/2。
