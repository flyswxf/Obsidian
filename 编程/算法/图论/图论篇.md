+-## 一、图的存储与遍历

### 知识点1：邻接表存图

#### 核心原理
用vector数组存每个节点的出边，空间O(M)，遍历O(M)，适用于稀疏图。

#### C++ 实现
```cpp
struct Edge { int to, w; };
vector<vector<Edge>> g;
// 初始化: g.resize(n+1);
// 加边（无向边加两次）:
void addEdge(int u, int v, int w) {
    g[u].push_back({v, w});
    g[v].push_back({u, w});
}
```

## 二、最短路算法

### 知识点1：Dijkstra算法（单源最短路，非负权）

#### 核心原理
贪心+优先队列：每次选距离起点最近且未确定的节点u，用u松弛所有出边。时间复杂度O(M log N)。

#### 实现思路
1. dist数组初始化为INF，dist[src]=0
2. 优先队列存(距离,节点)，按距离升序
3. 弹出队首(u)，若u已确定（st[u]=true）则跳过
4. 标记u已确定，遍历u的出边(v,w)，若dist[v]>dist[u]+w则松弛并加入队列

#### C++ 标准实现（堆优化）
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

typedef pair<int,int> PII;
const int INF = 0x3f3f3f3f;

vector<vector<Edge>> g;
vector<int> dist;
vector<bool> st;

void dijkstra(int src, int n) {
    dist.assign(n+1, INF);
    st.assign(n+1, false);
    dist[src] = 0;
    priority_queue<PII, vector<PII>, greater<PII>> pq;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (st[u]) continue;
        st[u] = true;
        for (auto& e : g[u]) {
            int v = e.to, w = e.w;
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }
}
```

#### 蓝桥杯真题应用：最短路径
**题目**：n个点m条边的有向图，求1到n的最短路（无负权）

**输入样例**：
```
3 3
1 2 2
2 3 1
1 3 5
```
**输出样例**：`3` （1→2→3，2+1=3）

**思考推导**：
1. **切入点**：非负权有向图最短路，Dijkstra标准题。
2. **边界条件**：dist[1]=0，其余INF；终点dist[n]仍为INF则输出-1。
3. **易错点**：边是有向的，只加一次；优先队列用小根堆。

### 知识点2：Bellman-Ford / SPFA（处理负权）

#### 核心原理
Bellman-Ford：每条边做n-1轮松弛，时间O(NM)。第n轮还能松弛则存在负环。

SPFA（Shortest Path Faster Algorithm）：Bellman-Ford队列优化，平均O(M)，最坏O(NM)。需要判负环时加cnt数组记录入队次数。

#### C++ SPFA实现（判负环）
```cpp
vector<int> dist, cnt;
vector<bool> inq;

bool spfa(int n) { // 返回true表示存在负环
    dist.assign(n+1, 0); // 判负环初始化为0即可
    cnt.assign(n+1, 0);
    inq.assign(n+1, true);
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i); // 所有点入队，避免不连通
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = false;
        for (auto& e : g[u]) {
            int v = e.to, w = e.w;
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= n) return true;
                if (!inq[v]) { q.push(v); inq[v] = true; }
            }
        }
    }
    return false;
}
```

### 知识点3：Floyd算法（多源最短路）

#### 核心原理
动态规划思想：`d[k][i][j]`=经过编号≤k的点，i到j的最短路。
$$d[i][j] = \min(d[i][j], d[i][k] + d[k][j])$$
三重循环k-i-j，时间O(N³)，空间O(N²)，适合N≤500。

#### C++ 实现
```cpp
vector<vector<int>> d;
void floyd(int n) {
    for (int i = 1; i <= n; i++) d[i][i] = 0;
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}
```

## 三、最小生成树（MST）

### 知识点1：Kruskal算法

#### 核心原理
将所有边按权值从小到大排序，用并查集依次加入不构成环的边，共加n-1条。时间O(M log M)，适合稀疏图。

#### 实现思路
1. 所有边排序
2. 初始化并查集
3. 遍历边，若两端点不在同一集合则加入，累加权值
4. 加入的边数<n-1则图不连通

#### C++ 标准实现
```cpp
struct EdgeMST { int u, v, w; };
vector<EdgeMST> edges;

struct DSU {
    vector<int> parent;

    DSU(int n) : parent(n + 1) {
        for (int i = 0; i <= n; i++) parent[i] = i;
    }

    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }

    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false; // 已连通，再加这条边会成环
        parent[a] = b;
        return true;
    }
};

bool kruskalCmp(const EdgeMST& a, const EdgeMST& b) { return a.w < b.w; }

int kruskal(int n, int m) {
    sort(edges.begin(), edges.end(), kruskalCmp);
    DSU dsu(n);
    int res = 0, cnt = 0;
    for (auto& e : edges) {
        if (dsu.unite(e.u, e.v)) {
            res += e.w;
            cnt++;          // 成功加入一条树边
        }
    }
    if (cnt < n-1) return -1; // 不连通
    return res;
}
```

#### 蓝桥杯真题应用：修建道路
**题目**：n个村庄，村庄间修道路，求最小总代价使所有村庄连通。

**输入样例**：
```
4 5
1 2 1
1 3 4
2 3 2
2 4 5
3 4 3
```
**输出样例**：`6`（选边1-2(1), 2-3(2), 3-4(3)）

**思考推导**：
1. **切入点**：最小生成树裸题，Kruskal或Prim。
2. **边界条件**：若输出-1则表示不连通。
3. **易错点**：按权值升序排序；并查集路径压缩+按秩合并。

## 四、拓扑排序

### 知识点1：拓扑排序（Kahn算法）

#### 核心原理
对DAG（有向无环图）的节点排序，使得任意有向边u→v中u排在v前。常用来判环、任务调度、递推顺序。

#### 实现思路（BFS版Kahn）
1. 统计每个节点入度indeg
2. 所有入度为0的节点入队
3. 弹出u加入拓扑序，遍历u的出边，将v入度-1，若为0则入队
4. 拓扑序大小<n则存在环

#### C++ 标准实现
```cpp
vector<int> topoSort(int n) {
    vector<int> indeg(n+1, 0);
    for (int u = 1; u <= n; u++)
        for (auto& e : g[u]) indeg[e.to]++;
    queue<int> q;
    for (int u = 1; u <= n; u++)
        if (indeg[u] == 0) q.push(u);
    vector<int> res;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        res.push_back(u);
        for (auto& e : g[u]) {
            int v = e.to;
            if (--indeg[v] == 0) q.push(v);
        }
    }
    if (res.size() < n) return {}; // 有环
    return res;
}
```

#### 蓝桥杯真题应用：可达性统计
**题目**：DAG，对每个点求其能到达的节点数量（含自身）。

**思考推导**：
1. **切入点**：拓扑排序后逆序处理，用bitset存储可达集合，|=运算合并子节点可达集。
2. **边界条件**：每个节点自身可达，初始f[u][u]=1。
3. **易错点**：必须逆拓扑序（先处理后继，再处理前驱）。

```cpp
#include <bitset>
void solveReachable(int n) {
    vector<int> order = topoSort(n);
    reverse(order.begin(), order.end());
    vector<bitset<30010>> f(n+1);
    for (int u = 1; u <= n; u++) f[u].set(u);
    for (int u : order)
        for (auto& e : g[u])
            f[u] |= f[e.to];
    for (int u = 1; u <= n; u++)
        printf("%d\n", f[u].count());
}
```

## 五、强连通分量（SCC）

### 知识点1：Tarjan算法求SCC

#### 核心原理
基于DFS，用dfn数组记录节点时间戳，low数组记录通过后向边能回到的最早节点。当`low[u]==dfn[u]`时栈顶到u构成SCC。

#### C++ 标准实现
```cpp
vector<int> dfn, low, stk, id; // id[u]记录u所在SCC编号
vector<bool> in_stk;
int timestamp, scc_cnt, top;

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    stk[++top] = u; in_stk[u] = true;
    for (auto& e : g[u]) {
        int v = e.to;
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stk[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {
        scc_cnt++;
        int y;
        do {
            y = stk[top--]; in_stk[y] = false;
            id[y] = scc_cnt;
        } while (y != u);
    }
}

// 调用入口:
void findSCC(int n) {
    dfn.assign(n+1, 0); low.assign(n+1, 0);
    id.assign(n+1, 0); in_stk.assign(n+1, false);
    stk.resize(n+2); timestamp = scc_cnt = top = 0;
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i);
}
```

#### 应用：缩点
求完SCC后，将每个SCC作为一个点，原图重构图为DAG，可在新图上拓扑排序求最长路等。

## 六、二分图

### 知识点1：二分图判定（染色法）

#### 核心原理
二分图充要条件：不含奇环。DFS或BFS交替染色（黑白二色），冲突则不是二分图。

#### C++ 实现
```cpp
vector<int> color; // 0=未染, 1=黑, 2=白
bool dfsColor(int u, int c) {
    color[u] = c;
    for (auto& e : g[u]) {
        int v = e.to;
        if (!color[v]) {
            if (!dfsColor(v, 3-c)) return false;
        } else if (color[v] == c) return false;
    }
    return true;
}
bool isBipartite(int n) {
    color.assign(n+1, 0);
    for (int i = 1; i <= n; i++)
        if (!color[i] && !dfsColor(i, 1)) return false;
    return true;
}
```

### 知识点2：二分图最大匹配（匈牙利算法）

#### 核心原理
左部点u去尝试匹配右部点v：若v未匹配则成功；若v已匹配给match[v]，则尝试让match[v]换一个右部点。

时间O(NM)。

#### C++ 标准实现
```cpp
vector<vector<int>> bg; // 二分图邻接表，只存左部→右部的边
vector<int> match;      // 右部点匹配的左部点编号
vector<bool> vis;

bool dfsMatch(int u) {
    for (int v : bg[u]) {
        if (!vis[v]) {
            vis[v] = true;
            if (match[v] == 0 || dfsMatch(match[v])) {
                match[v] = u;
                return true;
            }
        }
    }
    return false;
}

int hungarian(int n_left, int n_right) {
    match.assign(n_right + 1, 0);
    int res = 0;
    for (int u = 1; u <= n_left; u++) {
        vis.assign(n_right + 1, false);
        if (dfsMatch(u)) res++;
    }
    return res;
}
```

#### 蓝桥杯真题应用：棋盘覆盖
**题目**：n×n棋盘，某些格子不能放，放1×2骨牌（覆盖相邻两格）最多放几块。

**思考推导**：
1. **切入点**：将格子按(i+j)%2黑白染色，相邻格子颜色不同，构成二分图。骨牌匹配=二分图匹配。
2. **边界条件**：左右部分别为黑白格，不可放格跳过。
3. **易错点**：格子编号映射（i-1)*n+j → 左部/右部序号。

## 七、LCA最近公共祖先

### 知识点1：倍增法求LCA

#### 核心原理
预处理每个节点的2^k级祖先（f[k][u]），查询时两个节点先调到同一深度，再从高到低一起往上跳，直到相遇。预处理O(N log N)，查询O(log N)。

#### C++ 实现
```cpp
vector<vector<int>> tree; // LCA 只需要存树结构，不需要边权
vector<vector<int>> up; // up[k][u] = u的2^k级祖先
vector<int> depth;
int LOG;

void dfsLCA(int u, int fa) {
    up[0][u] = fa;
    for (int k = 1; k < LOG; k++)
        up[k][u] = up[k-1][up[k-1][u]];
    for (int v : tree[u]) {
        if (v == fa) continue;
        depth[v] = depth[u] + 1;
        dfsLCA(v, u);
    }
}

void initLCA(int n, int root) {
    LOG = 0; while ((1 << LOG) <= n) LOG++;
    up.assign(LOG, vector<int>(n+1));
    depth.assign(n+1, 0);
    depth[root] = 1;
    dfsLCA(root, 0);
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    // u往上跳到和v同深
    for (int k = LOG - 1; k >= 0; k--)
        if (depth[u] - (1 << k) >= depth[v])
            u = up[k][u];
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }
    return up[0][u];
}
```

#### 蓝桥杯真题应用：树上两点距离
**题目**：求树上u到v的距离 = depth[u] + depth[v] - 2*depth[lca(u,v)]
