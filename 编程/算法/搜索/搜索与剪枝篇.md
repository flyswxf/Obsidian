## 一、深度优先搜索（DFS）与回溯

### 知识点1：DFS通用框架与剪枝

#### 核心原理
递归深度优先搜索，每次选择一条分支深入到底，回溯后尝试其他分支。适合排列组合、子集枚举、可行解搜索等。

**搜索树深度=递归层数，每层有若干选择**。

#### 实现思路（三部曲）
1. **参数设计**：u=当前搜索层数/位置，path=当前选择的方案
2. **终止条件**：u达到目标深度，记录答案或计数
3. **枚举分支**：遍历本层所有可选分支，检查合法性，选→递归→回溯（撤销选择）

#### C++ 标准框架
```cpp
// 例：n的全排列
vector<int> path;
vector<bool> used;
vector<vector<int>> res;
int n;

void dfs(int u) {
    if (u == n) {
        res.push_back(path);
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;
            path[u] = i;        // 选择数字 i 放在第 u 位
            dfs(u + 1);
            used[i] = false;    // 撤销选择，尝试下一个数字
        }
    }
}

void init() {
    path.resize(n);            // path[u] 会直接按下标写，所以要先开空间
    used.assign(n + 1, false); // 1~n 是否已使用
}
```

#### 蓝桥杯真题应用：数独
**题目**：9×9数独填数，每行每列每个3×3宫1-9不重复。

**思考推导**：
1. **切入点**：从(0,0)开始逐格搜索，空格尝试1-9，检查合法性。
2. **剪枝优化**：优先选可选数字最少的格子（优先搜索分支少的节点，大幅提速）。
3. **边界条件**：所有格子填完即找到解。
4. **易错点**：检查行列宫三个维度；找到解后及时return。

## 二、广度优先搜索（BFS）

### 知识点1：BFS最短路与多源BFS

#### 核心原理
队列逐层扩展，第一次到达目标的距离就是最短路。适合**边权相等**（都是1）的最短路问题。

**多源BFS**：多个起点同时入队，距离取到最近源的距离。

#### 实现思路
1. dist数组初始化为-1（未访问）
2. 起点入队，dist[start]=0
3. 每次弹出队首，扩展相邻节点，dist=-1时入队并更新距离

#### C++ 标准实现（迷宫最短路）
```cpp
#include <iostream>
#include <queue>
using namespace std;

int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};

int bfsMatrix(vector<vector<int>>& g, pair<int,int> start, pair<int,int> end) {
    int n = g.size(), m = g[0].size();
    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int,int>> q;
    dist[start.first][start.second] = 0;
    q.push(start);
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        if (x == end.first && y == end.second) return dist[x][y];
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (g[nx][ny] == 1) continue; // 墙
            if (dist[nx][ny] == -1) {
                dist[nx][ny] = dist[x][y] + 1;
                q.push({nx, ny});
            }
        }
    }
    return -1;
}
```

#### 蓝桥杯真题应用：洪水填充/多源BFS
**题目**：多个洪水源头同时扩散，问每个格子多久被淹没。

**思考推导**：
1. **切入点**：所有源点同时入队，dist初始为源点=0，其他=-1。
2. **边界条件**：4/8方向。
3. **易错点**：源点同时入队，保证层次正确。

### 知识点2：双向BFS

#### 核心原理
起点和终点同时向中间扩展BFS，当两个搜索边界相遇时得到答案。搜索空间从O(k^d)降为约2×O(k^(d/2))，极大减少状态数。

适用于**起点终点都明确**，且状态空间大的搜索（如八数码、字符串最小变换次数）。

#### C++ 实现框架
```cpp
// 例：字符串最小变换次数（两字符串等长，每次换一个字符，只能变到wordList中的词）
int bidirectionalBFS(string start, string end, unordered_set<string>& dict) {
    if (start == end) return 0;
    if (!dict.count(end)) return -1;
    unordered_set<string> s1, s2, visited;
    s1.insert(start); s2.insert(end);
    int step = 0;
    while (!s1.empty() && !s2.empty()) {
        if (s1.size() > s2.size()) swap(s1, s2); // 每次扩展小的一方
        step++;
        unordered_set<string> next;
        for (string word : s1) {
            for (int i = 0; i < word.size(); i++) {
                char orig = word[i];
                for (char c = 'a'; c <= 'z'; c++) {
                    if (c == orig) continue;
                    word[i] = c;
                    if (s2.count(word)) return step; // 相遇
                    if (!visited.count(word) && dict.count(word)) {
                        visited.insert(word);
                        next.insert(word);
                    }
                }
                word[i] = orig;
            }
        }
        s1 = next;
    }
    return -1;
}
```

## 三、记忆化搜索（DFS + 备忘录）

### 知识点1：记忆化搜索实现DP

#### 核心原理
本质是将递归DFS中重复计算的子问题结果存入数组（memo），下次遇到直接查表，避免重复计算。与动态规划等价，但代码更直观，顺序更"自然"。

**适用条件**：子问题重叠 + 最优子结构。

#### 实现思路
1. memo数组初始化为特殊值（如-1）
2. dfs函数参数即DP状态
3. 进入函数先查memo，有值直接return
4. 算出结果后存入memo再return

#### 蓝桥杯真题应用：滑雪（记忆化搜索经典）
**题目**：n×m高度矩阵，可从高处滑到低处（相邻格），求最长滑雪路径。

**输入样例**：
```
5 5
1  2  3  4  5
16 17 18 19 6
15 24 25 20 7
14 23 22 21 8
13 12 11 10 9
```
**输出样例**：
```
25 // 从25出发滑1,2,...,25
```

**思考推导**：
1. **切入点**：对每个点u，f[u]=u能滑的最长距离，f[u] = 1 + max(f[v])（v是u四周且h[v]<h[u]的点）。
2. **边界条件**：四周都≥当前高度时f[u]=1。
3. **易错点**：递归不能无限循环（因为h严格递减不会死循环）；初始化memo为0或-1。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n, m;
vector<vector<int>> h;
vector<vector<int>> memo;
int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};

int dfsSki(int x, int y) {
    if (memo[x][y] != 0) return memo[x][y];
    int res = 1;
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx >= 0 && nx < n && ny >= 0 && ny < m && h[nx][ny] < h[x][y]) {
            res = max(res, dfsSki(nx, ny) + 1);
        }
    }
    return memo[x][y] = res;
}

int main() {
    scanf("%d%d", &n, &m);
    h.assign(n, vector<int>(m));
    memo.assign(n, vector<int>(m, 0));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            scanf("%d", &h[i][j]);
    int ans = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            ans = max(ans, dfsSki(i, j));
    printf("%d\n", ans);
    return 0;
}
```

## 四、迭代加深搜索（IDA*）

### 知识点1：迭代加深 + 估价函数剪枝

#### 核心原理
当搜索树**深度可能很大**（如无限深），但答案深度较浅时：
1. 限制最大深度D，DFS只搜索深度≤D
2. 无解则D++，重复1
3. 加上**估价函数f(u)**（u到目标还需的最少步数下界），若`当前深度 + f(u) > D`则剪枝，称为IDA*（Iterative Deepening A*）

**优势**：DFS空间+避免无限深+剪枝高效，适合八数码、排书等答案深度小的搜索。

#### C++ 实现框架（排书问题）

下面这段是**题解骨架**，重点看“估价函数怎么设计”和“何时剪枝”。  
其中 `a`、`move`、`undoMove` 需要按具体题目自己补全。
```cpp
// 例：排书问题，每次将一段连续书移动到其他位置，最少几步将1~n排好序
int n;
int h() { // 估价函数：后继不正确的书的数量，每次移动最多修3个，所以/3
int h() { // 估价函数：后继不正确的书的数量，每次移动最多修3个，所以/3
    int cnt = 0;
    for (int i = 0; i < n-1; i++)
        if (a[i+1] != a[i] + 1) cnt++;
    if (a[n-1] != n) cnt++;
    return (cnt + 2) / 3; // 上取整
}

bool dfsIDA(int depth, int maxDepth) {
    if (depth + h() > maxDepth) return false;
    if (h() == 0) return true;
    // 枚举所有移动操作
    for (int len = 1; len <= n; len++) {
        for (int l = 0; l + len - 1 < n; l++) {
            int r = l + len - 1;
            for (int k = r + 1; k < n; k++) {
                // 将[l,r]移到k后面
                move(l, r, k);
                if (dfsIDA(depth+1, maxDepth)) return true;
                undoMove(l, r, k);
            }
        }
    }
    return false;
}

void solve() {
    int d = 0;
    while (d < 5 && !dfsIDA(0, d)) d++;
    if (d >= 5) printf("5 or more\n");
    else printf("%d\n", d);
}
```

## 五、搜索优化与剪枝技巧

### 常用剪枝策略
1. **优化搜索顺序**：优先搜索分支少/约束多/影响大的选项
2. **排除等效冗余**：不搜索与已搜索状态等价的分支（如组合排序避免重复）
3. **可行性剪枝**：当前条件下无论如何都达不到目标，直接return
4. **最优性剪枝**：当前答案≥已找到的最优解，无需继续
5. **记忆化**：相同参数/状态已算过直接用
6. **估价函数（A*/IDA*）**：估计下界，当前+下界>上限则剪

### 蓝桥杯真题应用：小猫爬山（DFS最优剪枝+排序优化）
**题目**：n只猫重量c[i]，每辆车承重W，最少几辆车装完（$n \le 18$）。

**思考推导**：
1. **切入点**：按重量从大到小排序（重猫难放，先放减少分支）。
2. **DFS状态**：u=当前处理第几只猫，cnt=已用车数，每辆车当前总重。
3. **最优性剪枝**：cnt>=ans则剪（ans初值可设n或二分上界）。
4. **优化**：放入已有车或新开一车，相同重量车放入已放过的等价车可跳过。

```cpp
int n, W;
vector<int> cat;
vector<int> car; // 每辆车当前重量
int ans;

void dfsCat(int u, int cnt) {
    if (cnt >= ans) return; // 最优剪枝
    if (u == n) { ans = cnt; return; }
    // 尝试放入已有的车
    for (int i = 0; i < cnt; i++) {
        if (i > 0 && car[i] == car[i-1]) continue; // 等效剪枝
        if (car[i] + cat[u] <= W) {
            car[i] += cat[u];
            dfsCat(u + 1, cnt);
            car[i] -= cat[u];
        }
    }
    // 新开一辆车
    car[cnt] = cat[u];
    dfsCat(u + 1, cnt + 1);
    car[cnt] = 0;
}
```
