## 一、快速幂与模运算

### 知识点1：快速幂（二进制拆分）

#### 核心原理
将指数b拆分为二进制位，将$a^b$转化为$a^{2^k}$的乘积，时间O(log b)。
$$a^b = a^{b_0} \times (a^2)^{b_1} \times (a^4)^{b_2} \times \dots$$
其中$b_i$是b的第i个二进制位。

每次运算取模，避免溢出。

#### C++ 标准实现
```cpp
long long qpow(long long a, long long b, long long p) {
    long long res = 1 % p;
    a %= p;
    while (b) {
        if (b & 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
```

#### 蓝桥杯真题应用：矩阵快速幂求斐波那契
**题目**：求斐波那契数列第n项 mod p（$n \le 10^{18}$）

**输入样例**：`10 1000`
**输出样例**：`55`

**思考推导**：
1. **切入点**：n极大，递推O(n)超时，利用矩阵快速幂O(log n)。
2. **状态转移矩阵**：
$$\begin{bmatrix} f_{n+1} \\ f_n \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^n \times \begin{bmatrix} f_1 \\ f_0 \end{bmatrix}$$
3. **边界条件**：f(0)=0, f(1)=1。
4. **易错点**：矩阵乘法顺序，矩阵乘法也要取模。

```cpp
#include <cstring>

struct Matrix {
    long long a[2][2];
    Matrix() { memset(a, 0, sizeof a); }
};

Matrix multiply(const Matrix& x, const Matrix& y, long long mod) {
    Matrix res;
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 2; k++) {
                res.a[i][j] = (res.a[i][j] + x.a[i][k] * y.a[k][j]) % mod;
            }
        }
    }
    return res;
}

long long fib(long long n, long long p) {
    if (n == 0) return 0;
    Matrix base, res;
    base.a[0][0] = base.a[0][1] = base.a[1][0] = 1;
    res.a[0][0] = res.a[1][1] = 1; // 单位矩阵
    while (n) {
        // 当前二进制位为 1，就把这份贡献乘到答案里
        if (n & 1) res = multiply(res, base, p);
        // base 不断平方，对应 a^(1), a^(2), a^(4), a^(8)...
        base = multiply(base, base, p);
        n >>= 1;
    }
    // res 现在等于 base^n，右乘初始向量 [f1, f0]^T = [1, 0]^T
    // 因此答案就是 res[0][1]
    return res.a[0][1] % p;
}
```

### 知识点2：模逆元（除法取模）

#### 核心原理
模p下，a的逆元x满足 $a \times x \equiv 1 \pmod{p}$。

**费马小定理求逆元**（p为质数）：
$$a^{p-2} \equiv a^{-1} \pmod{p}$$
逆元 = qpow(a, p-2, p)

**扩展欧几里得求逆元**（p与a互质即可）

#### 应用
$$\frac{a}{b} \bmod p = a \times b^{-1} \bmod p$$

```cpp
long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long d = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
}
```

### 知识点3：欧拉函数

#### 核心原理
$\varphi(n)$ = 1~n中与n互质的数的个数。
$$\varphi(n) = n \times \prod_{i=1}^{k}(1-\frac{1}{p_i})$$
其中$p_i$是n的不同质因子。

**性质**：
- n为质数时$\varphi(n)=n-1$
- 若m,n互质：$\varphi(mn)=\varphi(m)\varphi(n)$（积性函数）
- 线性筛可求1~n欧拉函数

#### C++ 求单个欧拉函数
```cpp
long long eulerPhi(long long n) {
    long long res = n;
    for (long long i = 2; i*i <= n; i++) {
        if (n % i == 0) {
            res = res / i * (i - 1);
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}
```

## 三、组合数学

### 知识点1：排列组合与递推

#### 核心公式
- 排列：$A(n,k) = \frac{n!}{(n-k)!}$
- 组合：$C(n,k) = \frac{n!}{k!(n-k)!}$
- 递推式（杨辉三角）：$C(n,k) = C(n-1,k) + C(n-1,k-1)$，边界$C(n,0)=C(n,n)=1$

#### C++ 杨辉三角预处理（n≤4000，无模）
```cpp
vector<vector<long long>> C;
void initC(int n, int mod) {
    C.assign(n+1, vector<long long>(n+1, 0));
    for (int i = 0; i <= n; i++) {
        C[i][0] = 1;
        for (int j = 1; j <= i; j++)
            C[i][j] = (C[i-1][j-1] + C[i-1][j]) % mod;
    }
}
```

#### 大组合数取模（预处理阶乘+逆元）
```cpp
vector<long long> fact, inv_fact;
void initFact(int n, int mod) {
    fact.resize(n+1); inv_fact.resize(n+1);
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i-1] * i % mod;
    inv_fact[n] = qpow(fact[n], mod-2, mod);
    for (int i = n-1; i >= 0; i--) inv_fact[i] = inv_fact[i+1] * (i+1) % mod;
}
long long Ckn(int k, int n, int mod) {
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % mod * inv_fact[n-k] % mod;
}
```

#### 蓝桥杯真题应用：卡特兰数（Catalan）
**题目**：n对括号合法匹配方案数 / 出栈序列数 / 二叉搜索树结构数

**卡特兰通项**：
$$C_n = \frac{1}{n+1} C(2n, n) = C(2n, n) - C(2n, n-1)$$

**递推**：$C_0 = 1, C_{n+1} = \sum_{i=0}^{n} C_i C_{n-i}$

### 知识点2：容斥原理

#### 核心原理
计算多个集合的并集大小时，奇加偶减：
$$|A_1 \cup A_2 \cup ... \cup A_n| = \sum|A_i| - \sum|A_i \cap A_j| + \sum|A_i \cap A_j \cap A_k| - ...$$

实现时用二进制枚举所有子集组合。

#### 蓝桥杯真题应用：能被整除的数
**题目**：1~n中能被集合中至少一个数整除的数的个数

**输入样例**：
```
12 2
2 3
```
**输出样例**：`8`（2,3,4,6,8,9,10,12）

**思考推导**：
1. **切入点**：容斥，枚举每个子集的LCM，奇加偶减n/LCM。
2. **边界条件**：LCM超过n时贡献为0，剪枝。
3. **易错点**：2^m枚举，m个元素；LCM可能溢出，用long long或提前break。

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long gcd(long long a, long long b) { return b ? gcd(b, a%b) : a; }

int main() {
    long long n; int m;
    scanf("%lld%d", &n, &m);
    vector<long long> a(m);
    for (int i = 0; i < m; i++) scanf("%lld", &a[i]);
    long long ans = 0;
    for (int S = 1; S < (1<<m); S++) {
        long long lcm = 1;
        int cnt = 0;
        for (int i = 0; i < m; i++) {
            if (S >> i & 1) {
                cnt++;
                lcm = lcm / gcd(lcm, a[i]) * a[i];
                if (lcm > n) break; // 剪枝
            }
        }
        if (cnt % 2) ans += n / lcm;
        else ans -= n / lcm;
    }
    printf("%lld\n", ans);
    return 0;
}
```

## 四、博弈论

### 知识点1：Nim游戏

#### 核心原理
n堆石子，每堆$a_i$个，两人轮流取，每次从一堆中取任意个，取完获胜。

**结论**：$a_1 \oplus a_2 \oplus ... \oplus a_n \neq 0$ 先手必胜，否则必败。

**证明关键**：
- 异或≠0时，一定存在一种取法使异或变为0（取最高位对应堆，调整）
- 异或=0时，任意取都会使异或≠0

#### C++ 判断
```cpp
bool nimWin(vector<int>& a) {
    int xorSum = 0;
    for (int x : a) xorSum ^= x;
    return xorSum != 0;
}
```

### 知识点2：SG函数（Sprague-Grundy）

#### 核心原理
**Mex运算**：mex(S)=最小的非负整数且不在S中。

**SG值**：SG(x) = mex{SG(y) | x能到y}，终态SG=0。

**组合游戏**：多个独立游戏的SG值=各游戏SG的异或。异或≠0先手胜。

#### 蓝桥杯真题应用：取石子游戏变种
**题目**：多堆石子，每次从一堆取1~k个，SG(x) = x % (k+1)
**输入样例**：
```
3 2  // 3堆，每堆最多取2个
3 4 5
```
**分析**：SG(3)=3%3=0, SG(4)=1, SG(5)=2 → 0⊕1⊕2=3≠0，先手胜。

## 五、高斯消元（解线性方程组）

### 知识点1：高斯消元解线性方程组

#### 核心原理
通过行初等变换将系数矩阵化为上三角/阶梯形，再回代求解。时间O(N³)。

#### 实现思路
1. 枚举列c，找当前列绝对值最大的行交换上来（减小误差）
2. 将主元行归一化（除以a[r][c]）
3. 消去其他行第c列，使其他行在c列全为0
4. 最后判断无解/唯一解/无穷解

#### C++ 实现（浮点数）
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

const double EPS = 1e-8;

// a是增广矩阵 n×(n+1)，返回解向量，空表示无解，size<n表示无穷解
vector<double> gauss(vector<vector<double>>& a) {
    int n = a.size();
    int r = 0; // 非零行数
    for (int c = 0; c < n; c++) {
        int t = r;
        for (int i = r; i < n; i++)
            if (fabs(a[i][c]) > fabs(a[t][c])) t = i;
        if (fabs(a[t][c]) < EPS) continue;
        swap(a[t], a[r]);
        for (int j = n; j >= c; j--) a[r][j] /= a[r][c];
        for (int i = 0; i < n; i++) {
            if (i != r && fabs(a[i][c]) > EPS) {
                double factor = a[i][c];
                for (int j = c; j <= n; j++)
                    a[i][j] -= factor * a[r][j];
            }
        }
        r++;
    }
    // 判断矛盾方程
    for (int i = r; i < n; i++)
        if (fabs(a[i][n]) > EPS) return {};
    vector<double> res(n, 0);
    for (int i = 0; i < r; i++) {
        int pivot = -1;
        for (int j = 0; j < n; j++)
            if (fabs(a[i][j]) > EPS) { pivot = j; break; }
        if (pivot != -1) res[pivot] = a[i][n];
    }
    return res;
}
```
