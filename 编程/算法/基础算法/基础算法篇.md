## 一、排序算法

### 知识点1：快速排序（Quick Sort）

#### 核心原理
基于**分治思想**：从数组中选取一个基准元素（pivot），将数组划分为两部分——小于基准的放左边，大于基准的放右边，再递归处理左右子数组。

平均时间复杂度 $O(N \log N)$，最坏 $O(N^2)$（逆序时）。

#### 实现思路
1. 选择基准（首尾或随机或三者取中）
2. 双指针从两端向中间扫描，交换逆序对
3. 将基准放到最终位置，递归处理左右区间

#### C++ 标准实现
```cpp
#include <iostream>
#include <vector>
using namespace std;

void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int i = l - 1, j = r + 1, x = a[l + r >> 1]; // 基准取中间
    while (i < j) {
        do i++; while (a[i] < x);
        do j--; while (a[j] > x);
        if (i < j) swap(a[i], a[j]);
    }
    quickSort(a, l, j);
    quickSort(a, j + 1, r);
}

int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    quickSort(a, 0, n - 1);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

#### 蓝桥杯真题应用：第k小数
**题目**：给定长度为n的数组，求第k小的数（$1 \le k \le n \le 10^5$）

**输入样例**：
```
5 3
3 1 4 2 5
```
**输出样例**：
```
3
```

**思考推导**：
1. **切入点**：完整排序需要 $O(N \log N)$，利用快速排序的"划分"思想可以只递归包含第k个位置的那一半，得到 $O(N)$ 的**快速选择（Quickselect）算法。
2. **边界条件**：划分后基准位置 $j-l+1$ 表示左半区间元素个数
   - 若 $k \le j-l+1$：第k小在左半，递归 $[l,j]$
   - 否则：第k小在右半，变为找右半的第 $k-(j-l+1)$ 小
3. **易错点**：基准选取避免最坏情况，使用中间位置或随机基准。

**模拟过程**：数组`[3,1,4,2,5]`，k=3
- 第一轮基准=4（中间元素a[2]=4，i=0,j=4 → 交换后数组 `[3,1,2,4,5]`，j=2
- 左半长度 = 3个元素，k=3在左半
- 左半 `[3,1,2]`，基准=1，划分后 `[1,2,3]`，j=0
- 左半长度=1 < 3，去右半找第2个 → 递归右半 `[2,3]`
- 最终得第2小=3

```cpp
int quickSelect(vector<int>& a, int l, int r, int k) {
    if (l >= r) return a[l];
    int i = l - 1, j = r + 1, x = a[l + r >> 1];
    while (i < j) {
        do i++; while (a[i] < x);
        do j--; while (a[j] > x);
        if (i < j) swap(a[i], a[j]);
    }
    int leftSize = j - l + 1;
    if (k <= leftSize) return quickSelect(a, l, j, k);
    else return quickSelect(a, j + 1, r, k - leftSize);
}
```

### 知识点2：归并排序（Merge Sort）

#### 核心原理
**分治思想**：将数组一分为二，分别排序，再将两个有序数组合并为一个有序数组。时间复杂度稳定 $O(N \log N)$，空间 $O(N)$。

核心应用：**求逆序对数量**。

#### 实现思路
1. 递归二分分割数组到单个元素
2. 回溯时用双指针对两个有序区间进行合并
3. 统计逆序对：当右区间元素先放入时，累加左区间剩余元素个数

#### C++ 标准实现（含逆序对统计）
```cpp
#include <iostream>
#include <vector>
using namespace std;

long long mergeSort(vector<int>& a, vector<int>& tmp, int l, int r) {
    if (l >= r) return 0;
    int mid = l + r >> 1;
    long long cnt = 0;
    cnt += mergeSort(a, tmp, l, mid);
    cnt += mergeSort(a, tmp, mid + 1, r);
    
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else {
            tmp[k++] = a[j++];
            cnt += mid - i + 1; // 逆序对累加
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = l; i <= r; i++) a[i] = tmp[i];
    return cnt;
}

int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(n), tmp(n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    long long invCnt = mergeSort(a, tmp, 0, n - 1);
    printf("逆序对数量: %lld\n", invCnt);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

#### 蓝桥杯真题应用：逆序对
**题目**：求数组中逆序对的个数（$n \le 5 \times 10^5$）

**输入样例**：
```
6
2 3 4 5 6 1
```
**输出样例**：
```

```

**思考推导**：
1. **切入点**：$O(N^2)$ 暴力超时，归并排序过程天然适合统计逆序对。
2. **边界条件**：$a[i] > a[j]$ 时，左区间从 $a[i..mid]$ 全部都比 $a[j]$ 构成逆序对。

- i=0(2), j=2(1): 2>1 → cnt+=3(元素2,3,4均>1)，累计+3=4
- 继续...最终总逆序对=5

## 二、二分查找与二分答案

### 知识点1：整数二分

#### 核心原理
在**单调区间**内，通过每次折半查找，将搜索区间缩小一半。时间复杂度 $O(\log N)$。

**本质**：寻找满足某种性质的边界。存在两种模板：
1. 找左边界（第一个满足条件的位置
2. 找右边界（最后一个满足条件的位置

#### 实现思路
1. **左边界模板**：`mid = l + r >> 1`，若满足条件则 `r = mid`，否则 `l = mid + 1`
2. **右边界模板**：`mid = l + r + 1 >> 1`，若满足条件则 `l = mid`，否则 `r = mid - 1`
3. 死循环规避：右边界模板必须+1，否则当`l=r-1时死循环

#### C++ 标准实现
```cpp
// 左边界：第一个 >= x 的位置
int lowerBound(int a[], int n, int x) {
    int l = 0, r = n;
    while (l < r) {
        int mid = l + r >> 1;
        if (a[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return l;
}

// 右边界：最后一个 <= x 的位置
int upperBound(int a[], int n, int x) {
    int l = -1, r = n - 1;
    while (l < r) {
        int mid = l + r + 1 >> 1;
        if (a[mid] <= x) l = mid;
        else r = mid - 1;
    }
    return l;
}
```

#### 蓝桥杯真题应用：数的范围
**题目**：给定升序数组，查询元素x的起始和终止位置（$n \le 10^5$）

**输入样例**：
```
6 3
1 2 2 3 3 4
```
**输出样例**：
```
3 4
```

**思考推导**：
1. **切入点**：两次二分——第一次找第一个x（左边界），第二次找最后一个x（右边界）。
2. **边界条件**：左边界找不到时输出-1 -1。
3. **易错点**：右边界模板不加1会死循环。

**模拟过程**：数组`[1,2,2,3,3,4]`，x=3
- 左边界（第一个>=3）：l=0,r=6 → mid=3,a[3]=3>=3→r=3；l=0,r=3→mid=1,a[1]=2<3→l=2；mid=2,a[2]=2<3→l=3；返回3
- 右边界（最后一个<=3）：l=-1,r=5→mid=3,a[3]=3<=3→l=3；l=3,r=5→mid=4+1=5/2=4,a[4]=3<=3→l=4；l=4,r=5→mid=5,a[5]=4>3→r=4；返回4

### 知识点2：二分答案

#### 核心原理
当问题满足"最大值最小化 / 最小值最大化"且**答案具有单调性**（可行解构成连续区间时，对答案进行二分，每次检查可行性。

**标志词**："使...最小的最大值、最大的最小值、至少需要多少天完成...

#### 实现思路
1. 确定答案上下界 [l, r]
2. 二分答案 mid
3. 写check(mid)函数判断是否可行
4. 根据check结果缩小区间

#### C++ 标准实现框架
```cpp
// 最大值最小化：找最小的满足条件的答案
while (l < r) {
    int mid = l + r >> 1;
    if (check(mid)) r = mid; //可行，尝试更小
    else l = mid + 1;
}

// 最小值最大化：找最大的满足条件的答案
while (l < r) {
    int mid = l + r + 1 >> 1;
    if (check(mid)) l = mid; //可行，尝试更大
    else r = mid - 1;
}
```

#### 蓝桥杯真题应用：跳石头
**题目**：河中有n块石头，搬走m块，使剩余石头间最小距离的最大值最大。（$m < n \le 5\times10^4$）

**输入样例**：
```
25 5 2 // 总长25，5块石头，搬2块
2
11
14
17
21
```
**输出样例**：
```
4
```

**思考推导**：
1. **切入点**："最小距离的最大值"=最小值最大化 → 二分答案。
2. **check函数**：贪心，当前答案为mid时，最少需要搬走多少块石头？
   - 从起点出发，遇到距离<mid就搬掉下一块
3. **边界条件**：起点0和终点L必须保留。
4. **易错点**：check时别忘了最后一块石头到终点的距离。

**模拟过程**：石头位置[2,11,14,17,21]，L=25，m=2
- 二分答案mid=4
  - 起点0→2距离2<4，搬(+1，1块
  - 0→11距离11>=4，留，当前11
  - 11→14=3<4，搬(+1，2块=m，ok
  - 11→17=6>=4，留
  - 17→21=4>=4，留
  - 21→25=4>=4，ok → check(4)=true
- 继续二分更大值...最终答案=4

```cpp
#include <iostream>
#include <vector>
using namespace std;

int L, n, m;
vector<int> pos;

bool check(int mid) {
    int cnt = 0, last = 0;
    // 把终点也当成一块“不能删除的石头”统一处理
    // 这样就不用单独讨论最后一段距离了
    for (int i = 0; i < pos.size(); i++) {
        if (pos[i] - last < mid) {
            cnt++;              // 当前这块不能留，只能删掉
        } else {
            last = pos[i];      // 留下这块，作为新的上一块石头
        }
    }
    return cnt <= m;
}

int main() {
    scanf("%d%d%d", &L, &n, &m);
    pos.resize(n);
    for (int i = 0; i < n; i++) scanf("%d", &pos[i]);
    pos.push_back(L); // 终点加入数组，统一交给 check 处理
    int l = 1, r = L;
    while (l < r) {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    printf("%d\n", l);
    return 0;
}
```

## 三、双指针技巧

### 知识点1：同向双指针（滑动窗口）

#### 核心原理
两个指针同方向移动，维护一个区间 [l, r]，根据条件移动指针，将O(N²)优化到O(N)。

**适用场景**：子数组/子串满足单调性问题（最长/最短满足条件的子数组）。

#### 实现思路
1. 右指针r遍历数组，每次将a[r]加入窗口
2. 当窗口不满足条件时，移动左指针l缩小窗口
3. 每次更新答案

#### C++ 标准实现
```cpp
// 模板：和为target的最长子数组（正整数数组）
int longestSubarray(vector<int>& a, int target) {
    int n = a.size(), sum = 0, ans = 0;
    for (int l = 0, r = 0; r < n; r++) {
        sum += a[r];
        while (sum > target) sum -= a[l++];
        ans = max(ans, r - l + 1);
    }
    return ans;
}
```

#### 蓝桥杯真题应用：最长不重复子串
**题目**：求字符串中最长不含重复字符的子串长度

**输入样例**：
```
abcabcbb
```
**输出样例**：
```
3
```

**思考推导**：
1. **切入点**：用哈希表记录字符最后出现位置，右指针前进，左指针跳到重复位置+1。
2. **边界条件**：左指针只能前进不能后退（取max）。
3. **易错点**：字符集范围（ASCII或全部字符）。

**模拟过程**：s="abcabcbb"
- r=0(a): last[a]=0，窗口[0,0], len=1
- r=1(b): last[b]=1，窗口[0,1], len=2
- r=2(c): len=3，窗口[0,2]
- r=3(a): a已出现last[a]=0→l=max(0,0+1)=1，更新last[a]=3，窗口[1,3], len=3
- 继续...最大长度保持3

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int lengthOfLongestSubstring(string s) {
    vector<int> last(128, -1);
    int ans = 0;
    for (int l = 0, r = 0; r < s.size(); r++) {
        l = max(l, last[s[r]] + 1);
        last[s[r]] = r;
        ans = max(ans, r - l + 1);
    }
    return ans;
}
```

### 知识点2：相向双指针

#### 核心原理
两个指针从两端向中间移动，常用于有序数组两数之和、回文判断等。

#### C++ 标准实现
```cpp
// 两数之和：有序数组中找两个数等于target
vector<int> twoSum(vector<int>& a, int target) {
    int l = 0, r = a.size() - 1;
    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) return {l, r};
        else if (sum < target) l++;
        else r--;
    }
    return {-1, -1};
}
```

## 四、递归与分治

### 知识点1：递归与分治思想

#### 核心原理
**分治**：将大问题分解为相同结构的子问题，递归求解子问题后合并结果。

**递归三要素**：
1. 递归终止条件
2. 递归递推公式
3. 返回值

#### 蓝桥杯真题应用：汉诺塔问题变种（斐波那契数列/快速幂）

**快速幂**（分治经典）见数学篇，此处给出递归框架）：

```cpp
// 递归版快速幂
long long qpow(long long a, long long b, long long p) {
    if (b == 0) return 1 % p;
    long long res = qpow(a, b / 2, p);
    res = res * res % p;
    if (b % 2) res = res * a % p;
    return res;
}
```

## 五、前缀和与差分

### 知识点1：一维前缀和

#### 核心原理
预处理前缀和数组S，其中$S[i] = a[1]+a[2]+...+a[i]$，区间和查询O(1)：
$$\sum_{L}^{R} a[i] = S[R] - S[L-1]$$

#### C++ 标准实现
```cpp
vector<int> buildPrefix(vector<int>& a) {
    int n = a.size();
    vector<int> s(n + 1, 0);
    for (int i = 1; i <= n; i++) s[i] = s[i-1] + a[i-1];
    return s;
}
int querySum(vector<int>& s, int l, int r) { // 1-based [l,r]
    return s[r] - s[l-1];
}
```

### 知识点2：二维前缀和

#### 核心原理
$$S[i][j] = \sum_{x=1}^{i}\sum_{y=1}^{j} a[x][y]$$
容斥求子矩阵和：
$$S_{(x1,y1,x2,y2)} = S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]$$

#### C++ 标准实现
```cpp
void buildPrefix2D(vector<vector<int>>& a, vector<vector<int>>& s) {
    int n = a.size() - 1, m = a[0].size() - 1;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1];
}
int query2D(vector<vector<int>>& s, int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1];
}
```

#### 蓝桥杯真题应用：子矩阵求和
**题目**：n×m矩阵，q次查询子矩阵元素和（$n,m \le 10^3, q \le 10^5$）

**思考推导**：
1. **切入点**：直接查询O(nm)超时，前缀和O(1)查询。
2. **边界条件**：1-based索引，S[0][*]=S[*][0]=0。
3. **易错点**：容斥公式中减去的重复部分。

### 知识点3：差分

#### 核心原理
差分数组d，区间修改O(1)，最后前缀和还原。

**一维差分**：区间[L,R]加c：`d[L]+=c, d[R+1]-=c`

**二维差分**：子矩阵(x1,y1)-(x2,y2)加c：
```
d[x1][y1]+=c, d[x2+1][y1]-=c, d[x1][y2+1]-=c, d[x2+1][y2+1]+=c
```

#### C++ 标准实现
```cpp
// 一维差分：区间加c
void addDiff(vector<int>& d, int l, int r, int c) {
    d[l] += c; d[r+1] -= c;
}
void restore(vector<int>& d, vector<int>& res) {
    int cur = 0;
    for (int i = 1; i < res.size(); i++) {
        cur += d[i]; res[i] = cur;
    }
}
```

#### 蓝桥杯真题应用：区间加（多次区间修改后查询）
**题目**：初始全0数组，m次操作[L,R]加c，求最终数组

**输入样例**：
```
5 3
1 3 2
2 4 3
1 5 1
```
**输出样例**：
```
3 6 6 4 1
```

**模拟过程**：
- 操作1(1-3+2): d[1]=2, d[4]=-2
- 操作2(2-4+3): d[2]=3, d[5]=-3
- 操作3(1-5+1): d[1]+=1→3, d[6]-=1
- 前缀和还原：
  i=1: 3 → a[1]=3
  i=2: 3+3=6 → a[2]=6
  i=3: 6+0=6 → a[3]=6
  i=4: 6+(-2)=4 → a[4]=4
  i=5: 4+3=7? 不，i=5:4+d[5]=4+(-3)=1 → a[5]=1
