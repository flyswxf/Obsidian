当容器支持双向迭代器时，想取“最后一个元素”，本质上是在取 `end()` 的前一个位置。

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s = {1, 3, 5, 7};

    // 容器为空时，不能取最后一个元素
    if (s.empty()) {
        return 0;
    }

    // 写法 1：先拿到最后一个元素的迭代器
    auto it = prev(s.end());
    cout << *it << '\n';   // 7

    // 写法 2：直接取反向迭代器指向的元素
    cout << *s.rbegin() << '\n';   // 7

    return 0;
}
```

- `end()` 指向的是“最后一个元素的后一个位置”，不能直接解引用
- `prev(s.end())` 才是真正的最后一个元素位置
- `*s.rbegin()` 更直观，竞赛里通常更推荐

常见错误：

```cpp
auto it = prev(s.end()); // 当 s 为空时，这句就是未定义行为
cout << *s.end();        // 错，end() 不能解引用
```

更容易记的思路：

1. `begin()` 指向第一个元素
2. `end()` 不指向任何有效元素，只是“结尾标记”
3. 所以“最后一个元素”应该写成 `end()` 往前退一步

如果只是想拿值，最简洁写法是：

```cpp
int x = *s.rbegin();
```

如果后面还要删除最后一个元素，可以写成：

```cpp
auto it = prev(s.end());
s.erase(it);
```
