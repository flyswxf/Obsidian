## 一、栈与队列

### 知识点1：单调栈

#### 核心原理
栈中元素保持单调性（递增/递减），用于解决**每个元素左边/右边第一个比它大/小的元素**问题。时间复杂度O(N)，每个元素最多入栈出栈各一次。

#### 实现思路
1. 遍历数组，当前元素为a[i]
2. 当栈顶元素不满足单调性要求时，弹出并记录答案
3. 将当前元素压入栈

#### C++ 标准实现
```cpp
// 每个元素右边第一个比它大的元素位置
vector<int> nextGreater(vector<int>& a) {
    int n = a.size();
    vector<int> res(n, -1);
    stack<int> st; // 存下标，值单调递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            res[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

#### 蓝桥杯真题应用：柱状图中最大的矩形
**题目**：给定n个柱子高度，求能构成的最大矩形面积（$n \le 10^5$）

**输入样例**：
```
6
2 1 5 6 2 3
```
**输出样例**：
```
10
```

**思考推导**：
1. **切入点**：对每个柱子i，以h[i]为高的矩形，左右边界分别是左边/右边第一个比h[i]小的位置。
2. **边界条件**：左边界不存在设为-1，右边界不存在设为n。宽度 = r - l - 1。
3. **易错点**：栈中存储下标而非值；相等元素的处理（允许等于避免重复计算）。

**模拟过程**：h=[2,1,5,6,2,3]
- i=2(h=5): 左小=1(idx1), 右小=4(idx2) → 宽=4-1-1=2, 面积=5×2=10
- i=3(h=6): 左小=2(idx5), 右小=4(idx2) → 宽=1, 面积=6
- 最大面积=10

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<int> h(n);
    for (int i = 0; i < n; i++) scanf("%d", &h[i]);
    
    vector<int> left(n, -1), right(n, n);
    stack<int> st;
    
    for (int i = 0; i < n; i++) {
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        if (!st.empty()) left[i] = st.top();
        st.push(i);
    }
    while (!st.empty()) st.pop();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        if (!st.empty()) right[i] = st.top();
        st.push(i);
    }
    
    long long ans = 0;
    for (int i = 0; i < n; i++)
        ans = max(ans, (long long)h[i] * (right[i] - left[i] - 1));
    printf("%lld\n", ans);
    return 0;
}
```

### 知识点2：单调队列

#### 核心原理
队列中元素保持单调性，用于解决**滑动窗口最大值/最小值**问题。时间复杂度O(N)。

#### 实现思路
1. 右端入队：弹出队尾所有不满足单调性的元素
2. 左端出队：队首元素超出窗口范围时弹出
3. 窗口成形后，队首即为答案

#### C++ 标准实现
```cpp
// 滑动窗口最大值
vector<int> maxSlidingWindow(vector<int>& a, int k) {
    int n = a.size();
    deque<int> dq; // 存下标，值单调递减
    vector<int> res;
    for (int i = 0; i < n; i++) {
        // 弹出队尾比当前小的
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
        dq.push_back(i);
        // 弹出超出窗口的队首
        while (dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) res.push_back(a[dq.front()]);
    }
    return res;
}
```

#### 蓝桥杯真题应用：滑动窗口最大值
**题目**：数组长度n，窗口大小k，输出每个窗口内最大值（$n \le 10^6$）

**输入样例**：
```
8 3

```
**输出样例**：
```

```

**模拟过程**：
- i=2,窗口[1,3,-1]: 队列[1(idx),2(idx-1被弹出)] → 首=3
- i=3,窗口[3,-1,-3]: → 首=3
- i=4,窗口[-1,-3,5]: 队列前两个弹出 → 首=5
- 以此类推...

## 二、链表（STL list 或 数组模拟）

### 知识点1：数组模拟链表

#### 核心原理
使用两个数组`val[]`和`nxt[]`模拟单链表，优势是比指针实现快，适合竞赛中需要大量插入删除的场景。

#### C++ 标准实现
```cpp
const int MAXN = 100010;
int val[MAXN], nxt[MAXN], head, idx;

void init() { head = -1; idx = 0; }

// 头插法
void addHead(int x) {
    val[idx] = x; nxt[idx] = head; head = idx++;
}

// 在第k个插入的节点后插入（idx从0开始）
void insert(int k, int x) {
    val[idx] = x; nxt[idx] = nxt[k]; nxt[k] = idx++;
}

// 删除第k个插入的节点的下一个
void remove(int k) {
    nxt[k] = nxt[nxt[k]];
}
```

## 三、哈希表

### 知识点1：开放寻址法/拉链法

#### 核心原理
将关键字通过哈希函数映射到数组下标，冲突时用拉链（链表）或开放寻址（探测下一个空位）解决。

#### C++ 标准实现（拉链法）
```cpp
const int MOD = 100003; // 取质数
int h[MOD], e[MAXN], ne[MAXN], idx;

void init() { memset(h, -1, sizeof h); idx = 0; }

void insert(int x) {
    int t = (x % MOD + MOD) % MOD; // 保证非负
    e[idx] = x; ne[idx] = h[t]; h[t] = idx++;
}

bool find(int x) {
    int t = (x % MOD + MOD) % MOD;
    for (int i = h[t]; i != -1; i = ne[i])
        if (e[i] == x) return true;
    return false;
}
```

## 四、并查集（DSU）

（已有单独笔记[并查集.md](file:///d:/Obsidian/编程/算法/数据结构/模板/并查集.md)，此处补充应用实例）

#### 蓝桥杯真题应用：合根植物
**题目**：n×m个格子，k次操作将两个格子合并，求最后连通块个数

**输入样例**：
```
2 2 // 2行2列
3   // 3次合并
1 2
1 3
2 4
```
**输出样例**：
```
1
```

**思考推导**：
1. **切入点**：标准并查集连通块问题，合并后统计集合数。
2. **边界条件**：将二维坐标(i,j)映射为(i-1)*m+j。
3. **易错点**：合并前检查是否已连通，集合总数初始为n*m。

```cpp
#include <iostream>
#include <vector>
#include <numeric>
using namespace std;

struct DSU {
    vector<int> parent;
    int cnt; // 连通块数量
    DSU(int n) : parent(n+1), cnt(n) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a != b) { parent[a] = b; cnt--; }
    }
};
```

## 五、堆（优先队列）

### 知识点1：手写堆/STL优先队列

#### 核心原理
完全二叉树，父节点优先级高于子节点。支持插入、删除堆顶O(logN)，取堆顶O(1)。

**STL用法**：
- 大根堆：`priority_queue<int> q;`
- 小根堆：`priority_queue<int, vector<int>, greater<int>> q;`

#### C++ 手写堆实现（小根堆）
```cpp
const int MAXN = 100010;
int h[MAXN], sz;

void up(int x) {
    while (x > 1 && h[x] < h[x/2]) {
        swap(h[x], h[x/2]);
        x /= 2;
    }
}

void down(int x) {
    int t = x;
    if (2*x <= sz && h[2*x] < h[t]) t = 2*x;
    if (2*x+1 <= sz && h[2*x+1] < h[t]) t = 2*x+1;
    if (t != x) { swap(h[x], h[t]); down(t); }
}

void push(int x) { h[++sz] = x; up(sz); }
int pop() {
    int res = h[1]; h[1] = h[sz--]; down(1);
    return res;
}
```

#### 蓝桥杯真题应用：合并果子（哈夫曼编码思想）
**题目**：n堆果子，每次合并两堆消耗体力等于两堆之和，求全部合并最小消耗

**输入样例**：
```
5
1 2 3 4 5
```
**输出样例**：
```
33
```

**思考推导**：
1. **切入点**：贪心——每次选最小两堆合并，哈夫曼树思想。用小根堆维护。
2. **边界条件**：合并到只剩一堆为止，共n-1次合并。
3. **易错点**：答案用long long。

**模拟过程**：[1,2,3,4,5]
- 合1+2=3, 堆=[3,3,4,5], 累加=3
- 合3+3=6, 堆=[4,5,6], 累加=3+6=9
- 合4+5=9, 堆=[6,9], 累加=9+9=18
- 合6+9=15, 累加=18+15=33

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    priority_queue<int, vector<int>, greater<int>> q;
    for (int i = 0; i < n; i++) {
        int x; scanf("%d", &x); q.push(x);
    }
    long long ans = 0;
    while (q.size() > 1) {
        int a = q.top(); q.pop();
        int b = q.top(); q.pop();
        ans += a + b;
        q.push(a + b);
    }
    printf("%lld\n", ans);
    return 0;
}
```

## 六、线段树

（已有单独笔记[线段树.md](file:///d:/Obsidian/编程/算法/数据结构/模板/线段树.md)，此处补充完整实现及应用）

### 知识点1：线段树（区间修改+区间查询）

#### 核心原理
将区间划分为二叉树结构，每个节点代表一个区间。利用懒标记（lazy tag）将区间修改延迟到必要时下传，支持O(logN)区间修改和查询。

#### 实现思路
1. 建树：递归二分，叶子赋值，父节点合并
2. 修改：若当前区间完全在目标区间内，打懒标记并更新节点值；否则先下传懒标记再递归子树
3. 查询：同上逻辑，收集答案

#### C++ 标准实现（区间加+区间和）
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct SegTree {
    int n;
    vector<long long> sum, add;
    
    SegTree(int size, vector<int>& a) : n(size), sum(4*n), add(4*n) {
        build(1, 1, n, a);
    }
    
    void push_up(int u) { sum[u] = sum[u<<1] + sum[u<<1|1]; }
    
    void push_down(int u, int ln, int rn) {
        if (add[u]) {
            sum[u<<1] += add[u] * ln;
            sum[u<<1|1] += add[u] * rn;
            add[u<<1] += add[u];
            add[u<<1|1] += add[u];
            add[u] = 0;
        }
    }
    
    void build(int u, int l, int r, vector<int>& a) {
        if (l == r) { sum[u] = a[l]; return; }
        int mid = l + r >> 1;
        build(u<<1, l, mid, a);
        build(u<<1|1, mid+1, r, a);
        push_up(u);
    }
    
    void update(int u, int l, int r, int ql, int qr, int c) {
        if (ql <= l && r <= qr) {
            sum[u] += (long long)c * (r - l + 1);
            add[u] += c;
            return;
        }
        int mid = l + r >> 1;
        push_down(u, mid - l + 1, r - mid);
        if (ql <= mid) update(u<<1, l, mid, ql, qr, c);
        if (qr > mid) update(u<<1|1, mid+1, r, ql, qr, c);
        push_up(u);
    }
    
    long long query(int u, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return sum[u];
        int mid = l + r >> 1;
        push_down(u, mid - l + 1, r - mid);
        long long res = 0;
        if (ql <= mid) res += query(u<<1, l, mid, ql, qr);
        if (qr > mid) res += query(u<<1|1, mid+1, r, ql, qr);
        return res;
    }
    
    void Update(int l, int r, int c) { update(1, 1, n, l, r, c); }
    long long Query(int l, int r) { return query(1, 1, n, l, r); }
};
```

#### 蓝桥杯真题应用：区间加减+区间求和
**题目**：n个数，m次操作，支持[L,R]加c，查询[L,R]和

**输入样例**：
```
5 3
1 5 4 2 3
Q 2 4      // 查询2-4和
C 1 5 2    // 1-5加2

```
**输出样例**：


**思考推导**：

2. **边界条件**：1-based索引。
3. **易错点**：懒标记下传时乘以区间长度；sum和add用long long。

- Q[2-4]: 5+4+2=11
- C[1-5]+2: a=[3,7,6,4,5]
- Q[2-4]: 7+6+4=17

## 七、树状数组（Binary Indexed Tree / Fenwick Tree）

### 知识点1：单点修改+区间查询

#### 核心原理
利用二进制lowbit思想，将每个数x与x+lowbit(x)、x-lowbit(x)关联，形成树状结构。单点修改和前缀和查询均O(logN)。

**lowbit(x) = x & -x**：取x二进制最低位的1及后面的0。

#### 实现思路
1. 单点修改：从x向上跳到n，每个tr[x]加c
2. 前缀和查询：从x向下跳到0，累加tr[x]
3. 区间和=前缀(r)-前缀(l-1)

#### C++ 标准实现
```cpp
struct BIT {
    int n;
    vector<long long> tr;
    
    BIT(int size) : n(size), tr(n + 1, 0) {}
    
    int lowbit(int x) { return x & -x; }
    
    void add(int x, long long c) {
        for (; x <= n; x += lowbit(x)) tr[x] += c;
    }
    
    long long query(int x) {
        long long res = 0;
        for (; x > 0; x -= lowbit(x)) res += tr[x];
        return res;
    }
    
    long long rangeQuery(int l, int r) {
        return query(r) - query(l - 1);
    }
};
```

### 知识点2：区间修改+单点查询（差分思想）

#### 核心原理
对差分数组d建树状数组：
- 区间[L,R]加c → add(L, c), add(R+1, -c)
- 单点查询a[x] = 前缀和query(x)

### 知识点3：区间修改+区间查询（双树状数组）

#### 核心原理
利用数学推导，需要两个树状数组tr1和tr2：
- 更新[L,R]+c: `tr1.add(L,c), tr1.add(R+1,-c), tr2.add(L,c*L), tr2.add(R+1,-c*(R+1))`
- 前缀和S(x) = `(x+1)*tr1.query(x) - tr2.query(x)`

```cpp
struct BIT_Range {
    int n;
    BIT tr1, tr2;
    BIT_Range(int size) : n(size), tr1(size), tr2(size) {}
    void rangeAdd(int l, int r, long long c) {
        tr1.add(l, c); tr1.add(r+1, -c);
        tr2.add(l, c*l); tr2.add(r+1, -c*(r+1));
    }
    long long prefixSum(int x) {
        return (long long)(x+1)*tr1.query(x) - tr2.query(x);
    }
    long long rangeSum(int l, int r) {
        return prefixSum(r) - prefixSum(l-1);
    }
};
```

#### 蓝桥杯真题应用：逆序对（树状数组求法）
**题目**：求n个数逆序对个数（离散化+树状数组）

**思考推导**：
1. **切入点**：从右往左遍历，a[i]的逆序对贡献=已插入元素中<a[i]的个数，即query(a[i]-1)。
2. **边界条件**：值域过大需离散化（坐标压缩）。
3. **易错点**：相同元素处理，查询用a[i]-1避免统计相等。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) { scanf("%d", &a[i]); b[i] = a[i]; }
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    int m = b.size();
    BIT bit(m);
    long long ans = 0;
    for (int i = n-1; i >= 0; i--) {
        int x = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
        ans += bit.query(x - 1);
        bit.add(x, 1);
    }
    printf("%lld\n", ans);
    return 0;
}
```
