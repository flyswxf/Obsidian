## 一、贪心算法

### 知识点1：区间贪心

#### 核心原理
贪心算法核心：每步选**当前最优**的局部选择，最终得到全局最优。适用场景要求问题具备**贪心选择性质**（局部最优→全局最优）和**最优子结构**。

#### 经典区间问题
1. **区间选点**：给定n个区间，选最少点使每个区间至少含一个点 → 按右端点升序，每次选最右端点
2. **最大不相交区间数量**：按右端点升序，能选就选
3. **区间分组**：最少分几组使每组不相交 → 按左端点升序，用小根堆存每组最后右端点
4. **区间覆盖**：最少区间覆盖目标线段 → 按左端点升序，每次选覆盖当前起点且右端点最大的区间

#### C++ 区间选点/不相交区间
```cpp
// 最少选点覆盖所有区间 = 最大不相交区间数量
struct Interval { int l, r; };
int maxNonOverlap(vector<Interval>& a) {
    sort(a.begin(), a.end(), [](Interval& x, Interval& y){ return x.r < y.r; });
    int cnt = 0, last = -2e9;
    for (auto& itv : a) {
        if (itv.l > last) { // 不相交则选
            cnt++;
            last = itv.r;
        }
    }
    return cnt;
}
```

#### C++ 区间分组
```cpp
int minGroups(vector<Interval>& a) {
    sort(a.begin(), a.end(), [](Interval& x, Interval& y){ return x.l < y.l; });
    priority_queue<int, vector<int>, greater<int>> pq; // 每组最后右端点
    for (auto& itv : a) {
        if (!pq.empty() && pq.top() < itv.l) { // 可放入最早结束的那组
            pq.pop();
        }
        pq.push(itv.r);
    }
    return pq.size();
}
```

#### 蓝桥杯真题应用：区间覆盖
**题目**：数轴上[1,T]，n个区间[L_i,R_i]，选最少区间完全覆盖[1,T]。

**输入样例**：
```
5 10
1 7
3 6
5 9
8 10
9 10
```
**输出样例**：
```
2  // [1,7] + [8,10]，覆盖1-10
```

**思考推导**：
1. **切入点**：按左端点升序。当前覆盖到now=1，在所有L≤now的区间中选R最大的那个。
2. **边界条件**：找不到可扩展区间或now突破T时结束。
3. **易错点**：严格区分L≤now还是L≤now+1，题目区间是否是闭区间。

```cpp
int coverInterval(vector<Interval>& a, int T) {
    sort(a.begin(), a.end(), [](Interval& x, Interval& y){ return x.l < y.l; });
    int now = 1, i = 0, ans = 0, n = a.size();
    while (now <= T) {
        int best = now - 1;
        while (i < n && a[i].l <= now) {
            best = max(best, a[i].r);
            i++;
        }
        if (best < now) return -1; // 无法覆盖
        ans++;
        now = best + 1;
    }
    return ans;
}
```

### 知识点2：Huffman树 / 哈夫曼编码

#### 核心原理
合并果子的变种：每次选两个最小权值节点合并为新节点（权为两节点之和），所有中间节点权值之和=总代价。

**贪心正确性**：小权值节点深度大（合并次数多），总代价最小。

实现用小根堆，时间O(N log N)，同合并果子。

## 二、离散化

### 知识点1：坐标压缩

#### 核心原理
当数值域极大（如$10^9$）但实际出现的数值个数较少（如$10^5$）时，将实际出现的值映射为连续的小整数排名，方便用数组下标访问（树状数组、线段树等）。

#### 实现思路
1. 将所有需要离散化的值存入辅助数组alls
2. 排序alls并去重（unique+erase）
3. 用lower_bound查询值在alls中的排名+1（1-based）

#### C++ 标准实现
```cpp
vector<int> alls;
// 1. 插入所有要离散化的值: alls.push_back(x);
// 2. 排序去重:
sort(alls.begin(), alls.end());
alls.erase(unique(alls.begin(), alls.end()), alls.end());
// 3. 查询离散化结果（1-based）:
int getIndex(int x) {
    return lower_bound(alls.begin(), alls.end(), x) - alls.begin() + 1;
}
```

#### 蓝桥杯真题应用：区间和（离散化+前缀和/树状数组）
**题目**：数轴无限长，初始全0，n次操作某位置加c，m次查询区间[L,R]和。（位置值≤$10^9$，n,m≤$10^5$）

**思考推导**：
1. **切入点**：位置值大但数量少，将所有出现的位置（修改点+查询L-1和R）全部离散化。
2. **边界条件**：查询区间和需要L-1和R两个位置，也加入离散化。
3. **易错点**：unique之前必须先排序；getIndex返回+1方便前缀和/树状数组使用。

## 四、离线处理

### 知识点1：将查询离线排序

#### 核心原理
**在线**：每个查询立即处理。**离线**：先读入所有查询，按某种策略排序后统一处理，利用单调性/前缀信息加速。

适用场景：查询可重排、存在单调性、可以一次性利用处理历史信息。

#### 典型应用：莫队算法（Mo's Algorithm）
区间查询分块排序，用左右指针移动维护当前答案，时间O((N√N)。

**莫队排序规则**：块号为左端点/√N，块号奇升偶降（奇偶化排序优化）。

```cpp
// 莫队模板框架（求区间不同元素个数为例）
int n, m, len;
vector<int> a, ans, cnt;
struct Query { int l, r, id; } q[100010];

bool moCmp(Query& x, Query& y) {
    int bx = x.l / len, by = y.l / len;
    if (bx != by) return bx < by;
    return (bx % 2) ? (x.r < y.r) : (x.r > y.r); // 奇偶化
}

int res = 0;
void add(int x) { if (++cnt[x] == 1) res++; }
void del(int x) { if (--cnt[x] == 0) res--; }

void moSolve() {
    len = sqrt(n);
    sort(q, q + m, moCmp);
    int l = 1, r = 0;
    for (int i = 0; i < m; i++) {
        while (l > q[i].l) add(a[--l]);
        while (r < q[i].r) add(a[++r]);
        while (l < q[i].l) del(a[l++]);
        while (r > q[i].r) del(a[r--]);
        ans[q[i].id] = res;
    }
}
```
