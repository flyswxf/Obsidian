# 划分测试（等价类）笔记

## 等价类的定义
- 将输入域按“行为相同或近似相同”的数据集合分组，每组称为一个等价类。
- 在同一类中任取一个代表值进行测试，期望程序表现一致，从而减少用例数量。
- 分为“有效等价类”（满足规格约束）与“无效等价类”（不满足约束，用于健壮性与错误处理）。
- 边界值分析关注等价类边缘的取值（如上下界、长度限制、空/满/极端）。

## 等价类类型示例（Obsidian 表格）
| Type        | Eq. Partition Rule                | Example: Specification                                                   | Example: Eq. Classes                                                                         |
| ----------- | --------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Range       | 区间内为一类；区间外通常拆两类（低于/超过）            | `speed ∈ [60..90]`<br>`area: float`（示例值）<br>`age: int`<br>`letter: char` | `{50}`, `{75}`, `{92}`<br>`{-1.0}`, `{15.52}`<br>`{-1}`, `{56}`, `{132}`<br>`{'J'}`, `{'3'}` |
| String      | 至少一类包含所有合法字符串，另一类包含所有非法或约束不满足的字符串 | `fname: String`                                                          | `{'e'}`, `{'Sue'}`, `{'Loooong Name'}`                                                       |
| Enumeration | 每个枚举值单独成类（或按行为相同的值合并）             | `autocolor: {red, blue, green}`                                          | `{red}`, `{blue}`, `{green}`                                                                 |
| Array       | 合法数组一类；空数组单独一类；超出期望大小或含非法元素的一类    | `int[] aName: new int[3]`                                                | `{[]}`, `{-10, 20}`, `{-9, 0, 12, 15}`                                                       |

## 目标与核心思想
- 用“等价类”把庞大的输入域分组，每类用少量代表值即可覆盖相同行为。
- 在多变量场景，还需考虑变量间的关系划分与组合策略。

## 识别被测变量（输入域）
- 函数/方法的入参。
- 被测代码读取的全局或成员变量。
- 被测代码内部调用方法/函数返回的数据，以及可能被改写的数据。


## 示例：`substringsBetween(str, open, close)`

### Specification
- 在字符串 `str` 中搜索由起始标记 `open` 与结束标记 `close` 分隔的子串，返回所有匹配子串组成的数组。
	- `str`：包含子串的字符串。`str == null` 返回 `null`；`str == ""`（空串）返回空数组（课程原文为“empty string returns another empty string”，在数组语义下通常视作空数组）。
	- `open`：标识子串起始的字符串。`open == ""` 返回 `null`。
	- `close`：标识子串结束的字符串。`close == ""` 返回 `null`。
- 若不存在匹配，则返回 `null`；否则返回 `String[]`。

### 输入等价类表
| 变量      | 等价类    | 代表值示例      | 预期影响            |
| ------- | ------ | ---------- | --------------- |
| `str`   | `null` | `null`     | 返回 `null`       |
| `str`   | 空串     | `""`       | 返回 `[]`         |
| `str`   | 长度为 1  | `"a"`      | 可能无匹配或仅与单字符标记匹配 |
| `str`   | 长度 > 1 | `"<a><b>"` | 常规处理，可能产生多段匹配   |
| `open`  | `null` | `null`     | 返回 `null`       |
| `open`  | 空串     | `""`       | 返回 `null`（不合法）  |
| `open`  | 长度为 1  | `"<"`      | 合法，参与匹配         |
| `open`  | 长度 > 1 | `"[["`     | 合法，参与匹配         |
| `close` | `null` | `null`     | 返回 `null`       |
| `close` | 空串     | `""`       | 返回 `null`（不合法）  |
| `close` | 长度为 1  | `">"`      | 合法，参与匹配         |
| `close` | 长度 > 1 | `"]]"`     | 合法，参与匹配         |

### 关系划分表（位置/比较/出现次数）
| 关系 | 等价类/取值 | 示例 |
| --- | --- | --- |
| `str` 是否包含 `open` | 否 / 是 | `"abc"` 不含 `"["`；`"<a>"` 含 `"<"` |
| `open` 在 `str` 的位置 | 开头 / 末尾 / 中间 / 靠近边缘 / 居中 | `open` 索引 `0` / `len-1-open.len` / `len/2` |
| `str` 是否包含 `close` | 否 / 是 | `"abc"` 不含 `">"`；`"<a>"` 含 `">"` |
| `close` 在 `str` 的位置 | 开头 / 末尾 / 中间 / 靠近边缘 / 居中 | 与上类似 |
| `open == close` | 是 / 否 | `"<" == "<"` / `"<" != ">"` |
| 顺序 | `open` 在 `close` 之前 / 之后 | 合法匹配 / 无匹配 |
| 出现次数 | 单次 / 多次 | `"<a><b>"` 产生两段匹配 |

### 输出等价类表
| 输出 | 含义 | 示例 |
| --- | --- | --- |
| `null` | 无任何匹配或输入不合法（如 `open/close` 为空串） | `str` 不含 `open/close` |
| `[]` | 空数组（如 `str` 为空串且不匹配） | `[]` |
| `[1]` | 单段匹配 | `["a"]` （`str="<a>"`，`open="<"`，`close=">"`） |
| `[n]` | 多段匹配 | `["a", "b"]` （`str="<a><b>"`） |
| 元素取值 | 可能为空串、单字符或一般字符串 | `["", "x"]` （相邻标记产生空串） |
