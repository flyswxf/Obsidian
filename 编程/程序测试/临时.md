这是一个针对你提供的图片代码进行的**活跃变量分析 (Live Variables Analysis)**。

### 1. 代码与控制流图 (CFG)

首先，我们将代码分解为带编号的语句（节点）：

*   **1**: `x = 2;`
*   **2**: `y = 4;`
*   **3**: `x = 1;`
*   **4**: `if (y > x)`
*   **5**: `z = y;` (True 分支)
*   **6**: `z = y * y;` (False 分支)
*   **7**: `x = z;` (False 分支)

**控制流 (Edges)**:
*   1 -> 2 -> 3 -> 4
*   4 -> 5 (True) -> Exit
*   4 -> 6 (False) -> 7 -> Exit

### 2. Gen 和 Kill 集合

对于活跃变量分析：
*   **Gen(s)**: 在语句 s 中使用且在使用前未被重定义的变量。
*   **Kill(s)**: 在语句 s 中定义的变量。

| 语句 (Statement) | $gen(s)$ | $kill(s)$ |
| :--- | :--- | :--- |
| **1** `x = 2` | $\emptyset$ | $\{x\}$ |
| **2** `y = 4` | $\emptyset$ | $\{y\}$ |
| **3** `x = 1` | $\emptyset$ | $\{x\}$ |
| **4** `if (y > x)` | $\{x, y\}$ | $\emptyset$ |
| **5** `z = y` | $\{y\}$ | $\{z\}$ |
| **6** `z = y * y` | $\{y\}$ | $\{z\}$ |
| **7** `x = z` | $\{z\}$ | $\{x\}$ |

### 3. 数据流方程求解 (Data Flow Analysis)

我们使用后向分析 (Backward Analysis)。
*   $LV_{exit}(s) = \bigcup_{p \in succ(s)} LV_{entry}(p)$
*   $LV_{entry}(s) = gen(s) \cup (LV_{exit}(s) - kill(s))$

我们从 Exit 往回推导 (假设 Exit 处没有变量活跃)：

**第一轮迭代 (及最终结果)**:

1.  **语句 5 (`z = y`)**:
    *   $LV_{exit}(5) = \emptyset$ (通向 Exit)
    *   $LV_{entry}(5) = \{y\} \cup (\emptyset - \{z\}) = \{y\}$

2.  **语句 7 (`x = z`)**:
    *   $LV_{exit}(7) = \emptyset$ (通向 Exit)
    *   $LV_{entry}(7) = \{z\} \cup (\emptyset - \{x\}) = \{z\}$

3.  **语句 6 (`z = y * y`)**:
    *   $LV_{exit}(6) = LV_{entry}(7) = \{z\}$
    *   $LV_{entry}(6) = \{y\} \cup (\{z\} - \{z\}) = \{y\}$

4.  **语句 4 (`if y > x`)**:
    *   $LV_{exit}(4) = LV_{entry}(5) \cup LV_{entry}(6) = \{y\} \cup \{y\} = \{y\}$
    *   $LV_{entry}(4) = \{x, y\} \cup (\{y\} - \emptyset) = \{x, y\}$

5.  **语句 3 (`x = 1`)**:
    *   $LV_{exit}(3) = LV_{entry}(4) = \{x, y\}$
    *   $LV_{entry}(3) = \emptyset \cup (\{x, y\} - \{x\}) = \{y\}$

6.  **语句 2 (`y = 4`)**:
    *   $LV_{exit}(2) = LV_{entry}(3) = \{y\}$
    *   $LV_{entry}(2) = \emptyset \cup (\{y\} - \{y\}) = \emptyset$

7.  **语句 1 (`x = 2`)**:
    *   $LV_{exit}(1) = LV_{entry}(2) = \emptyset$
    *   $LV_{entry}(1) = \emptyset \cup (\emptyset - \{x\}) = \emptyset$

### 4. 最终结果表

| 语句 | 代码 | $LV_{entry}$ (In) | $LV_{exit}$ (Out) |
| :--- | :--- | :--- | :--- |
| **1** | `x = 2` | $\emptyset$ | $\emptyset$ |
| **2** | `y = 4` | $\emptyset$ | $\{y\}$ |
| **3** | `x = 1` | $\{y\}$ | $\{x, y\}$ |
| **4** | `if (y > x)` | $\{x, y\}$ | $\{y\}$ |
| **5** | `z = y` | $\{y\}$ | $\emptyset$ |
| **6** | `z = y * y` | $\{y\}$ | $\{z\}$ |
| **7** | `x = z` | $\{z\}$ | $\emptyset$ |

### 5. 观察与优化 (Dead Code)

根据分析结果，我们可以发现一些**死代码 (Dead Code)**：
1.  **语句 1 (`x = 2`)**: 其 $LV_{exit}$ 为空，意味着此处定义的 `x` 在后续没有被使用（在语句 3 被重新定义了）。这是一行死代码。
2.  **语句 5 (`z = y`)**: 其 $LV_{exit}$ 为空，定义的 `z` 没有被使用。
3.  **语句 7 (`x = z`)**: 其 $LV_{exit}$ 为空，定义的 `x` 没有被使用。
