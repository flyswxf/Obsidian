### 用例描述的格式
```
用例 X
简要描述
	.
主要参与者：
前置条件：
主事件流
	1. xxx
	2. xxx
	3. 拓展点 xxx（不用对拓展内容进行解释）
	4. 用例结束

拓展
	2a. xxx（2执行中发生的问题，导致2无法再执行）
	2a.1. xxx
	2a.2. 用例失败结束
	7a. xxx
	7a.1. 跳转至步骤8继续
	7b. xxx
	7b.1. xxx
	7b.2. 用例失败结束
	 
```




```
Brief Description

	This use case ...
Flow of Events
	Basic Flow
		...
		...
	Alternative Flows
		event1
			If in the Basic Flow, ...
		event2
			...
		...
Special Requirements
	...
Pre-Conditions
	...
Post-Conditions
	...
Extension Points
	...
```
- 如果描述的用例包含子用例, 可以在Basic Flow中写`当...引入子用例...`
