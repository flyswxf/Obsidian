### 描述的形式:
- 形式文本
- 非形式文本
- 交互图
- 状态图

### 用例描述的格式
```
Brief Description

	This use case ...
Flow of Events
	Basic Flow
		...
		...
	Alternative Flows
		event1
			If in the Basic Flow, ...
		event2
			...
		...
Special Requirements
	...
Pre-Conditions
	...
Post-Conditions
	...
Extionsion Points
	...
```
- 如果描述的用例包含子用例, 可以在Basic Flow中写`当...引入子用例...`
