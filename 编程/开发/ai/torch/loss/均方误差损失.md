# nn.MSELoss()

**均方误差损失 (Mean Squared Error Loss)**，也称为 L2 损失，常用于**回归任务**中，衡量模型预测值与真实值之间的差异。

### 使用

接受参数:
- `input`: 模型的预测值，形状可以是任意的，例如 $(N, *)$。
- `target`: 真实标签，形状必须与 `input` 相同。

```python
import torch
from torch import nn

# 预测值和真实值
predictions = torch.tensor([2.5, 0.0, 2.1, 7.8])
targets = torch.tensor([3.0, -0.5, 2.0, 7.5])

# 创建 MSELoss 实例
criterion = nn.MSELoss()

# 计算损失
loss = criterion(predictions, targets)
print("MSE 损失:", loss.item())
```

### 📐 数学公式

假设预测值为 $\hat{y}$，真实值为 $y$，样本数量为 $N$。均方误差的计算公式为：

$$ \text{MSE} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2 $$

### 📝 举例说明

假设正在预测房价（单位：百万元），模型对 3 套房子的预测价格和真实价格如下：
- 预测值 $\hat{y} = [2.0, 5.5, 3.2]$
- 真实值 $y = [2.5, 5.0, 3.0]$

**计算步骤：**
1. 计算每个样本的误差：$[-0.5, 0.5, 0.2]$
2. 计算误差的平方：$[0.25, 0.25, 0.04]$
3. 求平均值：
$$ \text{MSE} = \frac{0.25 + 0.25 + 0.04}{3} = \frac{0.54}{3} = 0.18 $$

结果说明模型在这个批次上的均方误差为 0.18。
