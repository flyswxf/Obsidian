## 父子组件通信

父子组件是 React 应用中最常见的结构。数据流动始终遵循**单向数据流**原则，即数据只能从父组件流向子组件。

### Props 传递与回调函数

- **父传子**：父组件通过属性（Props）将数据自顶向下传递给子组件。
- **子传父**：父组件将状态更新函数封装后作为 Props 传递给子组件，子组件通过调用该函数并传递参数，实现向父组件通信。

```javascript
import { useState } from 'react';

// 子组件
function Child({ count, onIncrement }) {
  return (
    <div style={{ padding: 10, border: '1px solid gray' }}>
      <p>子组件接收到的计数值: {count}</p>
      <button onClick={() => onIncrement(5)}>增加 5</button>
    </div>
  );
}

// 父组件
export default function Parent() {
  const [count, setCount] = useState(0);

  const handleIncrement = (amount) => {
    setCount(c => c + amount);
  };

  return (
    <div>
      <h2>父组件状态: {count}</h2>
      {/* 将状态和回调函数传递给子组件 */}
      <Child count={count} onIncrement={handleIncrement} />
    </div>
  );
}
```

## 跨层级通信

当组件嵌套层级较深时，逐层传递 Props（即 Props Drilling）会导致代码难以维护。此时可以通过 Context API 实现跨层级的数据共享。

### Context API 实践

Context 提供了一种在组件树中传递数据的方法，而无需在每一个层级手动传递 Props。这也是许多[[状态管理设计#常见状态管理模式|状态管理方案]]的底层基石。

- createContext ：创建一个上下文对象，用于跨越组件树的层级传递数据。
- Provider ：通过 <ThemeContext.Provider value={...}> 向下层所有组件广播数据。

```javascript
import { createContext, useContext, useState } from 'react';

// 1. 创建 Context
const ThemeContext = createContext('light');

// 孙组件
function Grandchild() {
  // 3. 消费 Context 数据
  const theme = useContext(ThemeContext);
  return <p>当前主题是: {theme}</p>;
}

function Child() {
  return <Grandchild />;
}

// 父组件
export default function App() {
  const [theme, setTheme] = useState('dark');

  return (
    // 2. 提供 Context 数据
    <ThemeContext.Provider value={theme}>
      <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
        切换主题
      </button>
      <Child />
    </ThemeContext.Provider>
  );
}
```
## 实例引用转发（Ref 转发）

在某些特殊场景下（如需要直接管理焦点、文本选择或集成第三方 DOM 库），父组件可能需要直接调用子组件内部的 DOM 节点或方法。通过 `forwardRef` 和 `useImperativeHandle` 可以实现受控的 Ref 暴露。

```javascript
import { forwardRef, useImperativeHandle, useRef } from 'react';

// 使用 forwardRef 包装子组件
const CustomInput = forwardRef((props, ref) => {
  const inputRef = useRef(null);

  // 自定义暴露给父组件的实例值
  useImperativeHandle(ref, () => ({
    focus: () => {
      inputRef.current.focus();
    },
    clear: () => {
      inputRef.current.value = '';
    }
  }));

  return <input ref={inputRef} type="text" placeholder="请输入..." />;
});

export default function RefDemo() {
  const childRef = useRef(null);

  return (
    <div>
      <CustomInput ref={childRef} />
      <button onClick={() => childRef.current.focus()}>聚焦输入框</button>
      <button onClick={() => childRef.current.clear()}>清空内容</button>
    </div>
  );
}
```

对于完全脱离组件树关系的兄弟组件或无关组件，如果不想引入全局[[状态管理设计|状态管理]]库，可以借助事件总线（Event Emitter）模式进行通信，但在现代 React 开发中，通常优先推荐提升状态（Lifting State Up）或使用全局状态管理方案。
