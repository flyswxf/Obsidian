## 重排（Reflow）

重排（也称为回流）是指当 DOM 的变化影响了元素的几何信息（如宽、高、位置等），浏览器需要重新计算元素在视口内的几何属性，并重新构建渲染树的过程。重排是浏览器渲染过程中性能开销最大的操作之一。

### 触发条件
- 添加或删除可见的 DOM 元素。
- 元素的尺寸、位置发生变化（如 `width`、`height`、`padding`、`margin`、`border` 等）。
- 元素的内容发生变化（如文本数量增减导致尺寸变化，或是替换了不同尺寸的图片）。
- 浏览器窗口尺寸发生改变（Resize）。
- 获取某些需要即时计算的布局属性（如 `offsetTop`、`offsetLeft`、`offsetWidth`、`offsetHeight`、`scrollTop`、`clientWidth` 等，或者调用了 `getComputedStyle()` / `getBoundingClientRect()`）。为了返回最精确的值，浏览器会被迫立即清空渲染队列，触发同步重排。

## 重绘（Repaint）

重绘是指当元素的非几何属性（如外观、颜色、背景等）发生变化，但并没有改变其在文档流中的位置或尺寸时，浏览器将新样式重新绘制到屏幕上的过程。

### 触发条件
- 改变 `color`、`background-color`、`visibility`、`box-shadow` 等属性。
- 注意：**重排必然引发重绘，但重绘不一定引发重排**。

## 性能优化策略

为了避免频繁的重排与重绘导致的页面卡顿，在日常开发中应遵循以下实践：

1. **合并样式修改**：避免逐条修改 DOM 的 `style` 属性，应通过修改 `className` 或使用 `cssText` 一次性更新样式。
2. **批量操作 DOM**：
   - 使用 `DocumentFragment` 创建一个文档片段，在其中完成所有 DOM 操作后，再将其一次性插入到文档中。
   - 对元素进行复杂的修改时，可以先将其 `display: none`（触发一次重排），修改完成后再恢复显示（再触发一次重排），从而避免中间过程的多次重排。
3. **避免强制同步布局**：将读取会导致重排的属性（如 `offsetWidth`）的操作与修改样式的操作分离，避免在循环中交替读写 DOM。
4. **使用 CSS3 硬件加速**：对于动画效果，尽量使用 `transform`（如 `translate`、`scale`）和 `opacity`。这些属性的改变不会触发重排和重绘，而是直接在合成线程（Compositor Thread）中通过 GPU 处理，性能极高。
