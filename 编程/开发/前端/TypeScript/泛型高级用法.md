## 泛型基础与进阶

泛型（Generics）提供了创建可重用组件的能力，使得函数、接口或类能够支持多种数据类型，而不丢失原本的类型信息。相较于基础的[[类型系统与类型体操#类型系统概述|类型系统]]，泛型更像是类型级别的参数。

### 泛型约束

默认情况下，泛型参数可以是任何类型。通过 `extends` 关键字可以对其进行约束，确保传入的类型具备特定属性。

```typescript
interface Lengthwise {
  length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
  console.log(arg.length);
  return arg;
}
```

### 泛型参数默认值

与函数参数类似，可以为泛型参数指定默认类型。当未显式提供且无法推断出类型时，将使用该默认值。

```typescript
interface Dictionary<T = string> {
  [key: string]: T;
}
```

## 高级应用场景

### 结合条件类型与 infer

泛型与 `infer` 结合是[[类型系统与类型体操#核心机制|类型体操]]中最强大的工具之一，能够动态提取类型结构中的信息。

```typescript
type ElementType<T> = T extends (infer U)[] ? U : T;
// string
type T1 = ElementType<string[]>; 
```

### 协变与逆变

在复杂的泛型使用中，理解类型兼容性至关重要：
- **协变（Covariance）**：允许子类型替换父类型，常见于返回值类型。
- **逆变（Contravariance）**：允许父类型替换子类型，主要出现在函数参数类型中（开启 `strictFunctionTypes` 时生效）。

### 泛型在类与接口中的组合

在构建大型应用或复杂数据结构时，泛型经常结合类使用。例如，利用泛型工厂函数创建实例，或者在某些场景下配合[[装饰器原理|装饰器]]以增强类的行为和类型提示。
