## 语义化标签的概念与意义

语义化标签是指具有明确含义的 HTML 标签，能够直观地表达其包含内容的结构和作用。使用语义化标签不仅有助于开发者理解代码逻辑，更能提升网页的结构清晰度。

核心优势包括：
- **提升代码可读性**：使文档结构一目了然，便于团队协作与后期维护。
- **SEO 优化**：搜索引擎爬虫依赖 HTML 标签来确定上下文和各个部分的权重，语义化标签能帮助爬虫更准确地解析页面内容。
- **无障碍访问（A11y）支持**：屏幕阅读器等辅助技术依赖于标签的语义来向视障用户解释页面结构。

## 常见语义化标签

HTML5 引入了大量结构性语义标签，取代了传统满篇 `div` 的布局方式：

- `header`：表示页面或区块的头部，通常包含导航链接或标识。
- `nav`：定义主要导航链接的容器。
- `main`：文档的主要内容区域，每个页面应仅包含一个 `main` 元素。
- `article`：表示独立的、完整的内容块，如博客文章或新闻报道。
- `section`：用于对页面内容进行分块或分段，通常带有自己的标题。
- `aside`：表示与主要内容相关但可独立存在的侧边栏内容。
- `footer`：表示页面或区块的底部，常包含版权信息、联系方式等。

## 无障碍访问（Accessibility, A11y）

无障碍访问旨在确保所有用户，包括残障人士，都能平等地获取和使用网页内容。语义化标签是实现无障碍访问的基础，但在更复杂的交互场景下，需要借助 WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications) 规范。

### ARIA 核心概念

ARIA 通过为 HTML 元素添加特定的属性，补充或覆盖原有的语义：

- **Role（角色）**：定义元素的类型，如 `role="button"`、`role="dialog"`。
- **Property（属性）**：描述元素的特征，如 `aria-label` 提供不可见的描述文本。
- **State（状态）**：表示元素的当前状态，如 `aria-expanded="true"` 表示下拉菜单已展开，`aria-disabled="true"` 表示按钮已禁用。

### 实践指南

1. **为图片添加替代文本**：始终为 `img` 标签提供有意义的 `alt` 属性，装饰性图片可设为空字符串 `alt=""`。
2. **合理的标题层级**：使用 `h2` 到 `h6` 构建清晰的文档大纲，不要跳跃层级。
3. **表单控件关联**：使用 `label` 标签的 `for` 属性与输入框的 `id` 进行显式关联。
4. **键盘可访问性**：确保所有交互元素（如按钮、链接、表单项）都能通过 `Tab` 键获取焦点，并且具有明显的焦点样式（如 `:focus` 伪类）。

```html
<!-- 语义化与无障碍访问结合的示例 -->
<header>
  <nav aria-label="主导航">
    <ul>
      <li><a href="/">首页</a></li>
      <li><a href="/about">关于</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <h2>如何实现无障碍访问</h2>
    <p>遵循标准规范，合理使用标签...</p>
    <button aria-expanded="false" aria-controls="details-section">展开详情</button>
    <section id="details-section" hidden>
      <!-- 隐藏的详情内容 -->
    </section>
  </article>
</main>
```
