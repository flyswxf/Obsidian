## 响应式设计的核心理念

响应式 Web 设计（Responsive Web Design, RWD）旨在使网页能够根据访问设备的屏幕尺寸、分辨率和方向自动调整布局与内容展示。核心目标是提供一致且优质的用户体验，无论用户使用的是桌面显示器、平板电脑还是智能手机。

## 视口（Viewport）设置

在 HTML 的 `head` 标签中配置视口元数据是实现响应式设计的第一步。它指示浏览器如何控制页面的尺寸和缩放。

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
- `width=device-width`：将视口宽度设置为设备屏幕的物理宽度。
- `initial-scale=1.0`：设置页面的初始缩放比例为 100%。

## 媒体查询（Media Queries）

媒体查询允许根据设备的特定特征（如宽度、高度、方向）应用不同的 CSS 样式。

### 移动端优先（Mobile First）策略

现代开发通常采用移动端优先的设计策略。即默认编写适用于小屏幕的基础样式，然后使用 `min-width` 媒体查询为大屏幕逐步增加或覆盖样式。

```css
/* 基础样式（移动端） */
.container {
  width: 100%;
  padding: 10px;
}

/* 平板设备 */
@media (min-width: 768px) {
  .container {
    width: 750px;
    margin: 0 auto;
  }
}

/* 桌面设备 */
@media (min-width: 1024px) {
  .container {
    width: 960px;
  }
}
```

## 弹性单位与相对尺寸

为了适应不同的屏幕尺寸，应尽量减少硬编码的绝对单位（如 `px`），转而使用相对单位。

- **百分比（%）**：相对于父元素的尺寸。
- **视口单位（vw, vh, vmin, vmax）**：`1vw` 等于视口宽度的 1%，`1vh` 等于视口高度的 1%。
- **相对字体单位（rem, em）**：`rem` 相对于根元素（`html`）的字体大小，`em` 相对于当前或父元素的字体大小。

## 响应式图像与媒体

在不同尺寸的屏幕上加载合适分辨率的图像，可以节省带宽并提升加载速度。

### 使用 `max-width`

防止图像超出其容器的宽度：
```css
img {
  max-width: 100%;
  height: auto;
}
```

### HTML5 `picture` 元素与 `srcset`

根据屏幕宽度或设备像素比提供不同的图像源：

```html
<picture>
  <source media="(min-width: 800px)" srcset="large-image.jpg">
  <source media="(min-width: 400px)" srcset="medium-image.jpg">
  <img src="small-image.jpg" alt="响应式图片示例">
</picture>

<!-- 或者使用 srcset -->
<img src="small.jpg" srcset="medium.jpg 1000w, large.jpg 2000w" alt="图片描述">
```
