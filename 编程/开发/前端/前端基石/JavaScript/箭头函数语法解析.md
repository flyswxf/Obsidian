## 箭头函数核心语法

箭头函数（Arrow Function）是 [[ES6+核心语法速览|ES6]] 引入的一种更为简洁的函数书写方式。它不仅简化了代码结构，还解决了传统函数中 `this` 指向的常见痛点。

### 基础语法转换

传统函数声明通常需要 `function` 关键字、参数括号和函数体大括号。箭头函数通过 `=>` 符号将参数与函数体连接。

```javascript
// 传统函数
const add = function(a, b) {
  return a + b;
};

// 箭头函数
const addArrow = (a, b) => {
  return a + b;
};
```

### 语法简写规则

根据参数数量和函数体复杂度的不同，箭头函数可以进一步简写：

1. **单参数简写**：当且仅当只有一个参数时，可以省略包裹参数的小括号。
2. **隐式返回值**：当函数体只有一条 `return` 语句时，可以省略大括号 `{}` 和 `return` 关键字。

```javascript
// 1. 无参数：必须保留空括号
const greet = () => "Hello World";

// 2. 单参数：省略小括号
const square = x => x * x;

// 3. 多参数：保留小括号
const multiply = (x, y) => x * y;

// 4. 返回对象字面量：必须用小括号包裹对象，避免被解析为代码块
const createUser = name => ({ name: name, role: "user" });
```

## 词法作用域与 this 绑定

箭头函数与传统函数最大的区别在于对 `this` 的处理。它不绑定自己的 `this`，而是通过[[闭包与作用域链|词法作用域]]捕获其所在上下文的 `this` 值。

```javascript
const timer = {
  seconds: 0,
  start() {
    // 传统函数会在 setInterval 内部丢失 this 指向（通常指向 window/undefined）
    // 箭头函数会捕获 start 方法执行时的 this（即 timer 对象）
    setInterval(() => {
      this.seconds++;
      console.log(this.seconds);
    }, 1000);
  }
};
```

**使用禁忌场景**：
- 作为对象的方法调用（若方法内部需要使用 `this` 指向该对象，应使用传统函数）。
- 作为构造函数（箭头函数没有 `prototype` 属性，不能使用 `new` 关键字实例化）。
- 需要使用 `arguments` 对象的场景（箭头函数没有自己的 `arguments`，可使用 ES6 的剩余参数 `...args` 替代）。
