## 作用域与作用域链

作用域定义了变量和函数的可访问范围。JavaScript 主要有全局作用域、函数作用域和块级作用域。块级作用域是 ES6 引入的重要特性，由 `let` 和 `const` 声明的变量具有块级作用域。

```javascript
// 块级作用域示例
{
  let blockScopedVar = "仅在块内可用";
  const PI = 3.14159;
}
// console.log(blockScopedVar); // ReferenceError
```

当访问一个变量时，JavaScript 引擎会首先在当前作用域中查找。如果没有找到，就会沿着词法环境的外部引用向上一级作用域查找，直到找到该变量或到达全局作用域为止。这种链式查找的结构被称为作用域链。

## 闭包的概念

闭包是指那些能够访问自由变量的函数。自由变量是指在函数中使用的，但既不是函数参数也不是函数的局部变量的变量。
换句话说，闭包是由函数以及声明该函数的词法环境组合而成的。即使创建该函数的上下文已经销毁，该函数依然可以访问其定义时的词法环境。

### 闭包的常见应用场景

- **数据私有化**：通过闭包可以创建私有变量，防止外部直接访问和修改，仅通过暴露的接口进行操作。

```javascript
// ES6+ 数据私有化示例
const createCounter = () => {
  let count = 0; // 私有变量
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
};

const counter = createCounter();
console.log(counter.increment()); // 1
console.log(counter.getCount()); // 1
// console.log(counter.count); // undefined，无法直接访问
```

- **函数柯里化**：利用闭包保存部分参数，返回一个接收剩余参数的新函数。

```javascript
// ES6+ 箭头函数实现柯里化
const add = a => b => a + b;
const addFive = add(5);
console.log(addFive(3)); // 8
```

- **事件防抖与节流**：在定时器回调中访问外部的定时器标识变量。

### 闭包的内存泄漏风险

由于闭包会保留对其外部词法环境的引用，导致相关变量无法被垃圾回收机制回收。如果过度使用闭包或未及时解除引用，可能会引起内存泄漏。因此在不再需要闭包时，应将相关变量置为 `null` 以释放内存。
