### 查看当前用户的所有任务
```
squeue -u $USER
```

### 查看某个任务的详情
```
sacct -j 289970 --format=JobID,JobName,State,ExitCode,Start,End
```

- 289964: 任务对应编号


## 查看资源使用情况
```bash
sacct \
  -S 2026-06-01 \
  -E 2026-06-19 \
  -u $USER \
  -X \
  --format=JobID,JobName,AllocTRES%50,Elapsed,State,Start,End
```

- `-S`: 查询起始时间（Start time）。
- `-E`: 查询结束时间（End time）。开区间，需要大于今日
- `-u`: 指定查询的用户（User）。
- `-X`: 仅显示作业级别的统计信息，过滤掉作业步（Job Step）细节。
- `--format`: 指定输出字段及其格式。
  - `JobID`: 作业 ID。
  - `JobName`: 作业名称。
  - `AllocTRES%50`: 分配的可追踪资源（Trackable RESources，包含 CPU、内存、GPU 等分配情况），`%50` 表示列宽设置为 50 个字符以防止长内容被截断。**这个长度刚刚好**
  - `Elapsed`: 作业运行耗时。
  - `State`: 作业运行状态（如 COMPLETED、FAILED、RUNNING 等）。
  - `Start`: 作业启动时间。
  - `End`: 作业结束时间。
