# 堆排序（Heap Sort）

## 核心概念
- 堆：一种基于数组的完全二叉树结构。
- 最大堆：任一结点的值不小于其子结点；用于升序排序。
- 最小堆：任一结点的值不大于其子结点；用于降序排序。
- 0 基下标的数组表示：
  - 父结点：`parent(i) = (i - 1) / 2`
  - 左孩子：`left(i) = 2i + 1`
  - 右孩子：`right(i) = 2i + 2`

## 算法步骤（升序）
1) 用待排序数组[[堆排序#^cc2658|构建最大堆（自底向上的下滤/堆化）]]
2) 交换堆顶与当前堆的最后一个元素，将堆规模减 1。
3) 对新的堆顶执行[[堆排序#^ade98a|下滤]]，恢复最大堆性质。
4) 重复步骤 23，直到堆大小为 1。

**时间与空间复杂度**

| 项目       | 复杂度          | 说明               |
| -------- | ------------ | ---------------- |
| 建堆       | `O(n)`       | 自底向上堆化，按高度求和     |
| 排序       | `O(n log n)` | 每次取堆顶并下滤 `log n` |
| 总时间      | `O(n log n)` | 额外空间 `O(1)`（就地）  |
| 稳定性      | 不稳定          | 相等元素相对次序可能改变     |
| 最好/平均/最坏 | `O(n log n)` | 最坏情况也有上界保证       |

## C++ 示例：迭代版堆排序（升序）
#### 下滤（sift-down / heapify）

^ade98a

- 目标：将索引 `i` 的元素向下移动到合适位置，使以 `i` 为根的子树满足堆性质。
- 迭代实现避免深递归：从当前结点与左右孩子中选择更大者交换，直到越界或不用交换。
```cpp
static void siftDown(std::vector<int>& a, int i, int n) {
    // n 为当前堆大小（开区间 [0, n)）
    while (true) {
        int l = i * 2 + 1;
        int r = l + 1;
        int largest = i;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest == i) break;           // 已满足最大堆
        std::swap(a[i], a[largest]);
        i = largest;                        // 继续向下
    }
}
```
### 构建最大堆（Build-Heap）

^cc2658

- 最后一个非叶子结点索引：`n/2 - 1`（0 基下标）。
- 从 `n/2 - 1` 到 `0` 依次下滤即可在 `O(n)` 时间完成建堆。
```cpp
static void buildMaxHeap(std::vector<int>& a) {
    for (int i = (int)a.size() / 2 - 1; i >= 0; --i) {
        siftDown(a, i, (int)a.size());
    }
}
```
### 堆排序
- **end不会遍历到0**, 因为没必要
```cpp
void heapSort(std::vector<int>& a) {
    int n = (int)a.size();
    buildMaxHeap(a);
    for (int end = n - 1; end > 0; --end) {
        std::swap(a[0], a[end]);           // 将堆顶最大值放到末尾
        siftDown(a, 0, end);               // 在缩小的堆中恢复堆性质
    }
}

// 使用示例
// std::vector<int> v{2, 3, 8, 6, 1};
// heapSort(v); // 结果：1 2 3 6 8
```

**使用 STL 的方式**
- `std::make_heap` 构建堆，`std::sort_heap` 完成排序（默认最大堆，升序）：
```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> a{2, 3, 8, 6, 1};
    std::make_heap(a.begin(), a.end());  // 构建最大堆
    std::sort_heap(a.begin(), a.end());  // 升序排序
}
```
- 降序排序：传入比较器，构建最小堆或对结果反向输出。

**适用与对比**
- 适用：需要就地且最坏时间受控的排序；内存紧张场景。
- 对比：
  - 快速排序：平均常数因子小、缓存友好，通常更快，但最坏 `O(n^2)`（有随机化可缓解）。
  - 归并排序：稳定、`O(n log n)`，但需要 `O(n)` 额外空间。
  - 堆排序：最坏也为 `O(n log n)`，就地但不稳定，常数因子略大。

**易错点与实践建议**
- 下标越界：注意当前堆大小 `n` 的边界判断。
- 最后非叶子结点：用 `n/2 - 1` 而不是 `n/2`。
- 比较器一致性：最大堆/最小堆与排序方向保持一致。
- 为提升性能，优先使用迭代版 `siftDown`，减少函数调用与分支。

**扩展：Top-K（选前 K 大/小）**
- 用大小为 `K` 的堆维护候选：
  - 取前 K 大：维护最小堆，遇到更大的替换堆顶；复杂度 `O(n log K)`。
  - 取前 K 小：维护最大堆，原理相同。
