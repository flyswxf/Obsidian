**问题定义**
- 给定数组 `A[0..n-1]`，求和最大的连续子数组，返回其区间与和。

**分治思想**
- 将区间 `[l, r]` 按中点 `mid` 划分为左右两半：`[l, mid]` 与 `[mid+1, r]`。
- 最大子数组只可能出现在三种情况：
  1) 完全在左半区间；
  2) 完全在右半区间；
  3) 横跨中点（左半的最佳后缀 + 右半的最佳前缀）。
- 分别求这三者，取和最大者即为答案。

**横跨中点的求法**
- 左半：从 `mid` 向左累加，取到达最大值的后缀和及其起点 `bestL`；
- 右半：从 `mid+1` 向右累加，取到达最大值的前缀和及其终点 `bestR`；
- 跨越和为 `leftSuffix + rightPrefix`，区间为 `[bestL, bestR]`。

**算法步骤**
1) 递归求左、右子问题的最大子数组；
2) 线性时间计算跨越中点的最大子数组；
3) 三者比较，返回更大的那一个。

**伪代码**
```text
function maxSubarray(A, l, r):
    if l == r: return (A[l], l, r)
    mid = (l + r) // 2
    (sumL, L1, L2) = maxSubarray(A, l, mid)
    (sumR, R1, R2) = maxSubarray(A, mid+1, r)

    // cross
    s = 0; leftBest = -INF; bestL = mid
    for i from mid downto l:
        s += A[i]
        if s > leftBest: leftBest = s; bestL = i
    s = 0; rightBest = -INF; bestR = mid+1
    for i from mid+1 to r:
        s += A[i]
        if s > rightBest: rightBest = s; bestR = i
    crossSum = leftBest + rightBest

    return argmax by sum of
        (sumL, L1, L2), (sumR, R1, R2), (crossSum, bestL, bestR)
```

**复杂度分析**
- 递推：`T(n) = 2T(n/2) + Θ(n)`（跨越部分线性）；
- 由主定理得：`T(n) = Θ(n log n)`；空间为递归栈 `Θ(log n)`。

**边界与实现细节**
- 基本情形：单元素直接返回其值与索引；
- 处理全部负数：分治算法自然返回最大（最不负）的元素；
- 若需稳定化选择（和相等时），可优先选区间更短或更靠左者。

**允许空子数组的变体**
- 若允许返回空子数组（和定义为 0），修改：
  - 基本情形改为返回 `max(A[l], 0)`，当为 `0` 时标记空；
  - 计算跨越部分时，左后缀和、右前缀和均与 `0` 比较取更大：`leftBest = max(leftBest, 0)`，`rightBest = max(rightBest, 0)`；
  - 三者比较后，若最大为 `0` 且对应区间为空，返回空子数组。
- 复杂度保持 `Θ(n log n)`。

**C++ 示例（返回区间与和）**
```cpp
struct Ans { long long sum; int L, R; };

Ans cross(const vector<int>& a, int l, int mid, int r) {
    long long s = 0, leftBest = LLONG_MIN; 
    int bestL = mid;
    for (int i = mid; i >= l; --i) {
	    s += a[i]; 
	    if (s > leftBest) { 
		    leftBest = s; bestL = i; 
		} 
	}
    s = 0; 
    long long rightBest = LLONG_MIN; 
    int bestR = mid+1;
    for (int i = mid+1; i <= r; ++i) { 
	    s += a[i]; 
	    if (s > rightBest) { 
		    rightBest = s; bestR = i; 
		} 
	}
    return {leftBest + rightBest, bestL, bestR};
}

Ans solve(const vector<int>& a, int l, int r) {
    if (l == r) return {a[l], l, r};
    int mid = (l + r) / 2;
    Ans L = solve(a, l, mid);
    Ans R = solve(a, mid+1, r);
    Ans C = cross(a, l, mid, r);
    return max({L, R, C}, [](const Ans& x, const Ans& y){ return x.sum < y.sum; });
}
```

**对比与应用**
- 与线性 `Kadane` 相比：分治更易与并行/分块结合；
- 适用于需要区间信息且可自然分区的场景，如区段树/并行计算。
