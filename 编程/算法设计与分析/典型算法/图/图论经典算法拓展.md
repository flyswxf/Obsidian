# 图论经典算法拓展 (Advanced Graph Algorithms)

除了基本的搜索与遍历，图论中还有许多解决特定问题的经典算法。

## 1. 最小生成树 (Minimum Spanning Tree, MST)
在加权连通无向图中，寻找一棵包含所有顶点且边权之和最小的树。

- **Prim 算法**:
  - 类似于 Dijkstra 算法。
  - 从一个顶点开始，每次选择连接已访问集合与未访问集合的最小权边。
  - 适合 **稠密图**。
  - 时间复杂度: $O(E + V \log V)$ (斐波那契堆)。

- **Kruskal 算法**:
  - 贪心策略。
  - 将所有边按权值排序，从小到大选择边，若加入该边不构成环（使用并查集判断），则加入。
  - 适合 **稀疏图**。
  - 时间复杂度: $O(E \log E)$。

## 2. 最短路径 (Shortest Path)
寻找图中两点之间权值之和最小的路径。

- **Dijkstra 算法**:
  - **适用**: 非负权图。
  - **思想**: 贪心。每次从未访问节点中选择距离起点最近的节点。
  - **复杂度**: $O(E + V \log V)$。

- **Bellman-Ford 算法**:
  - **适用**: 可处理负权边，可检测负权环。
  - **思想**: 动态规划。对所有边进行 $|V|-1$ 次松弛操作。
  - **复杂度**: $O(VE)$。

- **Floyd-Warshall 算法**:
  - **适用**: 多源最短路径（所有点对之间的最短路径）。
  - **思想**: 动态规划。
  - **复杂度**: $O(V^3)$。

## 3. 拓扑排序 (Topological Sort)
- **适用**: 有向无环图 (DAG)。
- **目标**: 将所有顶点排成一个线性序列，使得对于任意边 $u \to v$，顶点 $u$ 都排在 $v$ 前面。
- **应用**: 任务调度、依赖关系解析（如编译顺序）。
- **实现**: 基于 DFS 或 Kahn 算法（入度表）。
