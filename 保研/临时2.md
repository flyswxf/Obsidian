# EVA-X 肺炎图像分割微调报告

## 1. 模型信息
* **模型名称**：EVA-X
* **模型定位**：专为医学胸部X光图像打造的通用基础模型。
* **网络架构**：基于 Vision Transformer (ViT)，结合 UPerNet 架构作为解码器。
* **预训练机制**：采用基于掩码图像建模的自监督学习方法，能够从海量无标签 X 光图像中提取强大的语义与几何特征。
* **预训练权重**：提供了官方在大量医学图像上预训练的基础权重, 我们根据其README指导选择eva_x_small_patch16_merged520k_mim.pt。

## 2. 微调过程

* **环境配置**：
  * 基础依赖：安装了 PyTorch (1.12.1)、torchvision、timm 等核心库，以及加速工具 Apex 和 xFormers。
  * 分割库：从源码编译并安装了指定版本的 `mmsegmentation==0.29.1`（commit: `7b09967`），并成功编译了 `MSDA` 算子。
* **数据准备**：
  * 面向肺炎分割任务，使用了来自Kaggle的 RSNA Pneumonia 数据集。
  * 运行了数据划分脚本（`python data_splits/prepare_rsna.py`）将数据集划分为训练集与测试集，存储于 `./dataset` 目录下。
* **权重准备**：
  * 下载预训练权重至 `./pretrained` 目录。
  * 运行了精度转换脚本 `python tools/interpolate14to16`，将 EVA-X 权重的精度从 `Half` 转换为 `Float` 以适配分割任务。
* **模型训练**：
  * `python train.py config/eva_x/upernet_eva_x_small_rsna_10ep.py`
  * 在训练目录中成功生成了最终的模型权重文件 `latest.pth`。

## 3. 模型性能
模型训练完成后，在测试集（1776 张图像）上进行了验证。基于日志截图的输出，性能评估指标如下：
![[a3ee426cec634510ce959760a1c093da.png]]
### 3.1 总体评估指标 (Summary)
| 指标名称 | 简称 | 结果 (%) |
| :--- | :---: | :---: |
| **像素级总体准确率** | aAcc | **92.40** |
| **平均交并比** | mIoU | **62.63** |
| **平均准确率** | mAcc | **74.68** |
| **平均 Dice 系数** | mDice | **72.85** |

### 3.2 各类别评估指标 (Per Class Results)
| 类别 (Class) | 交并比 (IoU) | 准确率 (Acc) | Dice 系数 (Dice) |
| :--- | :---: | :---: | :---: |
| **正常背景 (normal)** | 92.10% | 95.27% | 95.89% |
| **肺炎病灶 (pneumonia)** | 33.17% | 54.08% | 49.81% |

### 3.3 结果分析
1. **背景识别极佳**：模型对于正常区域（`normal`）的分割表现非常优异，Acc 和 Dice 指标均达到了 95% 以上，说明模型能够非常精准地识别出非病灶区域的肺部结构。
2. **病灶分割具有挑战性**：肺炎病灶（`pneumonia`）的分割难度较大，其 Dice 系数为 49.81%，IoU 为 33.17%。这在医学影像分割中是较为常见的现象，因为肺炎病变区域往往边界模糊、形态不规则且与正常组织的对比度较低。
3. **总体表现**：得益于基础模型强大的特征提取能力，整体准确率（aAcc）保持在 92.40% 的高水位，说明模型已经具备了初步的肺炎辅助定位能力。
