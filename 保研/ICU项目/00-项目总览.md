## 项目简介

本项目是一个 **ICU 场景下的图神经网络医疗辅助决策系统**。输入为患者的结构化电子病历数据（诊断、手术、药物等），输出为 **药物推荐** 和 **心源性休克高风险状态预测**。

### 为什么用图建模
- 医疗数据天然存在强关系结构（疾病-并发症、疾病-治疗、药物-禁忌）
- 图结构可视化简洁清晰，有助于医学场景所需的 **可解释性**

### 核心技术栈
| 层次 | 技术 | 说明 |
|------|------|------|
| 数据层 | MIMIC-III + 多热编码 | 就诊序列 × 医疗事件指示向量 |
| 知识层 | LLM 增强知识图谱 + 语义聚类 | GPT-4 生成三元组 → k-means/层次聚类 → 超图 |
| 推理层 | 时序感知 GAT (BAT) | 超节点激活 → 邻域扩展 → 时序衰减 → 注意力聚合 |
| 交互层 | 自然语言反馈 + HNSW | 术语识别 → 语义对齐 → 动态图谱更新 → 二次推理 |
| 训练 | Focal Loss + 边稀疏化 | 解决长尾分布 + Top-K 硬掩码 + 辅助正则化 Loss |
