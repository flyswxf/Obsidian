# 推理层：时序感知的图注意力推理

> **整合自**: 4.md（基础版）、4.1.md（简化版）、4.2.md（全序列版）
>
> **核心目标**: 在全局知识超图基础上，围绕患者全序列就诊信息构建个体化子图，实施时序感知的图注意力推理。

## 1. 超节点激活与个体化子图构建

设知识层得到的全局超图为 $G^\star=(V^\star,\mathcal{R},E^\star)$。聚类分配映射 $\kappa:V\rightarrow\{1,\dots,K\}$ 将原始节点映射至超节点。

### 多次就诊联合激活

对每一时间步 $t=1,\dots,T_i$，定义基激活集合：

$$A_i^{(t)}=\big\{C_{\kappa(u)}\ \big|\ u\in \bar{S}_i^{\text{diag}}(t)\cup S_i^{\text{proc}}(t)\big\}\subseteq V^\star$$

其中 $\bar{S}_i^{\text{diag}}(t)$ 已剔除心源性休克诊断 $d_{\mathrm{CS}}$。

### 邻域扩展

在超图上定义无权最短路径距离 $\mathrm{dist}_{G^\star}$，给定半径参数 $k$，对每个 $t$ 的激活集进行半径扩展：

$$B_k(A_i^{(t)})=\big\{v\in V^\star\ \big|\ \exists\,u\in A_i^{(t)}:\ \mathrm{dist}_{G^\star}(u,v)<k\big\}$$

以所有时间步的扩展并集构建患者子图：

$$V_i=\bigcup_{t=1}^{T_i} B_k(A_i^{(t)}),\qquad G_i=G^\star[V_i]$$

> **设计要点**：由多次就诊联合驱动的节点激活先行完成，随后在 $G_i$ 上实施时序加权与图注意力推理。

## 2. 时序衰减权重

引入指数型时间衰减函数 $f(\Delta)=\exp(-\lambda\Delta)$，$\lambda>0$。对每个 $v\in V_i$，定义其时间加权激活强度：

$$s_i(v)=\sum_{t=1}^{T_i} f(T_i-t)\cdot \mathbf{1}_{\{v\in B_k(A_i^{(t)})\}}$$

患者子图上的初始节点表示：

$$h_v^{(0)}=s_i(v)\cdot \mu_v,\qquad v\in V_i$$

其中 $\mu_v$ 为超节点的静态语义嵌入。近期被激活的节点获得更高的初始表示权重，长期未出现的节点趋近零权重。

## 3. 时序增强的图注意力机制

在患者子图 $G_i$ 上采用图注意力网络（GAT/BAT）进行 $L$ 层消息传递。

### 注意力打分与归一化

$$e_{uv}^{(l)}=\mathrm{LeakyReLU}\Big(\mathbf{a}^{(l)\top}\big[\mathbf{W}^{(l)}h_u^{(l)}\ \Vert\ \mathbf{W}^{(l)}h_v^{(l)}\big]\Big)$$

将时序强度 $s_i(v)$ 融入注意力归一化：

$$\alpha_{uv}^{(l)}=\mathrm{softmax}_{v\in \mathcal{N}_i(u)}\Big(e_{uv}^{(l)}\cdot s_i(v)\Big)$$

### 节点更新

$$h_u^{(l+1)}=\sigma\!\left(\sum_{v\in \mathcal{N}_i(u)} \alpha_{uv}^{(l)}\ \mathbf{W}^{(l)}h_v^{(l)}\right)$$

对多头注意力（$m=1,\dots,M$）：

$$h_u^{(l+1)}=\big\Vert_{m=1}^{M}\ \sigma\!\left(\sum_{v\in \mathcal{N}_i(u)} \alpha_{uv}^{(l,m)}\ \mathbf{W}^{(l,m)}h_v^{(l)}\right)$$

## 4. 池化与输出

末层执行加权平均池化，获得固定长度的患者级图表示：

$$z_i=\frac{\sum_{v\in V_i} s_i(v)\, h_v^{(L)}}{\sum_{v\in V_i} s_i(v)}\in\mathbb{R}^{d}$$

经 MLP 映射至任务输出维度：

$$\mathbf{o}_i=\mathrm{MLP}(z_i)\in\mathbb{R}^{D_m+1}$$

输出端采用 Sigmoid 映射：

$$\hat{\mathbf{y}}_i^{\text{rx}}=\sigma_{\mathrm{sig}}(\mathbf{o}_i[1:D_m])\in(0,1)^{D_m},\quad\hat{r}_i=\sigma_{\mathrm{sig}}(\mathbf{o}_i[D_m+1])\in(0,1)$$

前 $D_m$ 维为处方用药的多标签概率，最后一维为心源性休克风险概率。

## 5. 代码实现

### BiAttentionGNNConv（核心卷积层）

代码位于 `graphcare_/model.py`，继承 `MessagePassing`：

```python
class BiAttentionGNNConv(MessagePassing):
    def __init__(self, nn, eps=0., edge_attn=True, **kwargs):
        kwargs.setdefault('aggr', 'add')  # Add 聚合
        self.W_R = nn.Linear(edge_dim, 1)  # 关系特征权重

    def message(self, x_j, edge_attr, attn):
        w_rel = self.W_R(edge_attr)
        out = (x_j * attn + w_rel * edge_attr).relu()  # 三维度消息
        return out
```

### 双注意力机制

- **Alpha Attention**（节点级）：`alpha = softmax(alpha_attn(visit_node))`，形状 `[B, V, N]`
- **Beta Attention**（就诊级）：`beta = tanh(beta_attn(visit_node)) * lambda_j`，形状 `[B, V, 1]`
- **合并**：`attn = alpha * beta`，在 $V$ 维度求和后映射到边

### 患者表征聚合

`patient_mode="joint"` 模式下，拼接两种表征：

```python
x_graph = global_mean_pool(x, batch)           # 全局图池化 [B, H]
x_node = ehr_nodes @ node_emb.weight / sum     # EHR 加权聚合 [B, H]
logits = MLP(cat(x_graph, x_node))              # 拼接后 MLP [B, C]
```

### 关键超参数

| 参数 | 默认值 | 说明 |

| `hidden_dim` | 128 | 隐藏层维度 |
