# 交互层：自然语言反馈闭环与关键性下沉分配

> **整合自**: 5.1.md（正式版）、5.2.md（关键性下沉）、5.3.md（草稿版）
>
> **核心目标**: 实现以自然语言为入口的人机协同决策，将临床人员补充信息规范化并与知识超图高效融合，触发个体化子图的再构建与时序感知推理。

## 1. 术语识别与语义对齐

用户交互输入为一段中文文本 $U_i$（对应患者 $i$ 的当前就诊情境）。经领域适配的中文术语识别（分词、同义归一、形态变体归并），提取候选术语集合 $\mathcal{T}_i=\{\tau_1,\dots,\tau_M\}$。

为每个术语计算嵌入 $\varphi(\tau_j)\in\mathbb{R}^d$，与知识图谱实体进行语义对齐：

$$\mathrm{align}(\tau_j)=\arg\max_{v\in V}\ \mathrm{sim}\big(\varphi(\tau_j),\varphi(v)\big)$$

以阈值判定有效性：仅当 $s(\tau_j)=\mathrm{sim}(\varphi(\tau_j),\varphi(\mathrm{align}(\tau_j)))\ge \tau_{\mathrm{align}}$ 且类型一致时保留。若对齐结果为目标诊断 $d_{\mathrm{CS}}$，则该术语在输入侧被忽略，避免标签泄露。

## 2. 动态图谱更新

交互层将经对齐的术语集合映射至超节点，增量地更新当前就诊的激活集合：

$$A_i^{(T_i)}\ \leftarrow\ A_i^{(T_i)}\ \cup\ \big\{C_{\kappa(\mathrm{align}(\tau_j))}\ \big|\ \tau_j\in \mathcal{T}_i,\ s(\tau_j)\ge \tau_{\mathrm{align}}\big\}$$

在超图中以半径 $k$ 进行邻域扩展，得到更新后的患者子图节点集合 $V_i=\bigcup_{t=1}^{T_i} B_k(A_i^{(t)})$。

> **设计要点**：交互术语在当前就诊 $T_i$ 被纳入激活，其贡献项以 $f(0)=1$ 的最大权重进入累计强度，从而在后续注意力归一化与末层池化中对近期信息赋予更高影响。

## 3. 反馈系统的工程实现

### 整体流程

```
用户自然语言反馈 → LLM 提示词工程 → 节点操作指令(add/remove) → 图结构调整 → 重新预测
```

### HNSW 近似最近邻搜索

反馈关键词经 embedding 后，使用 HNSW 在预先构建的 cluster embedding 索引中做近似最近邻搜索：

- **被搜索向量**：cluster embedding
- **查询向量**：关键词 embedding
- **参数**：`M=32`（每节点最多 32 条近邻边）、`ef_construction=200`（建图候选范围）、`ef_search=100`（查询候选范围）
- **重排**：将每个候选 cluster 的 embedding 与所有关键词 embedding 的余弦相似度求和，做精确重排

> HNSW 将原本线性扫描所有 cluster 的高耗时过程变为低延迟的近似最近邻检索，使反馈闭环可做到交互式响应。

## 4. 关键性下沉分配机制

### 问题背景

超节点的可解释性难以直接映射至临床可读的原始诊断/手术节点。本文提出"关键性下沉分配"机制：在保持模型末层关键性度量不变的前提下，将超节点级关键性沿聚类成员关系与患者时序激活轨迹，严格、可控地分配至原始节点。

### 末层关键性度量

$$\gamma(C_a)=\big\|h_{C_a}^{(L)}\big\|_2\ge 0$$

### 三类责任权重

**1) 时序存在性权重**：

$$p_i(u)=\sum_{t=1}^{T_i} f(T_i-t)\cdot \mathbf{1}_{\{u\in \bar{S}_i^{\text{diag}}(t)\cup S_i^{\text{proc}}(t)\}}$$

**2) 结构桥接权重**：

$$q_i(u)=\sum_{(u,r,v)\in \mathcal{E}_i}1$$

衡量 $u$ 在患者子图跨簇连接中的桥接参与度。

**3) 语义贴合权重**：

$$s(u)=\max\Big(0,\ \frac{\varphi(u)^\top \mu_a}{\|\varphi(u)\|_2\,\|\mu_a\|_2}\Big)$$

### 加权融合与下沉

$$\tilde{\rho}(u\mid C_a)=\alpha_p\frac{p_i(u)}{\sum_{w\in U(C_a)}p_i(w)}+\alpha_q\frac{q_i(u)}{\sum_{w\in U(C_a)}q_i(w)}+\alpha_s\frac{s(u)}{\sum_{w\in U(C_a)}s(u)}$$

其中 $\alpha_p+\alpha_q+\alpha_s=1$。归一化后：

$$\rho(u\mid C_a)=\frac{\tilde{\rho}(u\mid C_a)}{\sum_{w\in U(C_a)}\tilde{\rho}(w\mid C_a)}\in[0,1]$$

原始节点级关键性下沉分配：

$$\gamma_i(u)=\gamma(C_a)\cdot \rho(u\mid C_a),\qquad u\in U(C_a)$$

### 性质保证

- **保守性**：$\sum_{u\in U(C_a)}\gamma_i(u)=\gamma(C_a)$，关键性总量守恒
- **非负性**：$\gamma_i(u)\ge 0$
- **时序敏感性**：近期出现且结构桥接强的原始节点获得更高分配权重
- **避免标签泄露**：$d_{\mathrm{CS}}$ 已从输入侧剔除，$p_i(u)$ 不会因目标诊断提升输入侧权重

### 建议参数

$$\alpha_p=0.5,\ \alpha_q=0.3,\ \alpha_s=0.2$$

优先采用时序主导的分配，并提供面向临床的可调接口。
